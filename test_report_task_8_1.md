## Содержание XML-документации

### Для каждого класса/интерфейса:
- `<summary>` — краткое описание
- `<remarks>` — дополнительная информация, формулы, примеры

### Для каждого метода:
- `<summary>` — описание метода
- `<param>` — описание каждого параметра
- `<returns>` — описание возвращаемого значения
- `<remarks>` — формулы, алгоритмы, ограничения

### Для каждого свойства:
- `<summary>` — описание свойства
- `<remarks>` — формулы, диапазоны значений
- `<example>` — примеры использования (где применимо)

### Для перечислений (enum):
- `<summary>` — описание типа перечисления
- `<remarks>` — общая информация
- Для каждого значения: `<summary>` и `<remarks>`

## Формулы в документации

Все формулы в документации соответствуют `docs/Formulas_Snegotayanie.md`:

1. **Скорость потока:**
   ```
   w = v × 1000 / (3600 × π × di² / 4)
   ```

2. **Число Рейнольдса:**
   ```
   Re = 1000 × w × di / ν
   ```

3. **Коэффициент трения:**
   - Ламинарный: `λ = 64 / Re`
   - Переходный: линейная интерполяция
   - Турбулентный: формула Колбрука-Уайта

4. **Потери давления:**
   ```
   R = 1000 × (w² × ρ × λ) / (2 × di)
   ```

5. **Потери в вентиле:**
   ```
   Δp = (v / 1000 / Kv)² × 100000 × ρ
   ```
