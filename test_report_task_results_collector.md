# Отчёт о тестировании: Блок результатов коллектора

## Дата: 2026-03-20

## Выполненные изменения

### 1. Добавлен конвертер PressureColorConverter
- **Файл:** `src/Converters/Converters.cs`
- **Описание:** Конвертер для цветовой индикации давления
- **Логика:**
  - Давление ≤ 320 мбар → зелёный цвет (#2E7D32)
  - Давление > 320 мбар → красный цвет (#D32F2F)

### 2. Добавлены вычисляемые свойства в CircuitsViewModel
- **Файл:** `src/ViewModels/Hydraulics/CircuitsViewModel.cs`
- **Свойства для блока "Входные данные":**
  - `SupplyTemperature` — температура подачи
  - `ReturnTemperature` — температура обратки
  - `PipeType` — тип трубы
  - `OuterDiameter` — наружный диаметр
  - `WallThickness` — толщина стенки
  - `InnerDiameter` — внутренний диаметр
  - `PipeRoughness` — шероховатость (константа 0.007 мм)
  - `GlycolTypeName` — тип гликоля на русском

- **Свойства для блока "Данные укладки и мощности":**
  - `PowerUp` — удельная мощность вверх
  - `PowerDown` — удельная мощность вниз
  - `PipeSpacing_cm` — шаг укладки в см
  - `SupplySpacing_cm` — шаг подводки в см
  - `SupplyHeatPercent` — доля потерь в подводке

- **Свойства для блока "Результаты коллектора":**
  - `Summary` — итоги коллектора (CollectorSummary)
  - `CollectorTypeDisplay` — тип коллектора
  - `KvValue` — Kv клапана

### 3. Добавлены уведомления об изменении свойств
- Обновлён метод `OnThermalViewModelPropertyChanged` для уведомления об изменении свойств при изменении результата теплового расчёта

### 4. Добавлены атрибуты NotifyPropertyChangedFor
- Для `SelectedCollectorIndex` добавлены атрибуты:
  - `[NotifyPropertyChangedFor(nameof(SelectedCollector))]`
  - `[NotifyPropertyChangedFor(nameof(Summary))]`
  - `[NotifyPropertyChangedFor(nameof(CollectorTypeDisplay))]`
  - `[NotifyPropertyChangedFor(nameof(KvValue))]`

### 5. Модифицирован XAML CircuitsView.xaml
- **Добавлен конвертер:** `PressureColorConverter` в ресурсы
- **Добавлены три информационных блока в Grid.Row="0":**
  1. **Блок "ВХОДНЫЕ ДАННЫЕ"** (левый блок, оранжевый)
     - Температура подачи
     - Температура обратки
     - Тип трубы
     - Наружный диаметр × толщина стенки
     - Внутренний диаметр
     - Шероховатость
     - Тип гликоля
     - Концентрация

  2. **Блок "ДАННЫЕ УКЛАДКИ"** (центральный блок, зелёный)
     - Удельная мощность вверх
     - Удельная мощность вниз
     - Шаг укладки
     - Шаг подводки
     - Доля потерь

  3. **Блок "РЕЗУЛЬТАТЫ"** (правый блок, синий)
     - Количество контуров
     - Общая длина
     - Общая мощность
     - Общий расход
     - Потери (рабочая T) — с цветовой индикацией
     - Потери (расчётная T) — с цветовой индикацией
     - Тип коллектора
     - Kv клапана

- **Удалён старый блок** "Информация о коллекторе" (Grid.Row="3")
