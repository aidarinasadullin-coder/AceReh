# ViewModels/Construction

## Назначение
ViewModels для модуля "Конструктор конструкции" системы снеготаяния РЕХАУ.

## Файлы

### ConstructionViewModel.cs
ViewModel для экрана "Конструктор конструкции".

**Свойства:**
- `LayersAbovePipe` — ObservableCollection<Layer> — слои над трубой
- `LayersBelowPipe` — ObservableCollection<Layer> — слои под трубой
- `AvailableMaterials` — ObservableCollection<Material> — доступные материалы
- `Templates` — ObservableCollection<ConstructionTemplate> — шаблоны конструкций
- `SelectedLayer` — Layer? — выбранный слой
- `SelectedTemplate` — ConstructionTemplate? — выбранный шаблон
- `GroundwaterLevel` — double — уровень грунтовых вод (м)
- `HasLoads` — bool — наличие нагрузок на покрытие
- `ValidationMessage` — string — сообщение валидации
- `IsValid` — bool — признак валидности конструкции
- `R1Total` — double — суммарное R1 (м²·К/Вт)
- `R2Total` — double — суммарное R2 (м²·К/Вт)
- `LambdaE` — double — теплопроводность материала вокруг трубы (Вт/м·К)
- `HasUnsavedChanges` — bool — признак несохранённых изменений

**Команды:**
- `InitializeCommand` — инициализация (загрузка материалов и шаблонов)
- `AddLayerAbovePipeCommand` — добавить слой над трубой
- `AddLayerBelowPipeCommand` — добавить слой под трубой
- `RemoveLayerCommand` — удалить слой
- `ApplyTemplateCommand` — применить шаблон
- `SaveConstructionCommand` — сохранить конструкцию
- `LoadConstructionCommand` — загрузить конструкцию
- `ResetToDefaultCommand` — сбросить к значениям по умолчанию

**Методы:**
- `OnLayerChanged(Layer)` — обработчик изменения слоя
- `OnLayerPropertyChanged(object, PropertyChangedEventArgs)` — обработчик изменения свойств слоя; при изменении материала вызывает `layer.UpdateLambda(GroundwaterLevel)` для корректного выбора λА/λБ
- `UpdateCalculations()` — обновление R1, R2, LambdaE
- `Validate()` — валидация конструкции
- `GetConstruction()` — получить данные конструкции
- `SyncToModel()` — синхронизация данных из ViewModel в модель Construction
- `SyncFromModel()` — синхронизация данных из модели Construction в ViewModel

**Зависимости:**
- `IConstructionService` — сервис для работы с конструкциями
- `IMaterialRepository` — репозиторий материалов
- `IConstructionRepository` — репозиторий конструкций
- `Construction` — модель конструкции (singleton из DI)

**События:**
- `DataChanged` — событие изменения данных конструкции (для уведомления других модулей)

**Интеграция с DI:**
- `ConstructionViewModel` получает экземпляр `Construction` через DI
- `Construction` является singleton и реализует `IConstructionData`
- При изменении данных в `ConstructionViewModel` синхронизируются с моделью `Construction`
- Событие `Construction.DataChanged` уведомляет подписчиков (например, `ThermalViewModel`)
