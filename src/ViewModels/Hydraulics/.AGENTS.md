# ViewModels/Hydraulics

## Назначение
ViewModel для модуля гидравлического расчёта системы снеготаяния.

## Структура

### CircuitsViewModel.cs
Основная ViewModel для модуля "Контура".

**Ответственность:**
- Управление списком коллекторов и контуров
- Расчёт гидравлики контуров
- Балансировка контуров на коллекторе
- Интеграция с ThermalModule и ClimateModule

**Свойства:**
- `Collectors` — список коллекторов (ObservableCollection<CollectorData>)
- `SelectedCollectorIndex` — индекс выбранного коллектора
- `CurrentMode` — режим отображения (OperatingTemperature/DesignTemperature)
- `GlycolType` — тип гликоли
- `GlycolConcentration` — концентрация гликоля
- `InputData` — входные данные для расчёта (HydraulicInputData)

**Вычисляемые свойства:**
- `SelectedCollector` — выбранный коллектор
- `DesignTemperature` — расчётная температура
- `CanAddCollector` — признак возможности добавления коллектора
- `CanAddCircuit` — признак возможности добавления контура

**Команды:**
- `AddCollectorCommand` — добавить коллектор
- `RemoveCollectorCommand` — удалить коллектор
- `AddCircuitCommand` — добавить контур
- `RemoveCircuitCommand` — удалить контур
- `CalculateCommand` — выполнить расчёт
- `SwitchModeCommand` — переключить режим отображения

### CollectorData.cs
ViewModel для данных коллектора.

**Свойства:**
- `CollectorNumber` — номер коллектора
- `Circuits` — список контуров (ObservableCollection<CircuitRow>)
- `Summary` — итоги расчёта (CollectorSummary)
- `ValveType` — тип клапана

### CircuitViewModel.cs
ViewModel для отдельного контура системы снеготаяния.

**Ответственность:**
- Хранение параметров контура
- Вычисляемые свойства для конвертации единиц
- Статус и цвет для отображения в UI

**Свойства:**
- `CircuitNumber` — номер контура
- `CircuitName` — название контура
- `Length` — длина контура (м)
- `SupplyLength` — длина подводки (м)
- `Area` — площадь контура (м²)
- `FlowRate` — расход контура (л/ч)
- `PressureLoss` — потери давления (Па)
- `Throttling` — дросселирование (Па)
- `ValveSetting` — настройка вентиля (1-8)
- `IsReferenceCircuit` — признак опорного контура
- `Velocity` — скорость потока (м/с)
- `ReynoldsNumber` — число Рейнольдса
- `FlowRegime` — режим течения

**Вычисляемые свойства:**
- `PressureLossKPa` — потери давления (кПа)
- `PressureLossMbar` — потери давления (мбар)
- `ThrottlingKPa` — дросселирование (кПа)
- `ThrottlingMbar` — дросселирование (мбар)
- `SpecificFlowRate` — удельный расход (л/ч/м²)
- `Status` — статус контура
- `StatusColor` — цвет статуса

**Методы:**
- `Reset()` — сбросить значения
- `Clone()` — клонировать контур

### CollectorViewModel.cs
ViewModel для выбора и отображения коллектора РЕХАУ.

**Ответственность:**
- Загрузка списка коллекторов
- Подбор коллектора по параметрам
- Фильтрация по типу
- Отображение информации о коллекторе

**Свойства:**
- `AvailableCollectors` — список доступных коллекторов
- `SelectedCollector` — выбранный коллектор
- `SelectedCollectorType` — тип коллектора для фильтрации
- `CircuitCount` — количество контуров для подбора
- `TotalFlowRate` — общий расход (л/ч)
- `IsLoading` — признак загрузки
- `ErrorMessage` — сообщение об ошибке

**Вычисляемые свойства:**
- `FilteredCollectors` — отфильтрованный список
- `CanShowDetails` — признак возможности отображения деталей
- `SelectedCollectorInfo` — информация о коллекторе
- `SelectedCollectorName` — название коллектора
- `SelectedCollectorDiameter` — диаметр коллектора
- `SelectedCollectorKv` — Kv коллектора
- `SelectedCollectorMaxFlow` — максимальный расход
- `SelectedCollectorMaxPressure` — максимальное давление

**Команды:**
- `LoadCollectorsCommand` — загрузить коллекторы
- `SelectCollectorCommand` — подобрать коллектор
- `SelectCollectorFromListCommand` — выбрать из списка
- `ClearSelectionCommand` — сбросить выбор
- `FilterByTypeCommand` — фильтровать по типу

**Методы:**
- `SetSelectionParameters()` — установить параметры подбора
- `GetSelectedCollector()` — получить выбранный коллектор
- `IsCollectorCompatible()` — проверить совместимость
- `GetRecommendation()` — получить рекомендацию

## Использование

```csharp
// Создание ViewModel
var viewModel = new CircuitsViewModel(
    circuitsCalculator,
    glycolService,
    thermalViewModel,
    climateViewModel);

// Добавление коллектора
viewModel.AddCollectorCommand.Execute(null);

// Добавление контура
viewModel.AddCircuitCommand.Execute(null);

// Переключение режима
viewModel.SwitchModeCommand.Execute(null);
```
