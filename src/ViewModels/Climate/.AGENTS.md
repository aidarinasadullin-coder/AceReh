# Каталог: src/ViewModels/Climate/

## Назначение
ViewModel-и для модуля климатических данных

## Файлы

### ClimateViewModel.cs
**Класс**: `ClimateViewModel`
- Наследует `ObservableObject` (CommunityToolkit.Mvvm)
- Реализует MVVM паттерн для экрана климатических данных

**Observable Properties**:
- `FilteredCities: ObservableCollection<CityInfo>` — отфильтрованный список городов
- `SelectedCity: CityInfo?` — выбранный город
- `SearchQuery: string` — текст поиска города
- `AirTemperature: double` — расчётная температура наружного воздуха, °C (дефолт -15)
- `WindSpeed: double` — скорость ветра, м/с (дефолт 5)
- `Humidity: double` — относительная влажность, % (дефолт 70)
- `SnowfallIntensity: double` — интенсивность снегопада, см/ч (дефолт 0.3)
- `SelectedZone: ClimateZone` — выбранная климатическая зона
- `IsHighRequirements: bool` — признак повышенных требований
- `ValidationMessage: string` — сообщение валидации
- `HasUserModifications: bool` — признак ручного изменения данных
- `IsLoading: bool` — признак загрузки данных

**Computed Properties**:
- `IsValid: bool` — валидность данных
- `ZoneDescription: string` — описание климатической зоны
- `IsDataLoaded: bool` — признак загрузки данных
- `CitiesCount: int` — количество загруженных городов

**Commands**:
- `SearchCitiesCommand` — поиск городов
- `LoadAllCitiesCommand` — загрузка всех городов
- `ResetToDefaultsCommand` — сброс к дефолтным значениям
- `ResetToCityDataCommand` — сброс к данным выбранного города
- `LoadDataCommand` — загрузка данных

**Зависимости**:
- `IClimateDataService` — сервис климатических данных
- `IClimateData` — singleton климатических данных (для синхронизации)

**Методы**:
- `LoadDataAsync()` — загрузка климатических данных
- `GetClimateData()` — получение климатических данных для передачи другим модулям
- `SetClimateParameters()` — установка данных из ClimateParameters
- `ValidateAll()` — валидация всех данных
- `SyncToClimateData()` — синхронизация с singleton IClimateData

**События**:
- `DataChanged` — событие изменения климатических данных
- `ValidationChanged` — событие изменения валидации

**Синхронизация данных**:
- При изменении любого свойства вызывается `SyncToClimateData()`
- Метод копирует данные в singleton `IClimateData`
- `ThermalViewModel` подписан на `IClimateData.DataChanged`

## Зависимости
