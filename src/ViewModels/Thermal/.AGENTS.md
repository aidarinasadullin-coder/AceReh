# Каталог: src/ViewModels/Thermal/

## Назначение
ViewModel-и для модуля теплового расчёта

## Файлы

### ThermalViewModel.cs
**Класс**: `ThermalViewModel`
- Наследует `ObservableObject` (CommunityToolkit.Mvvm)
- Реализует MVVM паттерн для экрана теплового расчёта

**Observable Properties**:
- `SelectedMode: OperatingMode` — выбранный режим работы (Антиобледенение/Таяние/Интенсивное)
- `SupplyTemperature: double` — температура подачи, °C (дефолт 50)
- `DeltaT: double` — температурный перепад, К (дефолт 15)
- `GroundTemperature: double` — температура грунта, °C (дефолт 10)
- `SelectedPipe: PipeType` — выбранный тип трубы (дефолт RAUTHERM S 20x2,0)
- `PipeSpacing: double` — шаг укладки трубы, мм (дефолт 200)
- `Result: ThermalCalculationResult?` — результат расчёта
- `IsCalculating: bool` — признак выполнения расчёта
- `ValidationMessage: string` — сообщение валидации

**Коллекции**:
- `AvailablePipes: ObservableCollection<PipeType>` — доступные типы труб (3 стандартные)
- `AvailableModes: ObservableCollection<OperatingMode>` — доступные режимы (3 режима)

**Commands**:
- `CalculateCommand` — выполнить расчёт
- `ResetCommand` — сбросить к дефолтным значениям

**Зависимости**:
- `IThermalCalculator` — калькулятор теплового расчёта
- `IClimateData` — климатические данные
- `IConstructionData` — данные конструкции

**Методы**:
- `BuildThermalParameters()` — собрать ThermalParameters из свойств
- `ValidateInput()` — валидация входных данных

**События**:
- Подписка на `IClimateData.DataChanged`
- Подписка на `IConstructionData.DataChanged`
