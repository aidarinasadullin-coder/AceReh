# Сервисы для модуля "Конструктор конструкции"

## Структура

### IConstructionService.cs
Интерфейс сервиса работы с конструкциями:
- `CalculateThermalResistances(Construction)` — расчёт термических сопротивлений для всех слоёв
- `CalculateR1(IEnumerable<Layer>)` — расчёт R1 (слои над трубой)
- `CalculateR2(IEnumerable<Layer>, double groundwaterLevel)` — расчёт R2 (слои под трубой)
- `ValidateConstruction(Construction)` — валидация конструкции
- `CreateFromTemplate(ConstructionTemplate, IEnumerable<Material>)` — создание из шаблона
- `GetTotalThicknessAbovePipe(Construction)` — общая толщина над трубой
- `GetTotalThicknessBelowPipe(Construction)` — общая толщина под трубой

### ConstructionService.cs
Реализация сервиса:
- Расчёт R = d / λ / 1000 для каждого слоя
- Суммирование R для всех слоёв
- Учёт УГВ при выборе λА/λБ
- Делегирование валидации ConstructionValidator

### ConstructionValidator.cs
Валидатор конструкций с правилами:

#### Правила валидации
1. **Минимальная толщина над трубой**
   - Без нагрузок: 40 мм
   - С нагрузками: 50 мм

2. **Толщина слоя**
   - Минимум: 10 мм
   - Максимум: 1000 мм

3. **Уровень грунтовых вод**
   - Минимум: 0 м
   - Максимум: 10 м

4. **Материалы**
   - Бетон: предупреждение о макс. температуре подачи 50°C
   - Асфальт: предупреждение о мин. температуре воздуха -15°C

5. **УГВ < 1м**
   - Предупреждение о необходимости использования λБ

#### Методы валидации
- `Validate(Construction)` — базовая валидация
- `ValidateForOutdoorTemperature(Construction, double)` — валидация для температуры воздуха
- `ValidateForSupplyTemperature(Construction, double)` — валидация для температуры подачи

## Формулы

### Термическое сопротивление слоя
```
R = d / λ / 1000
```
где:
- d — толщина слоя, мм
- λ — теплопроводность, Вт/м·К
- Результат: м²·К/Вт

### Суммарное термическое сопротивление
```
R_total = Σ(R_i) для всех слоёв
```

### Выбор λ в зависимости от УГВ
```
if (УГВ < 1.0 м)
    λ = λБ  // влажные условия
else
    λ = λА  // сухие условия
```
