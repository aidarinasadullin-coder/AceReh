### ThermalCalculator.cs
**Класс**: `ThermalCalculator` (реализация IThermalCalculator)

**Константы**:
- `SnowDensity = 900.0` — плотность снега, кг/м³
- `IceHeatCapacity = 2100.0` — уд. теплоёмкость льда, Дж/кг·К
- `IceMeltingHeat = 330000.0` — уд. теплота плавления льда, Дж/кг
- `WaterHeatCapacity = 4200.0` — уд. теплоёмкость воды, Дж/кг·К
- `StefanBoltzmann = 5.77e-8` — постоянная Стефана-Больцмана, Вт/м²·К⁴
- `EmissionCoefficient = 0.055` — коэффициент излучения поверхности
- `AlphaBottom = 999999999.0` — коэффициент теплоотдачи снизу (адиабата)
- `RodCoefficient = 0.6` — коэффициент для расчёта параметра m

**Методы**:

#### CalculateHeatTransferCoefficient
```csharp
α = 2.26 × (t_П - t_H)^0.33 + 2.6 × v_H    [Вт/м²·К]
```

#### CalculatePowerUp
```csharp
q_FB = Q_таяние + Q_конв    [Вт/м²]
```
**Примечание**: Q_изл (лучистый поток) исключён из основного расчёта, но вычисляется отдельно для справки.

#### CalculateThermalResistance
```csharp
RFb = R1_total + 1/α_верх    [м²·К/Вт]
RD = R2_total + 1/α_низ      [м²·К/Вт]
```

#### CalculateRodTheory
```csharp
m = 0.6 × √[(1/RFb + 1/RD) / (λE × dE)]    [1/м]
ηR = tanh(m × lR/2) / (m × lR/2)            [безразмерный]
```

#### CalculateExcessTemperature
```csharp
JHmü = [A + (B - C/(q_FB × RFb × RD)) × D × E] × q_FB × RFb    [°C]
```
Где:
- A = 1/ηR
- B = 1/RFb + 1/RD
- C = |t_H - t_G|
- D = lR / (π × λR)
- E = s / (d - s)

#### Calculate
Полный тепловой расчёт:
1. Определение температуры поверхности по режиму
2. Расчёт коэффициента теплоотдачи α
3. Расчёт мощности вверх q_FB (**без Q_изл**)
4. Расчёт тепловых сопротивлений RFb, RD
5. Расчёт параметров теории стержня m, ηR
6. Расчёт избыточной температуры JHmü
7. Расчёт температур теплоносителя
8. Расчёт составляющих мощности (**включая RadiationHeat для справки**)
9. Расчёт мощности вниз q_D
10. Расчёт суммарной мощности
11. Расчёт расхода теплоносителя

## Формулы

### Мощность вверх (основная)
```
q_FB = Q_таяние + Q_конв    [Вт/м²]
```

### Мощность вверх (справочно)
```
q_FB_ref = Q_таяние + Q_изл + Q_конв    [Вт/м²]
```

### Составляющие
- **Q_таяние** = (h/3600) × ρ × [c_льда × (0 - t_H) + L_плавл + c_воды × (t_П - 0)]
- **Q_изл** = ε × σ × [(273 + t_П)/100]^4 (**справочно**)
- **Q_конв** = α × (t_П - t_H)
