# Services/Navigation

## Назначение

Сервисы навигации и синхронизации между модулями.

## Компоненты

### IModuleSynchronizationService.cs

Интерфейс сервиса синхронизации модулей.

**Методы:**
- `UpdateClimate(IClimateData, source)` — обновить климатические данные
- `UpdateConstruction(IConstructionData, source)` — обновить данные конструкции
- `UpdateThermalResult(ThermalCalculationResult, source)` — обновить результаты теплового расчёта
- `UpdateHydraulicsResult(List<CollectorSummary>, source)` — обновить результаты гидравлического расчёта
- `GetContext()` — получить контекст расчёта
- `IsReadyForThermalCalculation()` — проверить готовность к тепловому расчёту
- `IsReadyForHydraulicsCalculation()` — проверить готовность к гидравлическому расчёту
- `Reset()` — сбросить контекст

**События:**
- `ClimateChanged` — изменение климатических данных
- `ConstructionChanged` — изменение данных конструкции
- `ThermalResultChanged` — изменение результатов теплового расчёта
- `HydraulicsResultChanged` — изменение результатов гидравлического расчёта

### ModuleSynchronizationService.cs

Реализация сервиса синхронизации модулей.

**Зависимости:**
- `CalculationContext` — контекст расчёта

**Особенности:**
- Подписывается на `ContextChanged` события
- Перенаправляет события в зависимости от типа изменения
- Централизованная синхронизация между модулями

### ICalculationStateService.cs

Интерфейс сервиса состояния расчёта.

**Методы:**
- `SetThermalCalculating()` — установить флаг выполнения теплового расчёта
- `SetHydraulicsCalculating()` — установить флаг выполнения гидравлического расчёта
- `ResetThermalState()` — сбросить состояние теплового расчёта
- `ResetHydraulicsState()` — сбросить состояние гидравлического расчёта
- `SetThermalNeedsRecalculation(message)` — установить флаг необходимости пересчёта

**События:**
- `StateChanged` — изменение состояния расчёта

### CalculationStateService.cs

Реализация сервиса состояния расчёта.

**Особенности:**
- Хранит состояние расчёта (выполняется/завершён)
- Хранит сообщения о необходимости пересчёта
- Уведомляет подписчиков об изменении состояния

## Использование

```csharp
// DI регистрация
services.AddSingleton<IModuleSynchronizationService, ModuleSynchronizationService>();

// В ViewModel
public class ThermalViewModel
{
    private readonly IModuleSynchronizationService _syncService;
    
    public ThermalViewModel(IModuleSynchronizationService syncService)
    {
        _syncService = syncService;
        _syncService.ClimateChanged += OnClimateChanged;
    }
    
    private void OnClimateChanged(object? sender, ClimateSyncEventArgs e)
    {
        // Автоматический пересчёт при изменении климатических данных
        CalculateCommand.Execute(null);
    }
}
```
