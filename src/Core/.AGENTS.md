# Core Module

## Назначение

Модуль `Core` содержит центральные компоненты приложения, обеспечивающие синхронизацию между модулями и централизованные константы.

## Структура

```
Core/
├── CalculationContext.cs      # Единый контекст расчёта
├── Constants/
│   ├── ThermalConstants.cs    # Константы теплового расчёта
│   ├── HydraulicsConstants.cs # Константы гидравлики
│   └── ValidationConstants.cs  # Константы валидации
└── Extensions/
    ├── DoubleExtensions.cs    # Расширения для double
    └── ValidationExtensions.cs # Расширения для валидации
```

## Компоненты

### CalculationContext

Единый контекст расчёта для синхронизации между модулями.

**Паттерн:** Singleton с DI

**Назначение:**
- Централизованное хранение всех расчётных параметров и результатов
- Обеспечение синхронизации между модулями без событийной модели
- Автоматическое уведомление об изменениях через PropertyChanged

**Свойства:**
- `Climate` — климатические данные (IClimateData)
- `Construction` — данные конструкции (IConstructionData)
- `ThermalResult` — результаты теплового расчёта
- `HydraulicsResults` — результаты гидравлического расчёта
- `State` — состояние расчёта (CalculationState)

**Методы:**
- `UpdateClimate()` — обновить климатические данные
- `UpdateConstruction()` — обновить данные конструкции
- `UpdateThermal()` — обновить результаты теплового расчёта
- `UpdateHydraulics()` — обновить результаты гидравлического расчёта
- `Validate()` — проверить валидность всех данных
- `GetValidationErrors()` — получить список ошибок валидации
- `IsReadyForThermalCalculation()` — проверить готовность к тепловому расчёту
- `IsReadyForHydraulicsCalculation()` — проверить готовность к гидравлическому расчёту

**События:**
- `ContextChanged` — событие изменения контекста

**Использование:**

```csharp
// Внедрение через DI
public class ThermalViewModel
{
    private readonly CalculationContext _context;
    
    public ThermalViewModel(CalculationContext context)
    {
        _context = context;
        _context.ContextChanged += OnContextChanged;
    }
    
    private void OnContextChanged(object? sender, ContextChangedEventArgs e)
    {
        if (e.PropertyName == nameof(CalculationContext.Climate))
        {
            // Автоматический пересчёт при изменении климатических данных
            CalculateCommand.Execute(null);
        }
    }
}
```

### ThermalConstants

Константы теплового расчёта.

**Физические константы:**
- `SnowDensity` — плотность снега (900 кг/м³)
- `IceHeatCapacity` — теплоёмкость льда (2100 Дж/кг·К)
- `IceMeltingHeat` — теплота плавления льда (330000 Дж/кг)
- `WaterHeatCapacity` — теплоёмкость воды (4200 Дж/кг·К)
- `StefanBoltzmann` — постоянная Стефана-Больцмана (5.77e-8 Вт/м²·К⁴)

**Коэффициенты формулы теплоотдачи:**
- `HeatTransferCoefficientA` — коэффициент A (2.26)
- `HeatTransferCoefficientB` — показатель степени B (0.33)
- `HeatTransferCoefficientC` — коэффициент C (2.6)

**Ограничения:**
- `MinAirTemperature` / `MaxAirTemperature` — диапазон температур наружного воздуха
- `MinSupplyTemperature` / `MaxSupplyTemperature` — диапазон температур подачи
- `MinPipeSpacing` / `MaxPipeSpacing` — диапазон шага укладки

### HydraulicsConstants

Константы гидравлического расчёта.

**Ограничения РЕХАУ:**
- `MaxPressureLoss_Pa` — максимальные потери давления (32000 Па = 320 мбар)
- `MaxCircuitLength_m` — максимальная длина контура (120 м)
- `MinVelocity` / `MaxVelocity` — диапазон скорости потока

**Коэффициенты Kv:**
- `Kv_HKV_D` — Kv для вентиля HKV-D (1.2)
- `Kv_IV_DN25` — Kv для вентиля IV DN25 (1.45)
- `Kv_IV_DN32` — Kv для вентиля IV DN32 (1.5)
- `Kv_IV_DN40` — Kv для вентиля IV DN40 (2.0)

### ValidationConstants

Константы валидации.

**Диапазоны:**
- Температуры (воздух, грунт, подача)
- Скорость ветра
- Интенсивность снегопада
- Размеры труб
- Шаг укладки
- Тепловые сопротивления
- Параметры теплоносителя
- Параметры гидравлики

**Сообщения об ошибках:**
- `RangeErrorMessage` — шаблон сообщения об ошибке диапазона
- `PositiveErrorMessage` — шаблон сообщения об ошибке положительного значения
- `NonNegativeErrorMessage` — шаблон сообщения об ошибке неотрицательного значения

### DoubleExtensions

Расширения для типа double.

**Округление:**
- `RoundTo(int decimalPlaces)` — округлить до указанного количества знаков
- `RoundTo1()` / `RoundTo2()` / `RoundTo3()` — округлить до 1/2/3 знаков
- `RoundToInt()` — округлить до целого

**Сравнение:**
- `IsEqual(double other, double epsilon)` — равенство с учётом погрешности
- `IsZero(double epsilon)` — близость к нулю
- `IsPositive()` / `IsNegative()` / `IsNonNegative()` — проверка знака
- `IsInRange(double min, double max)` — проверка диапазона

**Конвертация:**
- `MmToM()` / `MToMm()` — мм ↔ м
- `PaToMbar()` / `MbarToPa()` — Па ↔ мбар
- `LhToM3h()` / `M3hToLh()` — л/ч ↔ м³/ч
- `CelsiusToKelvin()` / `KelvinToCelsius()` — °C ↔ K

**Ограничение:**
- `Clamp(double min, double max)` — ограничить в диапазоне
- `ClampMin(double min)` / `ClampMax(double max)` — ограничить снизу/сверху

### ValidationExtensions

Расширения для валидации.

**Базовые методы:**
- `ValidateRange(double min, double max, string paramName)` — проверка диапазона
- `ValidatePositive(string paramName)` — проверка положительного значения
- `ValidateNonNegative(string paramName)` — проверка неотрицательного значения
- `ValidateNotNull<T>(string paramName)` — проверка не null

**Специализированные методы:**
- `ValidateAirTemperature()` — проверка температуры наружного воздуха
- `ValidateWindSpeed()` — проверка скорости ветра
- `ValidateSnowfallIntensity()` — проверка интенсивности снегопада
- `ValidateSupplyTemperature()` — проверка температуры подачи
- `ValidatePipeSpacing()` — проверка шага укладки
- `ValidateDeltaT()` — проверка температурного перепада
- `ValidateCircuitLength()` — проверка длины контура
- `ValidateVelocity()` — проверка скорости потока
- `ValidatePressureLoss()` — проверка потерь давления

## Интеграция

### Регистрация в DI

```csharp
// Configuration/ServiceCollectionExtensions.cs
public static IServiceCollection AddNavigationServices(this IServiceCollection services)
{
    services.AddSingleton<ICalculationStateService, CalculationStateService>();
    services.AddSingleton<CalculationContext>();
    return services;
}
```

### Использование в ViewModel

```csharp
public class ThermalViewModel : ObservableObject
{
    private readonly CalculationContext _context;
    
    public ThermalViewModel(
        IThermalCalculator calculator,
        CalculationContext context)
    {
        _calculator = calculator;
        _context = context;
        
        // Подписка на изменения контекста
        _context.ContextChanged += OnContextChanged;
    }
    
    private void OnContextChanged(object? sender, ContextChangedEventArgs e)
    {
        if (e.PropertyName == nameof(CalculationContext.Climate) || 
            e.PropertyName == nameof(CalculationContext.Construction))
        {
            // Автоматический пересчёт
            CalculateCommand.Execute(null);
        }
    }
}
```

### Использование констант

```csharp
using SnowMeltingCalculator.Core.Constants;

// Тепловой расчёт
double alpha = ThermalConstants.HeatTransferCoefficientA * 
    Math.Pow(deltaTemp, ThermalConstants.HeatTransferCoefficientB) + 
    ThermalConstants.HeatTransferCoefficientC * windSpeed;

// Гидравлический расчёт
double maxPressureLoss = HydraulicsConstants.MaxPressureLoss_Pa;
double kv = HydraulicsConstants.Kv_HKV_D;

// Валидация
var errors = new List<string>();
temperature.ValidateSupplyTemperature(errors);
windSpeed.ValidateWindSpeed(errors);
```

### Использование расширений

```csharp
using SnowMeltingCalculator.Core.Extensions;

// Округление
double rounded = value.RoundTo2();

// Сравнение
if (value.IsEqual(other, 0.001)) { ... }
if (value.IsInRange(0, 100)) { ... }

// Конвертация

double mbar = pascals.PaToMbar();

// Валидация

```
