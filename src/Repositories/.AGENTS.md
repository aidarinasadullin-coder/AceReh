## Hydraulics Repositories

### ICollectorRepository

Интерфейс репозитория коллекторов РЕХАУ. Предоставляет методы для:

- `GetAllAsync()` — получение всех коллекторов
- `GetByIdAsync()` — получение коллектора по ID
- `GetByTypeAsync()` — получение коллекторов по типу (HKV/IV)
- `GetByCircuitsAsync()` — получение коллектора по количеству контуров
- `SelectCollector()` — подбор коллектора по параметрам
- `GetAvailableCircuitCounts()` — доступные количества контуров
- `IsCollectorSuitable()` — проверка пригодности коллектора
- `GetMaxCircuitsForHKV()` — максимальное количество контуров (12)
- `GetMaxFlowRateForHKV()` — максимальный расход (1.5 м³/ч)
- `GetMaxPressureForHKV()` — максимальное давление (320 мбар)

## Supported Collectors

### HKV-D (Бытовой коллектор)
- Количество контуров: 2, 4, 6, 8, 10, 12
- Kv = 1.2 м³/ч
- Максимальный расход: 1.5 м³/ч
- Максимальное давление: 320 мбар

### IV (Промышленный коллектор)
- IV 1¼" (DN25): Kv = 1.45 м³/ч
- IV 1½" (DN40): Kv = 1.5 м³/ч
