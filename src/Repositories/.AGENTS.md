## Hydraulics Repositories

### ICollectorRepository

Интерфейс репозитория коллекторов РЕХАУ. Предоставляет методы для:

- `GetAllAsync()` — получение всех коллекторов
- `GetByIdAsync()` — получение коллектора по ID
- `GetByTypeAsync()` — получение коллекторов по типу (HKV/IV)
- `GetByCircuitsAsync()` — получение коллектора по количеству контуров
- `SelectCollector()` — подбор коллектора по параметрам
- `GetAvailableCircuitCounts()` — доступные количества контуров
- `IsCollectorSuitable()` — проверка пригодности коллектора
- `GetMaxCircuitsForHKV()` — максимальное количество контуров (12)
- `GetMaxFlowRateForHKV()` — максимальный расход (1.5 м³/ч)
- `GetMaxPressureForHKV()` — максимальное давление (320 мбар)

## Climate Repositories

### ISearchHistoryRepository

Интерфейс репозитория истории поиска городов. Предоставляет методы для:

- `GetAllAsync()` — получение всех записей истории
- `GetByIdAsync()` — получение записи по идентификатору
- `GetByCityIdAsync()` — получение записи по идентификатору города
- `AddAsync()` — добавление записи в историю
- `UpdateAsync()` — обновление записи в истории
- `DeleteAsync()` — удаление записи из истории
- `ClearAsync()` — очистка всей истории
- `InitializeAsync()` — инициализация таблицы (создание если не существует)

### SearchHistoryRepository

Реализация репозитория истории поиска с использованием SQLite.

**Особенности:**
- Файл базы данных: `data/search_history.db`
- Таблица: `SearchHistory` с полями `Id`, `CityId`, `LastUsed`, `UseCount`
- Индекс: `IX_SearchHistory_LastUsed` для сортировки по дате
- Ограничение: `UNIQUE(CityId)` — один город в истории
- Ленивая инициализация — таблица создаётся при первом обращении

## Supported Collectors

### HKV-D (Бытовой коллектор)
- Количество контуров: 2, 4, 6, 8, 10, 12
- Kv = 1.2 м³/ч
- Максимальный расход: 1.5 м³/ч
- Максимальное давление: 320 мбар

### IV (Промышленный коллектор)
- IV 1¼" (DN25): Kv = 1.45 м³/ч
- IV 1½" (DN40): Kv = 1.5 м³/ч
