# Репозитории и сервисы для модуля "Конструктор конструкции"

## Структура

### Repositories/Construction/

#### IMaterialRepository.cs
Интерфейс репозитория материалов:
- `LoadMaterialsAsync()` — загрузка материалов из JSON
- `GetMaterialById(int id)` — получение материала по ID
- `GetMaterialsByCategory(MaterialCategory category)` — получение материалов по категории
- `GetAllMaterials()` — получение всех материалов из кэша

#### MaterialRepository.cs
Реализация репозитория материалов:
- Загрузка из `data/materials_db.json`
- Fallback на `Material.GetDefaultMaterials()` при отсутствии файла
- Кэширование загруженных данных
- Маппинг JSON → Material с конвертацией категорий

#### IConstructionRepository.cs
Интерфейс репозитория конструкций:
- `SaveConstructionAsync()` — сохранение в файл
- `LoadConstructionAsync()` — загрузка из файла
- `SaveToProjectAsync()` — сохранение в проект
- `LoadFromProjectAsync()` — загрузка из проекта

#### ConstructionRepository.cs
Реализация репозитория конструкций:
- Сериализация/десериализация JSON
- DTO для сохранения слоёв
- Интеграция с MaterialRepository

### Services/Construction/

#### IConstructionService.cs
Интерфейс сервиса работы с конструкциями:
- `CalculateThermalResistances()` — расчёт термических сопротивлений
- `CalculateR1()` — расчёт R1 (над трубой)
- `CalculateR2()` — расчёт R2 (под трубой)
- `GetLambdaE()` — получение λE
- `ValidateConstruction()` — валидация
- `CreateFromTemplate()` — создание из шаблона

#### ConstructionService.cs
Реализация сервиса:
- Расчёт R = d / λ / 1000
- Учёт УГВ при выборе λА/λБ
- Интеграция с ConstructionValidator

#### ConstructionValidator.cs
Валидатор конструкций:
- Минимальная толщина над трубой: 40 мм (50 мм при нагрузках)
- Толщина слоя: 10-1000 мм
- УГВ: 0-10 м
- Бетон: макс. температура подачи 50°C
- Асфальт: мин. температура воздуха -15°C
- УГВ < 1м: предупреждение о λБ

## Формулы

### Термическое сопротивление слоя
```
R = d / λ / 1000
```
где:
- d — толщина слоя, мм
- λ — теплопроводность, Вт/м·К

### Выбор λ в зависимости от УГВ
```
if (УГВ < 1.0) λ = λБ  // влажные условия
else λ = λА            // сухие условия
```

## Зависимости

- `Material` — модель материала
- `Layer` — модель слоя
- `Construction` — модель конструкции
- `ValidationResult` — результат валидации
- `ConstructionTemplate` — шаблон конструкции
