# Документация папки Resources

## Назначение

Папка содержит словарь ресурсов WPF (`Dictionary.xaml`) с цветами, стилями и компонентами дизайн-системы REHAU.

## Структура

```
src/Resources/
├── Dictionary.xaml      # Основной словарь ресурсов
└── .AGENTS.md          # Этот файл
```

## Использование

```xml
<!-- Кнопка Primary -->
<Button Style="{StaticResource Button.Primary}" Content="Сохранить"/>

<!-- Кнопка Secondary -->
<Button Style="{StaticResource Button.Secondary}" Content="Отмена"/>

<!-- TextBox с валидацией -->
<TextBox Style="{StaticResource TextBox.Default}"/>
<TextBox Style="{StaticResource TextBox.Error}"/>

<!-- Карточка -->
<Border Style="{StaticResource Card.Default}">
    <!-- Контент -->
</Border>
```
