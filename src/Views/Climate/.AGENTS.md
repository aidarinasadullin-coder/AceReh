# Каталог: src/Views/Climate/

## Назначение
WPF представления (Views) для модуля климатических данных

## Файлы

### ClimateView.xaml
**Класс**: `ClimateView` (UserControl)
- Представление для экрана климатических параметров
- Использует Material Design In XAML Toolkit
- Привязка к `ClimateViewModel` через ViewModelLocator

**Элементы управления**:
- `CityAutoCompleteBox` — контрол автозаполнения для выбора города
  - `SearchQuery` — двусторонняя привязка к ViewModel
  - `SelectedCity` — двусторонняя привязка к ViewModel
  - `FilteredCities` — односторонняя привязка к FilteredCitiesWithHighlight
  - `PlaceholderText` — текст плейсхолдера "Введите город..."
- `TextBox` — поля ввода климатических параметров
- `ComboBox` — выбор климатической зоны
- `CheckBox` — признак повышенных требований
- `materialDesign:Card` — карточки для группировки элементов

**Привязки данных**:
- `SearchQuery` ↔ `ViewModel.SearchQuery`
- `SelectedCity` ↔ `ViewModel.SelectedCity`
- `FilteredCities` ← `ViewModel.FilteredCitiesWithHighlight`
- `AirTemperature` ↔ `ViewModel.AirTemperature`
- `WindSpeed` ↔ `ViewModel.WindSpeed`
- `Humidity` ↔ `ViewModel.Humidity`
- `SnowfallIntensity` ↔ `ViewModel.SnowfallIntensity`
- `SelectedZone` ↔ `ViewModel.SelectedZone`
- `IsHighRequirements` ↔ `ViewModel.IsHighRequirements`
- `ColdFiveDayTemperature` ← `ViewModel.ColdFiveDayTemperature`
- `IsCitySelected` → видимость информации о городе

**Стили**:
- `RehauCardStyle` — стиль карточек
- `RehauSectionTitleStyle` — стиль заголовков секций
- `RehauTextBoxStyle` — стиль полей ввода
- `RehauComboBoxStyle` — стиль выпадающих списков
- `RehauSecondaryButtonStyle` — стиль вторичных кнопок

**Конвертеры**:
- `NullToVisibilityConverter` — видимость при выборе города
- `BoolToVisibilityConverter` — видимость информационных блоков
- `StringToVisibilityConverter` — видимость предупреждений
