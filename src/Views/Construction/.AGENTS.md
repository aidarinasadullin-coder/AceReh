# Views/Construction

## Назначение
Views для модуля "Конструктор конструкции" системы снеготаяния РЕХАУ.

## Файлы

### ConstructionView.xaml
XAML-разметка для экрана "Конструктор конструкции".

**Элементы:**
- Заголовок "Конструкция"
- Секция "Параметры":
  - ComboBox для выбора УГВ (УГВ < 1м / УГВ >= 1м)
  - CheckBox для наличия нагрузок
- Секция "Шаблоны конструкций":
  - ComboBox с шаблонами
  - Кнопка "Применить"
- Секция "Слои над трубой":
  - DataGrid со слоями
  - Кнопка "Добавить слой"
- Секция "Слои под трубой":
  - DataGrid со слоями
  - Кнопка "Добавить слой"
- Секция "Визуализация":
  - Canvas с отрисовкой "пирога" конструкции
  - Легенда материалов
- Секция "Результаты расчёта":
  - R1 (над трубой)
  - R2 (под трубой)
  - LambdaE (вокруг трубы)
- Секция "Валидация":
  - Сообщения об ошибках/предупреждениях

**DataGrid Columns:**
- Материал (ComboBox)
- Толщина, мм (TextBox)
- λ, Вт/м·К (TextBox, редактируемый)
- R, м²·К/Вт (ReadOnly)
- Удалить (Button)

### ConstructionView.xaml.cs
Code-behind для ConstructionView.xaml.

**Функционал:**
- Отрисовка визуализации "пирога" конструкции на Canvas
- Подписка на изменения коллекций слоёв
- Обновление визуализации при изменении свойств ViewModel

**Методы:**
- `DrawConstruction()` — отрисовка слоёв на Canvas
- `GetMaterialColor(Material)` — получение цвета материала по категории
