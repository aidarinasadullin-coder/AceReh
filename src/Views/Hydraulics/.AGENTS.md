# Views/Hydraulics — Представления модуля гидравлики

## Назначение

Папка содержит WPF представления для модуля гидравлического расчёта системы снеготаяния.

## Структура

```
Views/Hydraulics/
├── HydraulicsView.xaml          # Основное представление модуля
├── HydraulicsView.xaml.cs      # Code-behind с конвертером FlowRegimeToColorConverter
├── CircuitInputView.xaml       # Представление для ввода параметров контура
├── CircuitInputView.xaml.cs    # Code-behind для CircuitInputView
├── ResultsView.xaml            # Представление для отображения результатов
└── ResultsView.xaml.cs         # Code-behind для ResultsView
```

## Компоненты

### HydraulicsView.xaml

Основное представление для модуля гидравлики.

**DataBinding:**
- `CircuitLength` — длина контура (м)
- `SupplyLength` — длина подводки (м)
- `CircuitArea` — площадь контура (м²)
- `GlycolType` — тип гликоли
- `GlycolConcentration` — доля гликоля (%)
- `SupplyTemperature` — температура подачи (°C)
- `ReturnTemperature` — температура обратки (°C)
- `VolumeFlowRate` — расход (л/ч)
- `SelectedPipe` — выбранная труба
- `Roughness` — шероховатость (мм)
- `Result` — результат расчёта (HydraulicResult)
- `Warnings` — список предупреждений
- `HasWarnings` — признак наличия предупреждений
- `HasErrors` — признак наличия ошибок
- `ErrorMessage` — сообщение об ошибке
- `SelectedCollector` — выбранный коллектор
- `AvailablePipes` — список доступных труб

**Команды:**
- `CalculateCommand` — выполнить расчёт
- `ResetCommand` — сбросить параметры

### CircuitInputView.xaml

Представление для ввода параметров отдельного контура.

**DataBinding:**
- `CircuitNumber` — номер контура
- `CircuitName` — название контура
- `Length` — длина контура (м)
- `SupplyLength` — длина подводки (м)
- `Area` — площадь контура (м²)
- `FlowRate` — расход (л/ч)
- `PressureLossKPa` — потери давления (кПа)
- `Velocity` — скорость потока (м/с)
- `FlowRegime` — режим течения
- `ThrottlingMbar` — дросселирование (мбар)
- `ValveSetting` — настройка вентиля
- `IsReferenceCircuit` — признак опорного контура
- `Status` — статус контура

### ResultsView.xaml

Представление для отображения результатов расчёта.

**DataBinding:**
- `Result` — результат расчёта (HydraulicResult)
- `TotalPressureLossKPa` — общие потери (кПа)
- `TotalPressureLossMbar` — общие потери (мбар)
- `Warnings` — список предупреждений
- `HasWarnings` — признак наличия предупреждений
- `HasErrors` — признак наличия ошибок
- `ErrorMessage` — сообщение об ошибке
- `SelectedCollector` — выбранный коллектор

## Конвертеры

### FlowRegimeToColorConverter

Конвертер режима течения в цвет для визуальной индикации.

**Цвета:**
- `Laminar` → Зелёный (#2E7D32) — стабильное течение
- `Transitional` → Оранжевый (#FF9800) — требует внимания
- `Turbulent` → Синий (#2196F3) — нормальный режим

## Стили

Все представления используют единообразные стили:
- `SectionHeaderStyle` — заголовок секции
- `InputLabelStyle` — метка ввода
- `InputTextBoxStyle` — поле ввода
- `ResultLabelStyle` — метка результата
- `ResultValueStyle` — значение результата
- `PrimaryButtonStyle` — основная кнопка
- `SecondaryButtonStyle` — вторичная кнопка
- `WarningStyle` — предупреждение
- `ErrorStyle` — ошибка
