# Views/Hydraulics — Представления модуля гидравлики

## Назначение

Папка содержит WPF представления для модуля гидравлического расчёта системы снеготаяния.

## Структура

```
Views/Hydraulics/
├── CircuitInputView.xaml       # Представление для ввода параметров контура
├── CircuitInputView.xaml.cs    # Code-behind для CircuitInputView
├── CircuitsView.xaml           # Представление для таблицы контуров
├── CircuitsView.xaml.cs        # Code-behind для CircuitsView
├── CircuitsResultsView.xaml    # Представление для отображения результатов
└── CircuitsResultsView.xaml.cs # Code-behind для CircuitsResultsView
```

## Компоненты

### CircuitInputView.xaml

Представление для ввода параметров отдельного контура.

**DataBinding:**
- `CircuitNumber` — номер контура
- `CircuitName` — название контура
- `Length` — длина контура (м)
- `SupplyLength` — длина подводки (м)
- `Area` — площадь контура (м²)
- `FlowRate` — расход (л/ч)
- `PressureLossKPa` — потери давления (кПа)
- `Velocity` — скорость потока (м/с)
- `FlowRegime` — режим течения
- `ThrottlingMbar` — дросселирование (мбар)
- `ValveSetting` — настройка вентиля
- `IsReferenceCircuit` — признак опорного контура
- `Status` — статус контура

### CircuitsView.xaml

Представление для таблицы контуров с DataGrid.

**DataBinding:**
- `Collectors` — коллекция коллекторов (ObservableCollection<CollectorData>)
- `SelectedCollectorIndex` — индекс выбранного коллектора
- `SelectedCollector` — выбранный коллектор (CollectorData)
- `CurrentMode` — режим расчёта (HydraulicMode)
- `GlycolType` — тип гликоли (GlycolType)
- `GlycolConcentration` — концентрация гликоля (%)
- `CanAddCircuit` — признак возможности добавления контура

**Команды:**
- `AddCircuitCommand` — добавить контур
- `CalculateCommand` — выполнить расчёт
- `SwitchModeCommand` — переключить режим (Рабочая/Расчётная температура)

**DataGrid колонки:**
- `CircuitNumber` — номер контура (только чтение)
- `CircuitLength` — длина контура (м), редактируется, может блокироваться
- `SupplyLength` — длина подводки (м)
- `CircuitArea` — площадь контура (м²), редактируется, может блокироваться
- `Power` — мощность (Вт, только чтение)
- `FlowRate` — расход (л/ч, только чтение)
- `TotalLoss_mbar` — потери (мбар, только чтение)
- `ValveTurns` — обороты вентиля (только чтение)

**Сценарии ввода длины/площади:**
- При вводе длины → площадь вычисляется автоматически, поле площади блокируется
- При вводе площади → длина вычисляется автоматически, поле длины блокируется
- При очистке любого поля → оба поля становятся активными
- Заблокированные поля: серый фон (#F5F5F5), IsEnabled=False

### CircuitsResultsView.xaml

Представление для отображения результатов расчёта.

**DataBinding:**
- `Collectors` — коллекция коллекторов
- `SelectedCollector` — выбранный коллектор
- `CurrentMode` — режим отображения
- `InputData` — входные данные (HydraulicInputData)

## Конвертеры

### FlowRegimeToColorConverter

Конвертер режима течения в цвет для визуальной индикации.

**Цвета:**
- `Laminar` → Зелёный (#2E7D32) — стабильное течение
- `Transitional` → Оранжевый (#FF9800) — требует внимания
- `Turbulent` → Синий (#2196F3) — нормальный режим

### HydraulicModeToVisibilityConverter

Конвертер режима гидравлического расчёта в Visibility для переключателя режима.

**Параметры:**
- `"Operating"` — виден, если режим OperatingTemperature
- `"Design"` — виден, если режим DesignTemperature

**Использование:**
```xml
<Button Content="Рабочая температура"
        Visibility="{Binding CurrentMode, Converter={StaticResource HydraulicModeToVisibilityConverter}, ConverterParameter=Design}"/>
<Button Content="Расчётная температура"
        Visibility="{Binding CurrentMode, Converter={StaticResource HydraulicModeToVisibilityConverter}, ConverterParameter=Operating}"/>
```

- `ResultValueStyle` — значение результата
- `PrimaryButtonStyle` — основная кнопка
- `SecondaryButtonStyle` — вторичная кнопка
- `WarningStyle` — предупреждение
- `ErrorStyle` — ошибка
