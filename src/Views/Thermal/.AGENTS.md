# Каталог: src/Views/Thermal/

## Назначение
View (XAML) для модуля теплового расчёта

## Файлы

### ThermalView.xaml
**Тип**: UserControl (WPF View)
**DataContext**: `ThermalViewModel`

**Структура**:
- **Заголовок**: "Тепловой расчёт" (MaterialDesignHeadline5TextBlock)
- **Группа "Режим работы"**:
  - ComboBox: выбор режима (Антиобледенение/Таяние/Интенсивное)
  - Привязка: `SelectedMode` (OperatingMode)
  - Описание режима через конвертер `OperatingModeDescriptionConverter`
  
- **Группа "Температуры"**:
  - TextBox: Температура подачи (°C), привязка: `SupplyTemperature`
  - TextBox: Температурный перепад (К), привязка: `DeltaT`
  - TextBox: Температура грунта (°C), привязка: `GroundTemperature`
  
- **Группа "Труба"**:
  - ComboBox: выбор трубы, привязка: `SelectedPipe` (PipeType)
  - TextBox: Шаг укладки (мм), привязка: `PipeSpacing`
  - Информация о выбранной трубе (наружный/внутренний диаметр)
  
- **Кнопки**:
  - Button: "Рассчитать", Command: `CalculateCommand`
  - Button: "Сбросить", Command: `ResetCommand`
  - IsEnabled привязан к `IsCalculating` через `InverseBooleanConverter`
  
- **Валидация**:
  - TextBlock: `ValidationMessage` (оранжевый цвет, видимость через `StringToVisibilityConverter`)
  
- **Группа "Результаты"** (видимость через `NullToVisibilityConverter`):
  - Коэффициент теплоотдачи α (Вт/м²·К) — `Result.Alpha`
  - Мощность вверх q_FB (Вт/м²) — `Result.PowerUp`
  - Мощность вниз q_D (Вт/м²) — `Result.PowerDown`
  - Суммарная мощность (Вт/м²) — `Result.PowerTotal`
  - Средняя температура (°C) — `Result.MeanTemperature`
  - Температура обратки (°C) — `Result.ReturnTemperature`
  - Расход (л/(ч·м²)) — `Result.VolumeFlowRate`
  - КПД ребра η_R — `Result.EfficiencyEtaR`
  
- **Дополнительные параметры** (Expander):
  - Теплота плавления снега — `Result.MeltingHeat`
  - Лучистый поток (справочно) — `Result.RadiationHeat`
  - Конвективный тепловой поток — `Result.ConvectionHeat`
  - Параметр m — `Result.ParameterM`
  - Сопротивление R₁ — `Result.R1Total`
  - Сопротивление R₂ — `Result.R2Total`
  - Полное сопротивление R_FB — `Result.RFb`
  - Полное сопротивление R_D — `Result.RD`
  - Массовый расход — `Result.MassFlowRate`

**Стили MaterialDesign**:
- `MaterialDesignCard` — для групп
- `MaterialDesignTextBox` — для ввода
- `MaterialDesignComboBox` — для выбора
- `MaterialDesignRaisedButton` — для кнопки "Рассчитать"
- `MaterialDesignOutlinedButton` — для кнопки "Сбросить"
- `MaterialDesignSubtitle1TextBlock` — для заголовков групп
- `PrimaryHueMidBrush` — красный цвет РЕХАУ (#E50040)
- `SecondaryHueMidBrush` — зелёный цвет РЕХАУ (#44C7B5)

**Конвертеры**:
- `NullToVisibilityConverter` — видимость результатов
- `StringToVisibilityConverter` — видимость сообщений валидации
- `InverseBooleanConverter` — инверсия IsCalculating для IsEnabled
- `EnumDescriptionConverter` — описание enum
- `OperatingModeDescriptionConverter` — описание режима работы
