## Компоненты

### CityAutoCompleteBox

**Назначение:** Кастомный контрол для автозаполнения при выборе города.

**Функции:**
- TextBox с плейсхолдером
- Popup с выпадающим списком
- Debounce 300ms для поиска
- Навигация клавиатурой (↑↓, Enter, Escape, Tab)
- Подсветка совпадений в названиях

**Dependency Properties:**
- `SearchQuery` (string) — текст поиска
- `SelectedCity` (CityInfo) — выбранный город
- `FilteredCities` (IEnumerable<CityMatchResult>) — отфильтрованный список
- `IsPopupOpen` (bool) — признак открытого popup
- `SelectedSuggestionIndex` (int) — индекс выбранного предложения
- `PlaceholderText` (string) — текст плейсхолдера

**События:**
- `CitySelected` — выбор города
- `SearchCleared` — очистка поиска

**Использование:**
```xml
<controls:CityAutoCompleteBox
    SearchQuery="{Binding SearchQuery, Mode=TwoWay}"
    SelectedCity="{Binding SelectedCity, Mode=TwoWay}"
    FilteredCities="{Binding FilteredCities}"
    PlaceholderText="Введите город..."
    CitySelected="OnCitySelected"/>
```
