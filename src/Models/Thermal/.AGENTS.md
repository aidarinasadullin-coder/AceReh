# Каталог: src/Models/Thermal/

## Назначение
Модели данных для теплового расчёта

## Файлы

### OperatingMode.cs
**Enum**: `OperatingMode`
- `AntiIcing = 3` — Антиобледенение (t_П = +3°C)
- `Melting = 5` — Таяние (t_П = +5°C)
- `Intensive = 7` — Интенсивное (t_П = +7°C)

### PipeType.cs
**Класс**: `PipeType`
- `Name: string` — название трубы
- `Article: string` — артикул
- `OuterDiameter: double` — наружный диаметр, мм
- `InnerDiameter: double` — внутренний диаметр, мм
- `WallThickness: double` — толщина стенки, мм
- `ThermalConductivity: double` — теплопроводность, Вт/м·К
- `DisplayName: string` — отображаемое имя
- `StandardPipes: PipeType[]` — стандартные трубы РЕХАУ (3 типа)

### ThermalParameters.cs
**Класс**: `ThermalParameters`
- `Mode: OperatingMode` — режим работы
- `SupplyTemperature: double` — температура подачи, °C
- `DeltaT: double` — температурный перепад, К
- `GroundTemperature: double` — температура грунта, °C
- `Pipe: PipeType` — тип трубы
- `PipeSpacing: double` — шаг укладки, мм
- `R1Total: double` — сопротивление над трубой, м²·К/Вт
- `R2Total: double` — сопротивление под трубой, м²·К/Вт
- `LambdaE: double` — теплопроводность стяжки, Вт/м·К
- `AirTemperature: double` — температура воздуха, °C
- `WindSpeed: double` — скорость ветра, м/с
- `SnowfallIntensity: double` — интенсивность снегопада, см/ч
- `CoolantDensity: double` — плотность теплоносителя, кг/м³
- `CoolantHeatCapacity: double` — теплоёмкость, кДж/кг·К
- `Clone()` — создать копию

### ThermalCalculationResult.cs
**Интерфейс**: `IThermalCalculationResult`
**Класс**: `ThermalCalculationResult`
- `Alpha: double` — коэффициент теплоотдачи, Вт/м²·К
- `PowerUp: double` — мощность вверх, Вт/м²
- `PowerDown: double` — мощность вниз, Вт/м²
- `PowerTotal: double` — суммарная мощность, Вт/м²
- `MeltingHeat: double` — теплота плавления снега, Вт/м²
- `RadiationHeat: double` — лучистый поток, Вт/м² (**справочно**, не входит в q_FB)
- `ConvectionHeat: double` — конвективный поток, Вт/м²
- `ExcessTemperature: double` — избыточная температура, °C
- `MeanTemperature: double` — средняя температура, °C
- `SupplyTemperature: double` — температура подачи, °C
- `ReturnTemperature: double` — температура обратки, °C
- `DeltaT: double` — температурный перепад, К
- `R1Total: double` — сопротивление над трубой, м²·К/Вт
- `R2Total: double` — сопротивление под трубой, м²·К/Вт
- `RFb: double` — полное сопротивление вверх, м²·К/Вт
- `RD: double` — полное сопротивление вниз, м²·К/Вт
- `ParameterM: double` — параметр m, 1/м
- `EfficiencyEtaR: double` — КПД ребра
- `MassFlowRate: double` — массовый расход, кг/(ч·м²)
- `VolumeFlowRate: double` — объёмный расход, л/(ч·м²)
- `IsValid: bool` — признак валидности
- `ValidationErrors: string[]` — ошибки валидации
- `ToString()` — строковое представление

### IConstructionData.cs
**Интерфейс**: `IConstructionData`
- `R1Total: double` — сопротивление над трубой, м²·К/Вт
- `R2Total: double` — сопротивление под трубой, м²·К/Вт
- `LambdaE: double` — теплопроводность стяжки, Вт/м·К
- `IsValid: bool` — признак валидности
- `DataChanged` — событие изменения данных

**Класс**: `ConstructionData` (реализация по умолчанию)
- Дефолтные значения: R1Total=0.05, R2Total=0.1, LambdaE=1.6

**Класс**: `ConstructionDataChangedEventArgs`
- Аргументы события изменения данных конструкции
