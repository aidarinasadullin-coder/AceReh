# Модели данных модуля "Конструктор конструкции"

## Структура папки

```
src/Models/Construction/
├── Material.cs           # Модель материала
├── MaterialCategory.cs   # Enum категорий материалов (в Material.cs)
├── LayerPosition.cs      # Enum позиции слоя
├── Layer.cs              # Модель слоя конструкции
├── ValidationResult.cs   # Результат валидации
├── ConstructionTemplate.cs # Шаблон конструкции
└── Construction.cs       # Модель конструкции (реализует IConstructionData)
```

## Классы

### Material (Материал)

**Файл:** `Material.cs`

**Назначение:** Модель материала из справочника

**Свойства:**
- `Id` (int) — идентификатор материала
- `Name` (string) — название материала
- `Category` (MaterialCategory) — категория материала
- `LambdaA` (double) — теплопроводность в сухих условиях (УГВ >= 1м), Вт/м·К
- `LambdaB` (double) — теплопроводность во влажных условиях (УГВ < 1м), Вт/м·К
- `MaxSupplyTemp` (double?) — максимальная температура подачи, °C
- `MinOutdoorTemp` (double?) — минимальная температура наружного воздуха, °C
- `Notes` (string?) — примечания

**Методы:**
- `GetDefaultMaterials()` — получить предустановленные материалы (11 материалов)
- `GetDefaultMaterial()` — получить материал по умолчанию (Бетон плотный)
- `GetColor()` — получить цвет для визуализации

### MaterialCategory (Категория материала)

**Файл:** `Material.cs`

**Значения:**
- `Concrete` (0) — бетон
- `Soil` (1) — грунт
- `Insulation` (2) — изоляция
- `Coating` (3) — покрытие
- `Subbase` (4) — подстилающий слой
- `Screed` (5) — стяжка

### LayerPosition (Позиция слоя)

**Файл:** `LayerPosition.cs`

**Значения:**
- `AbovePipe` (0) — над трубой (к поверхности)
- `BelowPipe` (1) — под трубой (к грунту)

### Layer (Слой)

**Файл:** `Layer.cs`

**Назначение:** Модель слоя конструкции

**Свойства:**
- `Id` (Guid) — уникальный идентификатор слоя
- `Material` (Material) — материал слоя
- `Thickness` (double) — толщина слоя, мм
- `CalculatedLambda` (double) — теплопроводность (λ), Вт/м·К
- `IsLambdaOverridden` (bool) — признак ручного изменения λ
- `Position` (LayerPosition) — позиция относительно трубы
- `Order` (int) — порядковый номер слоя
- `CalculatedR` (double) — термическое сопротивление, м²·К/Вт (вычисляемое)

**Методы:**
- `Clone()` — создать копию слоя
- `UpdateLambda(double groundwaterLevel)` — обновить λ в зависимости от УГВ

### ValidationResult (Результат валидации)

**Файл:** `ValidationResult.cs`

**Назначение:** Результат валидации конструкции

**Свойства:**
- `IsValid` (bool) — признак валидности
- `Errors` (List<string>) — список ошибок
- `Warnings` (List<string>) — список предупреждений

**Методы:**
- `Success()` — создать валидный результат
- `Failure(string)` — создать невалидный результат с ошибкой
- `Failure(IEnumerable<string>)` — создать невалидный результат с ошибками
- `AddError(string)` — добавить ошибку
- `AddWarning(string)` — добавить предупреждение
- `Merge(ValidationResult)` — объединить результаты
- `GetAllMessages()` — получить все сообщения

### ConstructionTemplate (Шаблон конструкции)

**Файл:** `ConstructionTemplate.cs`

**Назначение:** Предустановленный шаблон конструкции

**Свойства:**
- `Id` (int) — идентификатор шаблона
- `Name` (string) — название шаблона
- `Description` (string) — описание
- `LayersAbovePipe` (List<LayerTemplate>) — слои над трубой
- `LayersBelowPipe` (List<LayerTemplate>) — слои под трубой
- `HasLoads` (bool) — признак наличия нагрузок
- `DefaultGroundwaterLevel` (double) — УГВ по умолчанию

**Методы:**
- `GetDefaultTemplates()` — получить предустановленные шаблоны (3 шаблона)

### Construction (Конструкция)

**Файл:** `Construction.cs`

**Назначение:** Модель конструкции ("Пирог"), реализует `IConstructionData`

**Свойства:**
- `LayersAbovePipe` (ObservableCollection<Layer>) — слои над трубой
- `Layers` (ObservableCollection<Layer>) — все слои (для совместимости)
- `GroundwaterLevel` (double) — уровень грунтовых вод, м
- `HasLoads` (bool) — признак наличия нагрузок
- `MaterialAroundPipe` (Material?) — материал вокруг трубы (вычисляемое)

**IConstructionData:**
- `R1Total` (double) — суммарное R над трубой, м²·К/Вт
- `R2Total` (double) — суммарное R под трубой, м²·К/Вт
- `LambdaE` (double) — теплопроводность вокруг трубы, Вт/м·К
- `IsValid` (bool) — признак валидности
- `DataChanged` (event) — событие изменения данных

**Методы:**
- `AddLayerAbovePipe(Material, double)` — добавить слой над трубой
- `AddLayerBelowPipe(Material, double)` — добавить слой под трубой
- `RemoveLayer(Layer)` — удалить слой
- `ClearLayers()` — очистить все слои
- `CalculateR1()` — рассчитать R1
- `CalculateR2()` — рассчитать R2
- `GetLambdaE()` — получить LambdaE
- `UpdateLambdaForGroundwater()` — обновить λ при изменении УГВ
- `ValidateConstruction()` — валидация конструкции
- `RaiseDataChanged(...)` — вызвать событие изменения
- `GetAllLayers()` — получить все слои
- `GetTotalThicknessAbovePipe()` — общая толщина над трубой
- `GetTotalThicknessBelowPipe()` — общая толщина под трубой

## Формулы

### Термическое сопротивление слоя

```
R = d / λ / 1000    [м²·К/Вт]

где:
- d — толщина слоя, мм
- λ — теплопроводность материала, Вт/м·К
```

### Выбор λ в зависимости от УГВ

```
λ = {
    λА, если УГВ >= 1 м (сухие условия)
    λБ, если УГВ < 1 м (влажные условия)
}

Примечание: Только для слоёв ПОД трубой.
Слои НАД трубой всегда используют λА.
```

## Валидация

### Правила валидации

| Параметр | Правило | Сообщение |
|----------|---------|-----------|
| Толщина слоя | 10 ≤ d ≤ 1000 мм | "Толщина слоя должна быть от 10 до 1000 мм" |
| Суммарная толщина над трубой (без нагрузок) | ≥ 40 мм | "Минимальная стяжка над трубой: 40 мм" |
| Суммарная толщина над трубой (с нагрузками) | ≥ 50 мм | "Минимальная стяжка над трубой при нагрузках: 50 мм" |
| УГВ | 0 ≤ УГВ ≤ 10 м | "Уровень грунтовых вод должен быть от 0 до 10 м" |
| Наличие слоёв | ≥ 1 слой | "Конструкция должна содержать хотя бы один слой" |
