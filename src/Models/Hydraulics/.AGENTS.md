# Hydraulics Models

## Назначение
Модели данных для модуля гидравлического расчёта.

## Структура

### Enums

#### FlowRegime
Режим течения жидкости в трубе. Определяется по числу Рейнольдса:
- `Laminar = 0` — ламинарный (Re < 2300)
- `Transitional = 1` — переходный (2300 ≤ Re ≤ 4000)
- `Turbulent = 2` — турбулентный (Re > 4000)

#### GlycolType
Тип гликоля в теплоносителе:
- `Ethylene = 0` — этиленгликоль (C2H6O2)
- `Propylene = 1` — пропиленгликоль (C3H8O2)

#### CollectorType
Тип коллектора РЕХАУ:
- `HKV = 0` — бытовой коллектор HKV-D
- `IV = 1` — промышленный коллектор IV

## Зависимости
- Нет внешних зависимостей

## Связанные файлы
- `data/glycol_data.json` — данные о свойствах гликолей
- `data/rehau_products.json` — данные о продукции РЕХАУ

## Классы

#### HydraulicParameters
Параметры для гидравлического расчёта контура. Содержит:
- Параметры контура: CircuitLength, SupplyLength, PipeSpacing, SupplySpacing
- Параметры теплоносителя: GlycolConcentration, GlycolType, SupplyTemperature, ReturnTemperature, MeanTemperature (вычисляемое)
- Свойства теплоносителя: Density, KinematicViscosity, SpecificHeat
- Параметры трубы: Pipe (PipeType), Roughness, InnerDiameter (вычисляемое)
- Параметры из теплового расчёта: VolumeFlowRate, PowerPerArea, CircuitArea, CircuitFlowRate (вычисляемое)
- Валидация: Validate(), IsValid
