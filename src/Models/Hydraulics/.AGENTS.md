# Hydraulics Models

## Назначение
Модели данных для модуля гидравлического расчёта.

## Структура

### Enums

#### FlowRegime
Режим течения жидкости в трубе. Определяется по числу Рейнольдса:
- `Laminar = 0` — ламинарный (Re < 2300)
- `Transitional = 1` — переходный (2300 ≤ Re ≤ 4000)
- `Turbulent = 2` — турбулентный (Re > 4000)

#### GlycolType
Тип гликоля в теплоносителе:
- `Ethylene = 0` — этиленгликоль (C2H6O2)
- `Propylene = 1` — пропиленгликоль (C3H8O2)

#### CollectorType
Тип коллектора РЕХАУ:
- `HKV = 0` — бытовой коллектор HKV-D
- `IV = 1` — промышленный коллектор IV

#### ValveType
Тип балансировочного клапана:
- `HKV_D = 0` — клапан HKV-D
- `IV_1_4 = 1` — клапан IV 1¼"
- `IV_1_5 = 2` — клапан IV 1½"

#### HydraulicMode
Режим отображения гидравлических данных:
- `OperatingTemperature = 0` — рабочая температура
- `DesignTemperature = 1` — расчётная температура (холодный пуск)

### Классы

#### HydraulicInputData
Входные данные для гидравлического расчёта контуров. Содержит:
- Данные из ThermalModule: PowerUp, PowerDown, SupplyTemperature, ReturnTemperature, InnerDiameter, PipeSpacing_mm
- Данные из ClimateModule: ColdFiveDayTemperature
- Данные от пользователя: GlycolType, GlycolConcentration, SupplySpacing_cm, SupplyHeatPercent, ValveType
- Вычисляемые свойства: OperatingTemperature, DesignTemperature, DeltaT, PipeSpacing_cm
- Валидация: Validate(), IsValid

#### CircuitTemperatureResult
Результат расчёта контура при определённой температуре. Содержит:
- Temperature — температура теплоносителя
- Density — плотность теплоносителя
- KinematicViscosity — кинематическая вязкость
- ReynoldsNumber — число Рейнольдса
- FlowRegime — режим течения
- FrictionFactor — коэффициент трения λ
- PressureLossPerMeter — удельные потери давления
- CircuitPipeLoss — потери в трубе контура
- SupplyPipeLoss — потери в трубе подводки
- ValveLoss — потери в вентиле
- TotalLoss — суммарные потери (вычисляемое)
- TotalLoss_mbar — суммарные потери в мбар (вычисляемое)

#### CircuitRow
Строка таблицы контура для гидравлического расчёта. Содержит:
- Входные данные: CircuitNumber, CircuitLength, SupplyLength, TotalLength (вычисляемое), CircuitArea, PipeSpacing_cm, SupplySpacing_cm, SupplyHeatPercent, Power, FlowRate, Velocity
- Результаты при рабочей температуре: OperatingResult (CircuitTemperatureResult)
- Результаты при расчётной температуре: DesignResult (CircuitTemperatureResult)
- Балансировка: Throttling, RecommendedValveSetting, ValveTurns, IsReferenceCircuit
- Вычисляемые свойства: IsActive, CurrentResult, FlowRegimeDescription, TotalLoss_mbar
- **Сценарии ввода длины/площади:**
  - `IsLengthUserInput` — признак того, что длина введена пользователем
  - `IsAreaUserInput` — признак того, что площадь введена пользователем
  - `IsLengthReadOnly` — признак того, что поле длины заблокировано
  - `IsAreaReadOnly` — признак того, что поле площади заблокировано
- **Обработчики изменения:**
  - `OnCircuitLengthChanged` — при изменении длины вычисляет площадь
  - `OnCircuitAreaChanged` — при изменении площади вычисляет длину
  - `OnPipeSpacing_cmChanged` — при изменении шага укладки пересчитывает связанное поле

#### CollectorSummary
Итоги расчёта коллектора. Содержит:
- CollectorNumber — номер коллектора
- CircuitCount — количество контуров
- ValveType — тип клапана
- Kv — коэффициент пропускной способности
- TotalPipeLength — общая длина труб
- TotalPower — суммарная мощность
- TotalFlowRate — суммарный расход
- PressureLoss_Operating_mbar — потери при рабочей температуре
- PressureLoss_Cold_mbar — потери при расчётной температуре
- ReferenceCircuitNumber — номер референсного контура
- Warnings — предупреждения
- IsValid — признак валидности
- MaxAllowedPressure_mbar — максимально допустимые потери (320 мбар)

#### ValidationResult
Результат валидации. Содержит:
- IsValid — признак валидности
- Errors — список ошибок
- Warnings — список предупреждений
- AddError() — добавить ошибку
- AddWarning() — добавить предупреждение
