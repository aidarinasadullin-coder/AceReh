# Behaviors

## Назначение
Папка содержит attached behaviors для WPF-контролов.

## Структура

### TextBoxBehavior.cs
Attached behavior для улучшения UX ввода чисел в TextBox.

**Функционал:**
1. **SelectAllOnFocus** - выделение всего текста при получении фокуса
2. **RestoreOnEscape** - восстановление исходного значения при нажатии Escape
3. **NormalizeDecimalSeparator** - замена точки и запятой на системный десятичный разделитель

**Использование в XAML:**
```xml
<TextBox behaviors:TextBoxBehavior.SelectAllOnFocus="True"
         behaviors:TextBoxBehavior.RestoreOnEscape="True"
         behaviors:TextBoxBehavior.NormalizeDecimalSeparator="True"/>
```

**Применено к полям:**
- ClimateView: AirTemperature, WindSpeed, Humidity, SnowfallIntensity
