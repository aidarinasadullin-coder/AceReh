# Каталог: src/

## Назначение
Исходный код Windows-приложения C# .NET 8 WPF для расчёта систем снеготаяния РЕХАУ.

## Структура проекта

```
src/
├── Configuration/          # DI-конфигурация
│   └── ServiceCollectionExtensions.cs
├── Models/                 # Модели данных
│   ├── Climate/           # Климатические модели
│   └── Thermal/           # Модели теплового расчёта
├── Services/               # Бизнес-логика
│   ├── Climate/           # Сервисы климата
│   └── Thermal/           # Сервисы теплового расчёта
├── ViewModels/             # MVVM ViewModels
│   ├── Climate/           # ViewModel климата
│   └── Thermal/           # ViewModel теплового расчёта
├── Views/                  # XAML представления
│   ├── Climate/           # View климата
│   └── Thermal/           # View теплового расчёта
├── Repositories/           # Репозитории данных
├── MainWindow.xaml         # Главное окно
├── MainWindow.xaml.cs      # Code-behind главного окна
└── App.xaml.cs             # Точка входа приложения
```

## Навигация

### MainViewModel (MainWindow.xaml.cs)
**Класс**: `MainViewModel` (partial, ObservableObject)

**Свойства**:
- `CurrentView: object` — текущее представление
- `MenuItems: MenuItem[]` — пункты меню
- `SelectedMenuItem: MenuItem?` — выбранный пункт меню

**Пункты меню**:
| # | Название | Icon | View | ViewModel |
|---|----------|------|------|-----------|
| 1 | Климат | WeatherCloudy | ClimateView | ClimateViewModel |
| 2 | Тепловой расчёт | Fire | ThermalView | ThermalViewModel |
| 3 | Конструкция | Layers | — | — |
| 4 | Контура | Pipe | — | — |
| 5 | Результаты | ChartBar | — | — |

**Навигация**:
```csharp
private void NavigateToView(MenuItem menuItem)
{
    CurrentView = menuItem.Title switch
    {
        "Климат" => new ClimateView { DataContext = _climateViewModel },
        "Тепловой расчёт" => new ThermalView { DataContext = _thermalViewModel },
        _ => new ClimateView { DataContext = _climateViewModel }
    };
}
```

## DI-регистрация

### App.xaml.cs
```csharp
protected override async void OnStartup(StartupEventArgs e)
{
    var services = new ServiceCollection();
    services.AddApplicationServices();  // Регистрирует все модули
    _serviceProvider = services.BuildServiceProvider();
    
    // Загрузка данных
    var climateService = _serviceProvider.GetRequiredService<IClimateDataService>();
    await climateService.LoadClimateDataAsync();
    
    // Создание окна
    var mainWindow = new MainWindow();
    mainWindow.Show();
}
```
