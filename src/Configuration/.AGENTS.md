# Каталог: src/Configuration/

## Назначение
Конфигурация DI (Dependency Injection) и регистрация сервисов приложения.

## Файлы

### ServiceCollectionExtensions.cs
**Класс**: `ServiceCollectionExtensions` (static)
- `AddClimateModule(IServiceCollection)` — регистрация сервисов климатического модуля
- `AddThermalModule(IServiceCollection)` — регистрация сервисов теплового модуля
- `AddConstructionModule(IServiceCollection)` — регистрация сервисов модуля конструктора конструкции
- `AddApplicationServices(IServiceCollection)` — регистрация всех сервисов приложения

## Зарегистрированные сервисы

## Использование

```csharp
// В App.xaml.cs
var services = new ServiceCollection();
services.AddApplicationServices();
var serviceProvider = services.BuildServiceProvider();

// Получение сервисов
var climateViewModel = serviceProvider.GetRequiredService<ClimateViewModel>();
var thermalViewModel = serviceProvider.GetRequiredService<ThermalViewModel>();
var constructionViewModel = serviceProvider.GetRequiredService<ConstructionViewModel>();
var circuitsViewModel = serviceProvider.GetRequiredService<CircuitsViewModel>();
```
