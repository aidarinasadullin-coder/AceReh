# Tests/Services/Hydraulics

## Назначение
Unit-тесты для сервисов гидравлического расчёта.

## Структура

### HydraulicCalculatorTests.cs
Тесты для `HydraulicCalculator`:
- `CalculateVelocity` — расчёт скорости потока
- `CalculateReynoldsNumber` — расчёт числа Рейнольдса
- `DetermineFlowRegime` — определение режима течения
- `CalculateFrictionFactor` — расчёт коэффициента трения λ
- `CalculatePressureLossPerMeter` — расчёт удельных потерь давления
- `CalculateValvePressureLoss` — расчёт потерь в вентиле
- `Calculate` — полный гидравлический расчёт
- `CalculateBalancing` — балансировка контуров

### GlycolDataServiceTests.cs
Тесты для `GlycolDataService`:
- `GetDensity` — получение плотности гликоля
- `GetSpecificHeat` — получение удельной теплоёмкости
- `GetKinematicViscosity` — получение кинематической вязкости
- `GetThermalConductivity` — получение теплопроводности
- `GetProperties` — получение всех свойств
- Интерполяция по температуре и концентрации
- Граничные случаи и валидация

### HydraulicValidatorTests.cs
Тесты для `HydraulicValidator`:
- `Validate` — валидация входных параметров
- `ValidateResult` — валидация результата расчёта
- Граничные случаи для всех параметров
- Проверка предупреждений

## Зависимости
- `NUnit` — фреймворк тестирования
- `SnowMeltingCalculator.Services.Hydraulics` — тестируемые сервисы
- `SnowMeltingCalculator.Models.Hydraulics` — модели данных

## Запуск тестов
```bash
dotnet test --filter "FullyQualifiedName~Hydraulics"
```
