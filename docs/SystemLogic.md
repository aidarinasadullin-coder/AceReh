# Логика работы системы снеготаяния

## 1. Режимы работы системы

### 1.1 Рабочий режим (Operating Mode)
- **Температура поверхности:** +3°C / +5°C / +7°C (выбирается пользователем)
- **Температура теплоносителя:** +35°C...+50°C (рабочая температура)
- **Назначение:** нормальная эксплуатация, поддержание температуры поверхности
- **Балансировка:** настраивается для этого режима

### 1.2 Расчётный режим (Design Mode) — холодный пуск
- **Температура наружного воздуха:** -28°C...-15°C (расчётная температура)
- **Температура поверхности:** +3°C / +5°C / +7°C
- **Назначение:** старт системы при отрицательных температурах
- **Особенности:** DpVent выше из-за большей плотности гликоля
- **Применение:** выбор насоса с запасом по напору

## 2. Сценарии работы системы

### 2.1 Режим 1: Старт с выходом на рабочую температуру
- Датчик температуры на поверхности
- Система поддерживает температуру поверхности +3/+5/+7°C
- Балансировка настраивается для рабочей температуры
- При старте система нагревается от расчётной до рабочей температуры

### 2.2 Режим 2: Работа по датчику осадков
- Система включается от датчика осадков
- Работает до температуры наружного воздуха:
  - **Zone_M10:** до -10°C
  - **Zone_M15:** до -15°C
  - **Zone_M20:** до -20°C
- Нагревает поверхность до +3/+5/+7°C
- Работает пока датчик осадков не покажет прекращение осадков
- При температуре ниже порога зоны система отключается

## 4. Гидравлические параметры

### 4.1 DpVent (потери на вентиле коллектора)

**Формула для IV/COMFORT:**
```
DpVent = (V_dot / 1000 / Kv)² × 100000 × ρ
```
где:
- V_dot — расход теплоносителя, л/ч
- Kv — коэффициент пропускной способности вентиля
- ρ — плотность гликоля, г/см³

**Формула для HKV-D:**
```
DpVent = 15000 × (ρ / 2000) × v²
```
где:
- ρ — плотность гликоля, г/см³
- v — скорость потока, м/с

**Разница между режимами:**
- Плотность гликоля зависит от температуры
- При рабочей температуре (+35°C...+50°C) плотность ниже
- При расчётной температуре (-28°C...-15°C) плотность выше
- DpVent выше при расчётной температуре из-за большей плотности

**Применение:**
- Выбор насоса с запасом по напору для холодного пуска
- Насос должен иметь изменяющиеся характеристики для работы в обоих режимах

### 4.2 Балансировка (обороты вентиля)

- Настраивается **один раз** для рабочей температуры
- При расчётной температуре балансировка **не пересчитывается**
- **Примечание:** балансировка выполнена для режима при работе рабочей температуры

**Формула Kv от оборотов:**
```
Kv = f(ValveTurns, ValveType)
```
где:
- ValveTurns — обороты вентиля
- ValveType — тип вентиля (IV 1¼", IV 1½", HKV-D)

## 5. Связь между режимами

### 5.1 Хранение результатов

Каждый контур хранит два результата:
- **OperatingResult** — результат при рабочей температуре
- **DesignResult** — результат при расчётной температуре

### 5.2 Переключение режимов

- Переключение режима **не вызывает пересчёт**
- Меняется только отображение (OperatingResult ↔ DesignResult)
- Данные сохраняются для обоих режимов

### 5.3 Параметры, зависящие от температуры

| Параметр | Рабочий режим | Расчётный режим |
|----------|---------------|-----------------|
| Плотность гликоля | ниже | выше |
| Вязкость гликоля | ниже | выше |
| DpVent | ниже | выше |
| DpGesamt | ниже | выше |

## 6. Рекомендации по выбору насоса

1. **Напор насоса** должен обеспечивать работу при расчётной температуре (холодный пуск)
2. **Производительность насоса** должна обеспечивать требуемый расход
3. **Рекомендуется** использовать насосы с изменяющимися характеристиками (частотное регулирование)
4. **Запас по напору** должен учитывать повышенное гидравлическое сопротивление при низких температурах
