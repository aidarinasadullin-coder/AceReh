## 3. РАСЧЁТНЫЕ ФОРМУЛЫ (DVERLUST)

### 3.1 Скорость потока (w):
```
w = (Q_lh / 3600) / (π × di² / 4)    [м/с]
```
Excel: `=(0.001*B12)/(3.141593*((0.001*F7-0.002*H7)^2)/4)`

Где:
- Q_lh - расход (л/ч)
- di - внутренний диаметр (мм)

### 3.2 Число Рейнольдса (Re):
```
Re = 10 × w × di / ν    [безразмерный]
```
Excel: `=10*D12*(F7-2*H7)/$R$3`

Где:
- w - скорость (м/с)
- di - внутренний диаметр (мм)
- ν - кинематическая вязкость (см²/с) → $R$3 = ν/100

### 3.3 Коэффициент гидравлического трения λ (ОРГИНАЛ):
**Формула Колбрука-Уайта (только турбулентный режим):**
```
λ = (1 / (-2 × LOG(k/(3.71×di) + 2.51/(Re×√λ))))²
```
Excel: `=(1/((-2)*LOG($F$4/(3.71*($F$7-2*$H$7))+2.51/($F12*SQRT(AQ12)))))^2`

Где:
- k = 0.007 мм (шероховатость PE-X)
- di - внутренний диаметр (мм)
- Re - число Рейнольдса

**Реализация:** Итерационный расчёт в скрытых столбцах AK→AQ (7 итераций)

### 3.4 Удельные потери давления (R):
```
R = 10000 × (w² × ρ × λ) / (2 × di) × 100    [Па/м]
```
Excel: `=10000*(($D12^2)*$R$4*$H12)/(2*($F$7-2*$H$7))*100`

Где:
- w - скорость (м/с)
- ρ - плотность (кг/м³) → $R$4 = ρ/1000
- λ - коэффициент трения
- di - внутренний диаметр (мм)

## 4. РАСЧЁТ КОНТУРА (Berechnung-Verteiler)

### 4.1 Мощность контура (QHK):
```
QHK = (L_HK / (100/VAHK) + L_Zul / (100/VAZul) × (qZul/100)) × (q_o + q_u)    [Вт]
```
Excel: `=($C19/(100/VAHK)+$D19/(100/VAZul)*(qZul/100))*(Leistung_nach_Oben+Leistung_nach_Unten)`

Где:
- L_HK - длина контура (м)
- L_Zul - длина подводки (м)
- VAHK - шаг укладки (см)
- VAZul - шаг подводки (см)
- qZul - коэффициент подводки (10% если изолирована)
- q_o - мощность вверх (Вт/м²)
- q_u - мощность вниз (Вт/м²)

### 4.2 Расход теплоносителя (v):
```
v = QHK × 3.6 / (ρ × c_p × ΔT)    [л/ч]
```
Excel: `=($F19*(3.6/(Dichte/1000)/spezifische_Wärmekapazität)/(Vorlauftemperatur-Rücklauftemperatur))`

### 4.3 Потери давления в трубе (DpRohr):
```
DpRohr = L × R    [Па]
```
Excel: `=(E19*J19)`

### 4.4 Потери давления в вентилях (DpVent):
**Для HKV-D:**
```
DpVent = (v / 1.2)² × 100000 × ρ    [Па]
```

**Для IV 1 1/4:**
```
DpVent = (1000 × 15) × (ρ/2) × w²    [Па]
DpVent2 = (v / 1.45)² × 100000 × ρ    [Па]
```

**Для IV 1 1/2:**
```
DpVent = (1000 × 15) × (ρ/2) × w²    [Па]
DpVent2 = (v / 1.5)² × 100000 × ρ    [Па]
```

### 4.5 Суммарные потери (DpGesamt):
```
DpGesamt = DpRohr + DpVent1 + DpVent2    [Па]
```

### 4.6 Дросселирование (zu drosseln):
```
Если DpGesamt < Dp_max:
    zu_drosseln = Dp_max - DpRohr - DpVent(HKV) или Dp_max - DpRohr - DpVent(IV)
Иначе:
    zu_drosseln = 0
```

## 5. ТРЕБУЕМЫЕ ИЗМЕНЕНИЯ ДЛЯ λ

### 5.1 Текущее состояние:
- λ рассчитывается **только** по формуле Колбрука-Уайта
- Нет проверки на режим течения

### 5.2 Новая логика расчёта λ:

```
ЕСЛИ Re < 2300 (ламинарный режим):
    λ = 64 / Re    (формула Пуазейля)
    
ИНАЧЕ ЕСЛИ 2300 ≤ Re ≤ 4000 (переходный режим):
    λ_lam = 64 / 2300 = 0.0278
    λ_turb = Colebrook-White(Re=4000)
    λ = λ_lam + (Re - 2300) / (4000 - 2300) × (λ_turb - λ_lam)
    
ИНАЧЕ Re > 4000 (турбулентный режим):
    λ = Colebrook-White (существующая формула)
```

### 5.3 Формула интерполяции (переходный режим):
```
λ = 0.0278 + (Re - 2300) / 1700 × (λ_CW_4000 - 0.0278)
```

Где λ_CW_4000 - значение λ по Колбруку-Уайту при Re=4000

## 6. АЛГОРИТМ ДЛЯ РЕАЛИЗАЦИИ (C#)

```csharp
public double CalculateFrictionFactor(double Re, double diameter_mm, double roughness_mm)
{
    if (Re < 2300)
    {
        // Ламинарный режим - формула Пуазейля
        return 64.0 / Re;
    }
    else if (Re <= 4000)
    {
        // Переходный режим - интерполяция
        double lambda_laminar = 64.0 / 2300; // ≈ 0.0278
        double lambda_turbulent = ColebrookWhite(4000, diameter_mm, roughness_mm);
        double ratio = (Re - 2300) / 1700.0;
        return lambda_laminar + ratio * (lambda_turbulent - lambda_laminar);
    }
    else
    {
        // Турбулентный режим - Колбрук-Уайт
        return ColebrookWhite(Re, diameter_mm, roughness_mm);
    }
}

private double ColebrookWhite(double Re, double d_mm, double k_mm)
{
    // Итерационное решение
    double lambda = 0.02; // Начальное приближение
    double di_m = d_mm / 1000.0;
    double k_m = k_mm / 1000.0;
    
    for (int i = 0; i < 20; i++)
    {
        double newLambda = Math.Pow(
            1.0 / (-2.0 * Math.Log10(k_m / (3.71 * di_m) + 2.51 / (Re * Math.Sqrt(lambda)))),
            2);
        
        if (Math.Abs(newLambda - lambda) < 0.000001)
            break;
        lambda = newLambda;
    }
    return lambda;
}
```
