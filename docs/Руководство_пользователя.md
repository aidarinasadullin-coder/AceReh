## 1. Введение

### 1.1 Назначение программы

Программа предназначена для теплового и гидравлического расчёта систем снеготаяния (антиобледенения) с использованием труб РЕХАУ RAUTHERM. Расчёт выполняется для открытых площадок: пандусы, въезды, пешеходные зоны, дорожки.

### 1.2 Нормативные ссылки

- **СП 131.13330.2025** «Строительная климатология» — климатические параметры (температура наиболее холодных суток, пятидневки, ветер, снеговая нагрузка)
- **DIN EN 60534** — промышленные регулирующие клапаны (формула Kv)
- **VDI 2075** — гидравлическая балансировка систем отопления
- **ASHRAE Handbook** — теплофизические свойства водных растворов гликолей (этиленгликоль / пропиленгликоль)

### 1.3 Термины и сокращения

| Термин | Описание |
|--------|----------|
| **α** | Коэффициент теплоотдачи поверхности, Вт/(м²·К) |
| **q_FB_ref** | Удельный тепловой поток покрытия, Вт/м² |
| **Q_таяние** | Тепловая мощность на таяние снега, Вт/м² |
| **Q_конв** | Тепловая мощность на конвекцию, Вт/м² |
| **Q_изл** | Тепловая мощность излучения (справочно, не входит в PowerUp), Вт/м² |
| **PowerUp** | Суммарная расчётная мощность: Q_таяние + Q_конв, Вт/м² |
| **R** | Удельные потери давления в трубе, Па/м |
| **Δp** | Потери давления, Па |
| **Kv** | Коэффициент пропускной способности клапана, м³/ч |
| **V_dot** | Объёмный расход, л/ч |
| **HKV-D** | Бытовой распределительный коллектор РЕХАУ |
| **IV 1¼", IV 1½"** | Промышленные коллекторы РЕХАУ |
| **HK** | Нагревательный контур |

| **T_воздуха (расчётная)** | °C | Расчётная температура наружного воздуха | **Авторасчёт (см. 4.2)** или ручной ввод |
| **T_холодной пятидневки** | °C | Температура наиболее холодной пятидневки обеспеченностью 0.92 | СП 131.13330.2025 (информационно) |

### 4.2 Расчётные величины

#### Автоматический выбор T_воздуха по таблице 1.6 (СП 131.13330.2025)

При выборе города из базы программа получает **T5Days092** — температуру наиболее холодной пятидневки обеспеченностью 0.92. T_воздуха устанавливается автоматически:

| T_холодной пятидневки T5Days092 | T_воздуха расчётная | Климатическая зона |
|--------------------------------|--------------------|-------------------|
| T5Days092 ≥ −27 °C | **−10 °C** | Zone_M10 |
| −37 °C ≤ T5Days092 < −27 °C | **−15 °C** | Zone_M15 |
| T5Days092 < −37 °C | **−20 °C** | Zone_M20 |
| Включён флаг «Повышенные требования» | **−20 °C** | Zone_M20_Plus |

> **Развилка (fork):** расчётная температура выбирается не произвольно, а по критерию холодной пятидневки. Это соответствует таблице 1.6 СП 131.13330.2025.

**Пользователь может вручную изменить T_воздуха** — после ручного редактирования программа считает, что данные модифицированы (`HasUserModifications = true`), и не будет автоматически пересчитывать температуру при повторном выборе того же города.

**Кнопка «Сбросить к данным города»** (ResetToCityData) восстанавливает авто-расчётное значение по таблице 1.6.

#### Остальные расчётные величины

- **Скорость ветра** — заполняется из данных города (`WindAvgTempLe8`)
- **Влажность** — заполняется из данных города (`Humidity15hCold`)
- **K_atm** — коэффициент атмосферного давления (зависит от высоты над уровнем моря, если задана)

### 4.3 Ограничения

- T_воздуха: **−50…+10 °C** (по умолчанию −15 °C, при выходе за диапазон — предупреждение)
- Скорость ветра: 0.1–30 м/с
- Влажность: 20–100 %
- Интенсивность снегопада: 0–20 мм/ч

## 6. Шаг 3 — Тепловой расчёт

### 6.1 Входные данные

| Поле | Ед. изм. | Описание |
|------|----------|----------|
| Режим работы | — | Антиобледенение (+3 °C) / Таяние (+5 °C) / Интенсивный (+7 °C) |
| T_подачи | °C | Температура теплоносителя на подаче (вводится пользователем) |
| T_обратки | °C | Температура теплоносителя на обратке (рассчитывается программой) |
| Тип гликоля | — | Этиленгликоль / Пропиленгликоль |
| Концентрация гликоля | % | Объёмная доля гликоля в растворе |
| T_воздуха | °C | Расчётная температура наружного воздуха (с Шага 1) |
| Скорость ветра v_wind | м/с | Расчётная скорость ветра (с Шага 1) |
| Интенсивность снегопада | мм/ч | Водяной эквивалент снегопада (0 = без снега) |

### 6.2 Расчёт α (коэффициента теплоотдачи)

**Единая формула для всех типов покрытия:**

```
α = 2.26 × (t_П − t_H)^0.33 + 2.6 × v_wind    [Вт/(м²·К)]
```

Где:
- **t_П** — температура поверхности, °C (зависит от выбранного режима)
- **t_H** — температура наружного воздуха (T_воздуха), °C
- **v_wind** — скорость ветра, м/с

**Важно:** T_пов (температура поверхности) задаётся режимом работы. Ограничение −15 °C относится только к материалу «Асфальт» (см. Шаг 2, материалы БД) — при его выборе и T_воздуха < −15 °C программа выдаёт предупреждение. Для бетона и других покрытий такого ограничения нет.

### 6.3 Составляющие теплового потока

```
Q_таяние = f(интенсивность_снегопада, t_пов, t_воздуха)    [Вт/м²]
Q_конв   = α × (t_П − t_H)                                 [Вт/м²]
PowerUp  = Q_таяние + Q_конв                                [Вт/м²]
```

Где:
- **Q_таяние** — мощность на плавление снега (0 при отсутствии снегопада). Рассчитывается по энтальпии: `(h/3600) × ρ_снега × [c_льда×(0−t_H) + L_плавл + c_воды×(t_П−0)]`
- **Q_конв** — мощность на компенсацию конвективных теплопотерь
- **t_П** — температура поверхности, °C (зависит от режима: +3 / +5 / +7 °C)
- **t_H** — температура наружного воздуха, °C
- **Q_изл** (лучистая составляющая) рассчитывается отдельно справочно и **не входит** в PowerUp

**Важно:** В коде нет отдельного промежуточного параметра `q_FB_ref`. Мощности Q_таяние и Q_конв рассчитываются независимо и суммируются в PowerUp.

### 6.5 Расчёт средней температуры и обратки

T_средняя рассчитывается по стержневой теории ребра (штрибе — теория стержня):

1. **Термические сопротивления:**
   - RFb = R_над + 1/α (сопротивление теплопередаче вверх)
   - RD = R_под (сопротивление теплопередаче вниз, адиабата)

2. **Параметр ребра:**
   ```
   m = 0.6 × √[(1/RFb + 1/RD) / (λE × d_нар)]
   ```

3. **КПД ребра:**
   ```
   ηR = tanh(m × s/2) / (m × s/2)
   ```

4. **Избыточная температура JHmü** и **T_средняя**:
   ```
   T_средняя = JHmü + t_H    [°C]
   ```

Далее, по заданной T_подачи:
```
T_обратки = 2 × T_средняя − T_подачи    [°C]
ΔT = T_подачи − T_обратки                [K]
```

### 6.6 Расчёт расхода G

```
G_удельный = PowerUp / (c_p / 3.6) / ΔT    [кг/(ч·м²)]
V_dot_удельный = G_удельный / ρ × 1000      [л/(ч·м²)]
V_dot_суммарный = V_dot_удельный × A        [л/ч]
```

Где:
- PowerUp — удельная тепловая мощность, Вт/м²
- A — обогреваемая площадь, м²
- c_p — удельная теплоёмкость теплоносителя, кДж/(кг·К)
- ρ — плотность теплоносителя, кг/м³
- ΔT — перепад температур, K

### 6.7 Проверки (зашиты в коде)

- T_подачи ≥ T_средняя (иначе расчёт некорректен)
- ΔT ≤ MaxDeltaT (30 K, константа `ValidationConstants.MaxDeltaT`)
- T_обратки ≥ T_замерзания раствора гликоля (предупреждение)
- **Отсутствует:** проверка T_обратки ≥ 0 °C (см. `docs/Планируемые_изменения.md`, п.1)
- **Отсутствует:** проверка T_замерзания < t_cold_days_098 (см. `docs/Планируемые_изменения.md`, п.3)

## 7. Шаг 4 — Гидравлический расчёт и балансировка

### 7.1 Параметры теплоносителя

Свойства гликолевого раствора (ρ, c_p, ν) определяются билинейной интерполяцией по данным ASHRAE из файла `data/glycol_data.json`:

- **Плотность ρ** — кг/м³ (зависит от температуры и концентрации)
- **Удельная теплоёмкость c_p** — кДж/(кг·К)
- **Кинематическая вязкость ν** — мм²/с

Поддерживаются оба типа гликоля: этиленгликоль и пропиленгликоль.

### 7.2 Расчёт контуров

Для каждого контура программа рассчитывает:

#### 7.2.1 Мощность контура Q_HK

```
Q_HK = (L_HK / (100 / VA) + L_Zul / (100 / VA_Zul) × (q_Zul / 100)) × (q_o + q_u)    [Вт]
```

Где:
- L_HK — длина контура, м
- VA — шаг укладки, см
- L_Zul — длина подводки, м
- VA_Zul — шаг подводки, см
- q_Zul — коэффициент подводки (10 % если изолирована, иначе 100 %)
- q_o — тепловой поток вверх, Вт/м²
- q_u — тепловой поток вниз, Вт/м²

#### 7.2.2 Расход V_dot

```
V_dot = Q_HK × 3.6 / (ρ × c_p × ΔT)    [л/ч]
```

#### 7.2.3 Скорость v

```
v = (V_dot / 3600) / (π × d_i² / 4)    [м/с]
```

#### 7.2.4 Число Рейнольдса Re

```
Re = v × d_i / ν
```

Где ν — кинематическая вязкость, м²/с.

#### 7.2.5 Коэффициент трения λ

Определяется по режиму течения:

| Re | Режим | Формула |
|----|-------|---------|
| Re < 2 300 | Ламинарный | λ = 64 / Re (Пуазейль) |
| 2 300 ≤ Re ≤ 4 000 | Переходный | Линейная интерполяция между λ_lam(Re=2300) и λ_turb(Re=4000) |
| Re > 4 000 | Турбулентный | Колбрук-Уайт: `1/√λ = −2 × lg(k / (3.71 × d_i) + 2.51 / (Re × √λ))` |

Шероховатость k = 0.007 мм (PE-X).

#### 7.2.6 Удельные потери R

```
R = 10000 × v² × ρ × λ / (2 × d_i) × 100    [Па/м]
```

#### 7.2.7 Потери в трубе DpRohr

```
DpRohr = (L_HK + L_Zul) × R    [Па]
```

#### 7.2.8 Потери в распределителе DpVerteiler и вентиле DpVent

Формулы **различаются** для разных типов коллекторов:

**HKV-D:**
```
DpVerteiler = (V_dot / 1000 / 1.2)² × 100 000 × ρ    [Па]
DpVent      = 15 000 × (ρ / 2) × v²                   [Па]
```

**IV 1¼" и IV 1½":**
```
DpVerteiler = 15 000 × (ρ / 2) × v²                   [Па]
DpVent      = (V_dot / 1000 / Kv)² × 100 000 × ρ      [Па]
```

#### 7.2.9 Суммарные потери контура DpGesamt

```
DpGesamt = DpRohr + DpVerteiler + DpVent    [Па]
```

#### 7.2.10 Ограничения

- **R** — удельные потери: проверка `R ≤ 300 Па/м` (предупреждение, не блокирует расчёт)
- **v** — скорость: `0.1 ≤ v ≤ 2.0 м/с` (`ValidationConstants.MinVelocity / MaxVelocity`). При нарушении — сообщение, расчёт не блокируется

### 7.3 Автоподбор коллектора

Тип коллектора выбирается автоматически по суммарному расходу на коллектор:

| Суммарный расход V_sum | Тип коллектора |
|------------------------|----------------|
| V_sum ≤ 1.5 м³/ч | **HKV-D** |
| 1.5 < V_sum ≤ 2.5 м³/ч | **IV 1¼"** |
| 2.5 < V_sum ≤ 7.0 м³/ч | **IV 1½"** |
| V_sum > 7.0 м³/ч | Ошибка — превышение пропускной способности |

Дополнительное условие: суммарные потери на коллектор (DpGesamt самого нагруженного контура + Dp коллектора) **не должны превышать 320 мбар** (32 000 Па).

### 7.4 Балансировка

#### 7.4.1 Расчёт дросселирования

Для каждого контура:
```
Δp_макс = Δp_самого_нагруженного_контура
Δp_дроссель = Δp_макс − DpRohr − DpVent    (для HKV-D)
Δp_дроссель = Δp_макс − DpRohr − DpVerteiler  (для IV)
```

**Разная логика для HKV-D и IV!**
- HKV-D: из максимальных потерь вычитаются DpRohr и DpVent (DpVerteiler не дросселируется)
- IV: из максимальных потерь вычитаются DpRohr и DpVerteiler (DpVent не дросселируется)

#### 7.4.2 Расчёт Kv

```
Kv = (V_dot / 1000) / √(Δp_дроссель / 100 000 / ρ)    [м³/ч]
```

Внимание: единицы измерения — V_dot в л/ч, Δp в Па, ρ в г/см³.

#### 7.4.3 Расчёт оборотов вентиля

Для каждого типа коллектора — своя эмпирическая формула:

| Тип | Формула | Характер |
|-----|---------|----------|
| **IV 1½"** | `обороты = 5.122 × Kv − 0.2106` | Линейная |
| **IV 1¼"** | `обороты = 5.1818 × Kv − 0.23` | Линейная |
| **HKV-D** | `обороты = 4.2111 × Kv³ − 6.7436 × Kv² + 4.6613 × Kv − 0.712` | Кубическая |

Рекомендации:
- HKV-D: Kv рекомендуется в диапазоне 0.8–4.0 м³/ч
- Отрицательное количество оборотов — проверьте правильность расхода
- Результат округляется до 0.1 оборота
