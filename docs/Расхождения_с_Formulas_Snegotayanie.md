# Расхождения с docs/Formulas_Snegotayanie.md

**Дата:** 2026-06-02  
**Источник:** Сверка кода `SnowMeltingCalculator` с документом `docs/Formulas_Snegotayanie.md`

---

В процессе разработки выявлены расхождения между текущей реализацией и документом `docs/Formulas_Snegotayanie.md`. **Актуальными являются формулы из кода программы.**

| № | Пункт | В `Formulas_Snegotayanie.md` | Факт в коде |
|---|-------|-----------------------------|-------------|
| 1 | Q_изл | Входит в q_FB_ref | Рассчитывается отдельно, **не включён** в PowerUp |
| 2 | ΔT | Пользователь выбирает 10–15 K | Жёстко зашит **15.0 K** в `BuildThermalParameters()` (см. `docs/Планируемые_изменения.md` п.2) |
| 3 | T_воздуха | −50…+10 °C | −50…+10 °C (совпадает) |
| 4 | T_подачи: макс 50 °C для бетона | Ограничение 50 °C | Не реализовано |
| 5 | Проверка замерзания гликоля | T_зам < t_cold_days_098 | Не реализовано |
| 6 | Макс. длина контура | 120 м для Ø20 | Не реализовано |
| 7 | Скорость 0.15–1.0 м/с | Рекомендация | Валидация есть: 0.1–2.0 м/с (`ValidationConstants`) |
| 8 | DpVerteiler / DpVent | Разные для HKV-D и IV | Совпадает с документацией |
| 9 | Балансировка | Описана поверхностно | Реализована полностью, разная для HKV-D и IV |
| 10 | Обороты вентиля | Не описаны | 3 формулы (HKV-D, IV 1¼", IV 1½") |
| 11 | Тепловой расчёт (ядро) | Совпадает | Совпадает |
| 12 | Гидравлика (λ, Re, R, Kv) | Совпадает | Совпадает |
| 13 | Концентрация гликоля по умолчанию | Не указана | В `HydraulicInputData.cs` по умолчанию **этиленгликоль 50%** (а не пропилен 40%) |

---

**Приоритет:** Исходный код программы является истиной.
