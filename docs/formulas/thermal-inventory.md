## Notes

- `NotCalculatedDefault` means the value remains the C# default of the `ThermalCalculationResult` property (0, 0.0, false, empty array) because the early-return branch executed before that field was assigned.
- `TH-B-007D` is the repeated `PowerUp = MeltingHeat + ConvectionHeat` assignment that re-derives the same `PowerUp` value computed by `CalculatePowerUp`; this ensures the result object’s components sum to its total upward power.
- `TH-F-006` lists the ephemeral intermediates `jhmuLow`, `A`, `B`, `C`, `D`, `E`, `numerator`, and `denominator` as required by the inherited critical finding.
- `TH-B-004A` is the small-`x` branch (`Math.Abs(x) < 0.001`) where `etaR` is set to `1.0` without calling `Math.Tanh`.
- `TH-B-007C` is the invalid supply temperature early-return branch: if `SupplyTemperature <= MeanTemperature`, the calculation stops and `ReturnTemperature`, `DeltaT`, `MeltingHeat`, `RadiationHeat`, `ConvectionHeat`, `PowerDown`, `PowerTotal`, `MassFlowRate`, and `VolumeFlowRate` remain `NotCalculatedDefault`.
- `TH-B-007E` is the negative `PowerDown` early-return branch: if `PowerDown < 0`, `PowerTotal`, `MassFlowRate`, and `VolumeFlowRate` remain `NotCalculatedDefault`.
- `TH-B-007F` maps any unhandled exception inside `Calculate` to `IsValid=false` with a message, leaving whatever fields were already assigned and the rest as defaults.
- The known discrepancy for `TH-F-002`: the external formula document shows `h/(3600*10)` while the implementation uses `snowfallIntensity / 1000 / 3600`, which is mathematically equivalent (`1/3600000`). The inventory records this as a notation difference, not a behavioral discrepancy.
