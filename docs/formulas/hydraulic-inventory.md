## Notes

- Re=2300 maps to transitional in FlowRegimeCalculator.DetermineFlowRegime (FR-F-002B) and IsTransitional (FR-F-003B); Re=4000 also maps to transitional (FR-F-002B, FR-F-003B). Re < 2300 is laminar; Re > 4000 is turbulent.
- Colebrook-White turbulent friction (FR-F-006B) uses a Blasius initial guess, then iterates up to 20 times with a 1e-10 stop condition; if it does not converge the last lambda is returned.
- ValveType.IV_1_5 (IV 1 1/2 inch) is covered by VT-F-004A, VT-F-009A, VT-F-005, VT-F-006, VT-F-008A, and CIR-B-003H.
- Water branch is GLY-F-006, entered when concentration == 0; it uses water-specific property tables (GLY-F-007A..D) and is restricted to 0..100°C.
- Propylene glycol is covered by GLY-F-011B and GLY-F-017C / GLY-F-018E..H fallback matrices; the same bilinear interpolation (GLY-F-012E) applies.
- Exact grid point branch (GLY-F-012B) returns values[cLow, tLow] without interpolation when concentration and temperature both match grid coordinates.
- Empty collector branches (CIR-F-006A, CIR-F-006B) return a CollectorSummary with zeroed totals and the supplied collector number.
- Reference balancing branch (CIR-F-005E) sets the reference circuit throttling to 0 and valve turns to max turns; non-reference circuits receive a throttling pressure and a recalculated Kv/turns (CIR-F-005F..I).
- DpVent is intentionally not recalculated after balancing (CIR-F-005J), so it continues to represent the fully-open valve loss.
- All persistence classifications are drawn from: Persisted, ComputedProperty, Ephemeral, NotCalculatedDefault, Unavailable.
- No blank required fields (Formula ID, Surface ID, Owner symbol, Branch/precondition, Inputs+units, Constants/source, Implemented expression, Output+unit, Persistence classification+path, Failure/default behavior, Source path:lines, Docs reference) remain.
