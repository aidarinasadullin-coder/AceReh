## 1. Физический смысл коэффициента Kv

### 1.1 Определение

**Kv (Kvs)** — коэффициент пропускной способности клапана, численно равный объёмному расходу воды (плотность 1000 кг/м³) в м³/ч, который проходит через клапан при перепаде давления 1 бар.

```
Kv = Q / √(Δp / ρ)
```

Где:
- **Q** — объёмный расход, м³/ч
- **Δp** — перепад давления, бар
- **ρ** — плотность жидкости, г/см³ (или кг/дм³)

### 1.2 Физический смысл параметров

| Параметр | Обозначение | Единица | Физический смысл |
|----------|-------------|---------|------------------|
| Kv | — | м³/ч | Пропускная способность клапана при Δp = 1 бар |
| Q | Расход | м³/ч | Объём жидкости, проходящий через сечение за 1 час |
| Δp | Перепад давления | бар | Разность давлений до и после клапана |
| ρ | Плотность | г/см³ | Масса единицы объёма жидкости |

### 1.3 Размерность

Проверка размерности классической формулы:

```
Kv = Q / √(Δp / ρ)

[м³/ч] = [м³/ч] / √([бар] / [г/см³])
[м³/ч] = [м³/ч] / √([бар] × [см³/г])
[м³/ч] = [м³/ч] / √([бар × см³/г])
```

При ρ = 1 г/см³ (вода):
```
Kv = Q / √Δp
[м³/ч] = [м³/ч] / √[бар]
```

## 2. Классическая формула расчёта Kv

### 2.1 Основная формула (DIN EN 60534)

```
         Q
Kv = ─────────
     √(Δp / ρ)
```

### 2.2 Формула с единицами измерения калькулятора РЕХАУ

В калькуляторе используются следующие единицы:
- Q в **л/ч** (литры в час)
- Δp в **Па** (паскали)
- ρ в **г/см³** (граммы на кубический сантиметр)

**Формула:**

```
              Q [л/ч] / 1000
Kv [м³/ч] = ─────────────────────────
            √(Δp [Па] / 100000 / ρ [г/см³])
```

Или в развёрнутом виде:

```
              Q
Kv = ─────────────────────
     1000 × √(Δp / 100000 / ρ)
```

### 2.3 Вывод формулы

Исходная формула (DIN):
```
Kv = Q / √(Δp / ρ)
```

Где Q в м³/ч, Δp в бар, ρ в г/см³.

Перевод единиц:
- Q [м³/ч] = Q [л/ч] / 1000
- Δp [бар] = Δp [Па] / 100000

Подстановка:
```
Kv = (Q [л/ч] / 1000) / √((Δp [Па] / 100000) / ρ [г/см³])
```

## 3. Пошаговый пример расчёта

### 3.1 Исходные данные

| Параметр | Значение | Единица | Примечание |
|----------|----------|---------|------------|
| Расход Q | 278.2 | л/ч | Из теплового расчёта |
| Дросселирование Δp | 9580 | Па | zu_drosseln — потери, которые нужно дросселировать |
| Плотность ρ | 1086.4 | кг/м³ | 50% пропиленгликоль при низкой температуре |
| Плотность ρ | 1.0864 | г/см³ | То же значение в других единицах |
| Тип клапана | HKV-D | — | Бытовой коллектор РЕХАУ |

### 3.2 Шаг 1: Перевод единиц

```
Q = 278.2 л/ч = 278.2 / 1000 = 0.2782 м³/ч
Δp = 9580 Па = 9580 / 100000 = 0.0958 бар
ρ = 1086.4 кг/м³ = 1086.4 / 1000 = 1.0864 г/см³
```

### 3.3 Шаг 2: Вычисление подкоренного выражения

```
Δp / ρ = 0.0958 / 1.0864 = 0.0882 бар × см³/г
```

### 3.4 Шаг 3: Извлечение квадратного корня

```
√(Δp / ρ) = √0.0882 = 0.297
```

### 3.5 Шаг 4: Вычисление Kv

```
Kv = Q / √(Δp / ρ)
Kv = 0.2782 / 0.297
Kv = 0.9369 м³/ч
```

### 3.6 Шаг 5: Расчёт оборотов балансировочного клапана

Для клапана HKV-D используется эмпирическая формула:

```
umdreh1 = 4.2111 × Kv³ - 6.7436 × Kv² + 4.6613 × Kv - 0.712
```

Подстановка:
```
umdreh1 = 4.2111 × 0.9369³ - 6.7436 × 0.9369² + 4.6613 × 0.9369 - 0.712
umdreh1 = 4.2111 × 0.822 - 6.7436 × 0.878 + 4.6613 × 0.9369 - 0.712
umdreh1 = 3.462 - 5.921 + 4.367 - 0.712
umdreh1 = 1.25 оборота
```

**Результат:** 1.25 оборота = 1¼ оборота

## 4. Типичная ошибка: неверный перевод единиц

### 4.1 Ошибочный расчёт

**Ошибка:** Использование плотности в кг/м³ без перевода в г/см³.

```
❌ НЕПРАВИЛЬНО:
Kv = Q / √(Δp / ρ)

Где:
- Q = 0.2782 м³/ч
- Δp = 9580 Па = 0.0958 бар
- ρ = 1086.4 кг/м³  ← ОШИБКА: плотность в кг/м³

Kv = 0.2782 / √(0.0958 / 1086.4)
Kv = 0.2782 / √0.0000882
Kv = 0.2782 / 0.00939
Kv = 29.6 м³/ч  ← ЯВНО НЕПРАВИЛЬНЫЙ РЕЗУЛЬТАТ
```

### 4.2 Другой вариант ошибки

**Ошибка:** Деление расхода на плотность.

```
❌ НЕПРАВИЛЬНО:
Kv = (Q / ρ) / √(Δp / ρ)

Где:
- Q = 278.2 л/ч
- ρ = 1086.4 кг/м³
- Δp = 9580 Па

Q / ρ = 278.2 / 1086.4 = 0.256 л·м³/(кг·ч)  ← БЕССМЫСЛЕННАЯ РАЗМЕРНОСТЬ
```

### 4.3 Правильный подход

```
✅ ПРАВИЛЬНО:
Kv = Q / √(Δp / ρ)

Где:
- Q = 278.2 л/ч = 0.2782 м³/ч
- Δp = 9580 Па = 0.0958 бар
- ρ = 1086.4 кг/м³ = 1.0864 г/см³  ← ПРАВИЛЬНЫЙ ПЕРЕВОД

Kv = 0.2782 / √(0.0958 / 1.0864)
Kv = 0.2782 / √0.0882
Kv = 0.2782 / 0.297
Kv = 0.9369 м³/ч  ← ПРАВИЛЬНЫЙ РЕЗУЛЬТАТ
```

## 6. Проверка размерностей

### 6.1 Классическая формула

```
Kv = Q / √(Δp / ρ)

Размерности:
- Q: [м³/ч]
- Δp: [бар] = [10⁵ Па] = [10⁵ кг/(м·с²)]
- ρ: [г/см³] = [кг/дм³] = [10³ кг/м³]

Δp / ρ:
[10⁵ кг/(м·с²)] / [10³ кг/м³] = [10² м²/с²]

√(Δp / ρ):
√[10² м²/с²] = [10 м/с]

Kv:
[м³/ч] / [10 м/с] = [м³/ч] × [с/10 м] = [м²·с/(ч·10)]

При учёте, что 1 ч = 3600 с:
[м²·с/(3600 с·10 м)] = [м/36000]

Это не совсем очевидно, поэтому лучше использовать практический подход.
```

### 6.2 Практическая проверка

Для воды (ρ = 1 г/см³) при Δp = 1 бар:

```
Kv = Q / √(1 / 1) = Q / 1 = Q

То есть Kv численно равен расходу воды при перепаде 1 бар.
```

**Пример:**
- Клапан с Kv = 1.2 м³/ч пропускает 1.2 м³/ч воды при Δp = 1 бар
- Клапан с Kv = 1.2 м³/ч пропускает 0.6 м³/ч воды при Δp = 4 бар (Kv = Q/√4 = Q/2)

## 8. Частые ошибки

### 8.1 Ошибка №1: Неправильные единицы плотности

**Проблема:** Использование плотности в кг/м³ вместо г/см³.

**Решение:** Всегда переводить плотность:
```
ρ [г/см³] = ρ [кг/м³] / 1000
```

### 8.2 Ошибка №2: Неправильные единицы давления

**Проблема:** Использование давления в Па вместо бар.

**Решение:** Всегда переводить давление:
```
Δp [бар] = Δp [Па] / 100000
```

### 8.3 Ошибка №3: Неправильные единицы расхода

**Проблема:** Использование расхода в л/ч вместо м³/ч.

**Решение:** Всегда переводить расход:
```
Q [м³/ч] = Q [л/ч] / 1000
```

### 8.4 Ошибка №4: Деление расхода на плотность

**Проблема:** Попытка "нормализовать" расход делением на плотность.

**Решение:** Плотность используется только под корнем:
```
✅ Kv = Q / √(Δp / ρ)
❌ Kv = (Q / ρ) / √(Δp / ρ)
```

### 8.5 Ошибка №5: Забытый множитель 100000

**Проблема:** Использование Δp в Па без перевода в бар.

**Решение:** Добавить множитель 100000:
```
✅ Kv = Q / √(Δp / 100000 / ρ)
❌ Kv = Q / √(Δp / ρ)  при Δp в Па
```

## 10. Резюме

### 10.1 Ключевые правила

1. **Всегда проверяйте единицы измерения:**
   - Q → м³/ч (делить на 1000)
   - Δp → бар (делить на 100000)
   - ρ → г/см³ (делить на 1000)

2. **Используйте правильную формулу:**
   ```
   Kv = Q / √(Δp / ρ)
   ```

3. **Не делите расход на плотность:**
   ```
   ❌ Kv = (Q / ρ) / √(Δp / ρ)
   ✅ Kv = Q / √(Δp / ρ)
   ```

4. **Проверяйте результат:**
   - Kv для балансировочных клапанов обычно в диапазоне 0.5–2.0 м³/ч
   - Если Kv > 10 или Kv < 0.1 — ошибка в расчётах

### 10.2 Контрольные вопросы

1. Какой Kv получится при расходе 100 л/ч, Δp = 5000 Па, ρ = 1053 кг/м³?
   
   **Ответ:**
   ```
   Q = 0.1 м³/ч
   Δp = 0.05 бар
   ρ = 1.053 г/см³
   
   Kv = 0.1 / √(0.05 / 1.053)
   Kv = 0.1 / √0.0475
   Kv = 0.1 / 0.218
   Kv = 0.459 м³/ч
   ```

2. Какой Kv получится при расходе 500 л/ч, Δp = 20000 Па, ρ = 1000 кг/м³ (вода)?
   
   **Ответ:**
   ```
   Q = 0.5 м³/ч
   Δp = 0.2 бар
   ρ = 1.0 г/см³
   
   Kv = 0.5 / √(0.2 / 1.0)
   Kv = 0.5 / √0.2
   Kv = 0.5 / 0.447
   Kv = 1.118 м³/ч
   ```
