## 1. ВХОДНЫЕ ДАННЫЕ

### 1.1 Климатические параметры
| Параметр | Обозначение | Ед. изм. | Источник |
|----------|-------------|----------|----------|
| Температура наружного воздуха | t_H (Ji) | °C | climate_db.json (t_5days_092) |
| Температура грунта (снизу) | t_G (Ju) | °C | По заданию (дефолт +10°C) |
| Скорость ветра | v_H | м/с | climate_db.json (wind_avg_t_le_8) — средняя за отопительный период |
| Влажность воздуха | φ | % | climate_db.json (humidity_15h_cold) — информационно, не используется в расчётах |
| Интенсивность снегопада | h | мм/ч | Ручной ввод (водяной эквивалент) |

**Примечание:** Влажность воздуха не входит в формулы расчёта систем снеготаяния РЕХАУ. Параметр `humidity_15h_cold` (влажность в 15 часов холодного периода) отображается в интерфейсе информационно и не используется в расчётах.

### 1.2 Конструкция ("Пирог")
Слои над трубой (R1) и под трубой (R2):
- Материал
- Толщина d (мм)
- Теплопроводность λ (Вт/м·К)
- Термическое сопротивление R = d / λ / 1000 (м²·К/Вт)

**Учёт грунтовых вод:**
- Если уровень грунтовых вод < 1 м от трубы — для материалов под трубой принимаются характеристики λБ (влажные условия)
- В остальных случаях — λА (нормальные условия)

**Ограничения по материалам:**
- Бетон — максимальная температура подачи 50°C
- При температуре наружного воздуха -15°C и ниже — асфальт не применяется

**Минимальная толщина стяжки над трубой:**
- Без нагрузок — не менее 40 мм
- При нагрузках — не менее 50 мм

### 1.3 Параметры трубы РЕХАУ
| Тип трубы | d (мм) | s (мм) | λR (Вт/м·К) |
|-----------|--------|--------|-------------|
| RAUTHERM S 17x2,0 | 17 | 2,0 | 0,35 |
| RAUTHERM S 20x2,0 | 20 | 2,0 | 0,35 |
| RAUTHERM S 25x2,3 | 25 | 2,3 | 0,35 |

**Полный перечень продукции:** `data/rehau_products.json` (трубы, коллекторы, фитинги)

### 1.4 Режимы работы (целевая температура поверхности t_П)
| Режим | t_П (°C) |
|-------|----------|
| Антиобледенение | +3 |
| Таяние | +5 |
| Интенсивное | +7 |

### 1.5 Температурный перепад (ΔT)
- Рекомендуемый диапазон: 10–15 К
- Оптимальное значение: 15 К

### 1.6 Выбор мощности по климатическому региону
| Температура холодной пятидневки | Расчётная колонка |
|--------------------------------|-------------------|
| -27°C и выше | -10°C |
| от -27°C до -37°C | -15°C |
| -37°C и ниже | -20°C |
| Повышенные требования | -20°C |

## 2. КОЭФФИЦИЕНТ ТЕПЛООТДАЧИ НА ПОВЕРХНОСТИ α

### Формула (конвекция + излучение):
```
α = 2,26 × (t_П - t_H)^0,33 + 2,6 × v_H    [Вт/м²·К]
```

Где:
- t_П — требуемая температура поверхности (°C)
- t_H — температура наружного воздуха (°C)
- v_H — скорость ветра (м/с)

**Примечание:** Для расчёта вниз α_низ ≈ 999999999 (адиабата, нет потерь)

---

## 3. ТРЕБУЕМАЯ МОЩНОСТЬ ВВЕРХ (geforderte Leistung nach oben)

### Суммарная удельная мощность:
```
q_FB = Q_таяние + Q_конв    [Вт/м²]
```

### Справочная формула (для сравнения):
```
q_FB_ref = Q_таяние + Q_изл + Q_конв    [Вт/м²] — справочно, с учётом излучения
```

### 3.1 Теплота плавления (таяния) снега:
```
Q_таяние = (h / (3600×10)) × 900 × [2100 × (0 - t_H) + 330000 + 4200 × (t_П - 0)]
```

Где:
- h — интенсивность снегопада (мм/ч), водяной эквивалент
- 900 — плотность снега (кг/м³)
- 2100 — уд. теплоёмкость льда (Дж/кг·К)
- 330000 — уд. теплота плавления льда (Дж/кг)
- 4200 — уд. теплоёмкость воды (Дж/кг·К)
- t_H — температура наружного воздуха (°C)
- t_П — температура поверхности (°C)

**Примечание:**  3600×10 = 1000 (мм→м) × 3600 (ч→с)

### 3.2 Лучистый тепловой поток (излучение):
```
Q_изл = 0,055 × 5,77 × [(273 + t_П) / 100]^4    [Вт/м²]
```

Где:
- 5,77 — постоянная Стефана-Больцмана × 100^4
- 0,055 — коэффициент излучения (условный)

### 3.3 Конвективный тепловой поток:
```
Q_конв = α × (t_П - t_H) × 1    [Вт/м²]
```

Где α — коэффициент теплоотдачи из раздела 2.

---

## 4. ТЕПЛОВОЕ СОПРОТИВЛЕНИЕ КОНСТРУКЦИИ

### 4.1 Суммарное сопротивление слоёв над трубой (R1):
```
R1_total = Σ(R_i) = Σ(d_i / λ_i / 1000)    [м²·К/Вт]
```

### 4.2 Суммарное сопротивление слоёв под трубой (R2):
```
R2_total = Σ(R_i)    [м²·К/Вт]
```

### 4.3 Полное сопротивление вверх (с учётом α):
```
RFb = R1_total + 1 / α_верх    [м²·К/Вт]
```

### 4.4 Полное сопротивление вниз (с учётом α):
```
RD = R2_total + 1 / α_низ    [м²·К/Вт]
```

---

## 5. РАСЧЁТ ПО ТЕОРИИ СТЕРЖНЯ (Stabtheorie / Chapman-Katunich)

### 5.1 Параметр m:
```
m = fm × √[(1/RFb + 1/RD) / (λE × dE)]    [1/м]
```

Где:
- fm = 0,6 — коэффициент для мокрых систем
- λE — теплопроводность бетона (стяжки) вокруг трубы (Вт/м·К)
- dE — наружный диаметр трубы (м)

### 5.2 Коэффициент эффективности ребра ηR:

Шаг укладки трубы:
```
lR = Verlegeabstand / 1000    [м]
```

Аргумент:
```
x = m × lR / 2
```

Гиперболический тангенс (приближённая формула):
```
tanh(x) = 1 - 2 / (e^(2×x) + 1)
```

КПД ребра:
```
ηR = tanh(x) / x    [безразмерный]
```

### 5.3 Вспомогательные коэффициенты:
```
A = 1 / ηR
B = (1/RFb + 1/RD)
C = |t_H - t_G| = |Ji - Ju|    [К]
D = lR / (π × λR)
E = s / (d - s)
```

Где:
- λR — теплопроводность материала трубы (Вт/м·К)
- d — наружный диаметр трубы (м)
- s — толщина стенки трубы (м)

---

## 6. ИЗБЫТОЧНАЯ ТЕМПЕРАТУРА ТЕПЛОНОСИТЕЛЯ JHmü

### Основная формула (из Excel ROW115):
```
JHmü = [A + (B - C/(q_FB × RFb × RD)) × D × E] × q_FB × RFb    [°C]
```

Или развёрнутая форма:
```
JHmü = (1/ηR + ((1/RFb+1/RD) - |t_H-t_G|/(q_FB×RFb×RD)) × lR/(π×λR) × s/(d-s)) × q_FB × RFb
```

---

## 7. СРЕДНЯЯ ТЕМПЕРАТУРА ТЕПЛОНОСИТЕЛЯ

```
T_mean = JHmü + t_H    [°C]
```

---

## 8. ТЕМПЕРАТУРА ПОДАЧИ И ОБРАТКИ

### 8.1 Выбранная температура подачи:
```
T_supply = ввод пользователя
```
**Ограничения:**
- Для PE-Xa: макс. 65°C
- Для бетона: макс. 50°C

### 8.2 Температура обратки (арифметическая):
```
IF T_supply > T_mean THEN
    T_return = T_mean - (T_supply - T_mean)
ELSE
    Ошибка: "Температура подачи слишком мала"
END IF
```

### 8.3 Разность температур (Spreizung):
```
ΔT = T_supply - T_return    [К]
```

---

## 9. РАСХОД ТЕПЛОНОСИТЕЛЯ

### 9.1 Теплоотдача вниз (потери):
```
q_D = (JHmü_low × RFb + C × D × E) / (RFb × RD × (A + B × D × E))    [Вт/м²]
```

Где JHmü_low = T_mean - t_G

### 9.2 Суммарная мощность:
```
q_total = q_FB + q_D    [Вт/м²]
```

### 9.3 Массовый расход:
```
ṁ = q_total / (c_p / 3,6) / ΔT    [кг/(ч·м²)]
```

Где:
- c_p — удельная теплоёмкость теплоносителя (кДж/кг·К)
  - Вода: 4,18 кДж/кг·К
  - 50% гликоль: ~3,39 кДж/кг·К

### 9.4 Объёмный расход:
```
V_dot = ṁ / ρ × 1000    [л/(ч·м²)]
```

Где ρ — плотность теплоносителя (кг/м³)
- Вода: ~1000 кг/м³
- 50% гликоль: ~1053 кг/м³

---

## 10. ПРОВЕРКА РАСЧЁТА

### Удельная мощность вверх (проверка):
```
q_check = (JHmü × RD + C × D × E) / (RFb × RD × (A + B × D × E))
```

Должно выполняться: q_check ≈ q_FB

---

## 11. ГИДРАВЛИЧЕСКИЙ РАСЧЁТ

### 11.1 Входные данные гидравлики

| Параметр | Обозначение | Ед. изм. | Источник |
|----------|-------------|----------|----------|
| Температура подачи | T_VL | °C | Из теплового расчёта |
| Температура обратки | T_RL | °C | Из теплового расчёта |
| Средняя температура | T_mean | °C | (T_VL + T_RL) / 2 |
| Плотность теплоносителя | ρ | кг/м³ | **data/glycol_data.json** (интерполяция) |
| Кинематическая вязкость | ν | мм²/с | **data/glycol_data.json** (интерполяция) |
| Уд. теплоёмкость | c_p | кДж/кг·К | **data/glycol_data.json** (интерполяция) |
| Шероховатость трубы (PE-Xa) | ε | мм | 0,007 |
| Трубы РЕХАУ | da, s, di | мм | **data/rehau_products.json** |

**Важно о единицах измерения:**

| Параметр | В базе данных | В формулах Excel | Примечание |
|----------|---------------|------------------|------------|
| Плотность ρ | кг/м³ (≈1053) | г/см³ (≈1,053) | Численно равны! |
| Вязкость ν | мм²/с | мм²/с | Совпадают |
| Диаметр d | мм | мм | В формулах с множителями |

**Примечание:** В формулах раздела 11.8 используется ρ в г/см³. Для конвертации:
```
ρ[г/см³] = ρ[кг/м³] / 1000
ρ[кг/м³] = ρ[г/см³] × 1000

Пример: ρ = 1053 кг/м³ = 1,053 г/см³
```

### 11.2 Длина контура:
```
L_HK = S × 1000 / lR    [м] — длина греющего контура
L_Zul = ввод пользователя    [м] — длина подводки (подающая + обратная)
L_total = L_HK + L_Zul    [м] — полная длина
```

### 11.3 Мощность контура:
```
Q_HK = [(L_HK / (100 / VAHK)) + (L_Zul / (100 / VAZul)) × (qZul / 100)] × (q_o + q_u)    [Вт]
```

**Единицы измерения:**
| Параметр | Обозначение | Единица | Примечание |
|----------|-------------|---------|------------|
| Длина контура | L_HK | м | Длина греющего контура |
| Длина подводки | L_Zul | м | Подающая + обратная |
| Шаг укладки | VAHK | см | 15, 20, 25 или 30 см |
| Шаг подводки | VAZul | см | Обычно 5 см |
| Доля тепла подводки | qZul | % | Обычно 10%
| Мощность вверх | q_o | Вт/м²| Из теплового расчёта |
| Мощность вниз | q_u | Вт/м² | Из теплового расчёта |

**Вывод формулы:**
```
Q_HK = S_эфф × (q_o + q_u)

Где S_эфф — эффективная площадь:
S_эфф = L_HK × (VAHK/100) + L_Zul × (VAZul/100) × (qZul/100)

Пояснение:
- (VAHK/100) — шаг в метрах, площадь на 1 м трубы = шаг(м)
- (qZul/100) — учитывает теплоизоляцию подводок (10% тепла)
```

**Пример расчёта:**
```
Дано: L_HK = 100 м, L_Zul = 20 м, VAHK = 20 см, VAZul = 5 см
qZul = 10%, q_o = 256 Вт/м², q_u = 5 Вт/м²

S_контур = L_HK / (100 / VAHK) = 100 / (100/20) = 100 / 5 = 20 м²
S_подводка = L_Zul / (100 / VAZul) × (qZul/100) = 20 / (100/5) × 0,1 = 20/20 × 0,1 = 0,1 м²

S_эфф = 20 + 0,1 = 20,1 м²

Q_HK = S_эфф × (q_o + q_u) = 20,1 × (256 + 5) = 20,1 × 261 = 5246 Вт
```

### 11.4 Расход теплоносителя:
```
V_dot = Q_HK × 3,6 / (ρ × c_p × ΔT)    [л/ч]
```

**Единицы измерения:**
| Параметр | Обозначение | Единица | Примечание |
|----------|-------------|---------|------------|
| Мощность | Q_HK | Вт | Из раздела 11.3 |
| Плотность | ρ | кг/м³ | Из glycol_data.json |
| Теплоёмкость | c_p | кДж/(кг·К) | Из glycol_data.json |
| Температурный перепад | ΔT | К | T_VL - T_RL |

**Пример расчёта:**
```
Дано: Q_HK = 5246 Вт, ρ = 1053 кг/м³, c_p = 3,21 кДж/(кг·К), ΔT = 10 К

V_dot = 5246 × 3,6 / (1053 × 3,21 × 10)
V_dot = 18886 / 33801
V_dot = 0,56 м³/ч = 560 л/ч
```

### 11.5 Скорость потока:
```
v = V_dot × 4 / (3600 × π × d_inner²) × 10⁶    [м/с]
```

Или equivalently:
```
v = V_dot / (3600 × π × d_inner² / 4 / 10⁶)    [м/с]
```

**Единицы измерения:**
| Параметр | Обозначение | Единица | Примечание |
|----------|-------------|---------|------------|
| Расход | V_dot | л/ч | Объёмный расход |
| Внутренний диаметр | d_inner | мм | D_ext - 2 × s |
| Скорость | v | м/с | Результат |

**Пример расчёта:**
```
Дано: V_dot = 280 л/ч, d_inner = 13 мм (труба 17×2,0)
v = 280 × 4 / (3600 × π × 13²) × 10⁶
v = 280 × 4 / (3600 × 3,14159 × 169) × 10⁶
v = 0,59 м/с
```

**Ограничения:** 0,15 – 1,0 м/с (рекомендуется 0,3 – 0,8 м/с)

### 11.6 Число Рейнольдса:
```
Re = 1000 × v × d_inner / ν    [безразмерный]
```

**Единицы измерения:**
| Параметр | Обозначение | Единица | Примечание |
|----------|-------------|---------|------------|
| Скорость | v | м/с | Из раздела 11.5 |
| Внутренний диаметр | d_inner | мм | D_ext - 2 × s |
| Кинематическая вязкость | ν | мм²/с | Из glycol_data.json |

**Вывод формулы:**
```
Re = v × d / ν

В единицах СИ:
Re = v[м/с] × d[м] / ν[м²/с]
Re = v × (d/1000) / (ν × 10⁻⁶)
Re = v × d × 1000 / ν    [при d в мм, ν в мм²/с]
```

**Пример расчёта:**
```
Дано: v = 0,59 м/с, d_inner = 13 мм, ν = 2,16 мм²/с (50% гликоль при 40°C)
Re = 1000 × 0,59 × 13 / 2,16
Re = 7670 / 2,16
Re = 3551
```

### 11.7 Коэффициент гидравлического трения λ:

**В зависимости от режима движения:**

| Режим | Условие | Формула λ |
|-------|---------|-----------|
| Ламинарный | Re < 2300 | λ = 64 / Re (формула Пуазейля) |
| Переходный | 2300 ≤ Re ≤ 4000 | Линейная интерполяция |
| Турбулентный | Re > 4000 | Colebrook-White |

**Формула Пуазейля (ламинарный режим):**
```
λ = 64 / Re
```

**Интерполяция (переходный режим):**
```
λ_lam = 64 / 2300 ≈ 0,0278
λ_turb = ColebrookWhite(Re=4000)
λ = λ_lam + (Re - 2300) / (4000 - 2300) × (λ_turb - λ_lam)
```

**Формула Колбрука-Уайта (турбулентный режим):**
```
1 / √λ = -2 × lg(ε / (3,7 × d_inner) + 2,51 / (Re × √λ))
```

Где ε — эквивалентная шероховатость трубы (м)

*Примечание: Решается итерационно (обычно 5-10 итераций)*

### 11.8 Удельные потери давления:
```
R = 10000 × (v² × ρ × λ) / (2 × d_inner) × 100    [Па/м]
```

**Единицы измерения:**
| Параметр | Обозначение | Единица | Примечание |
|----------|-------------|---------|------------|
| Скорость | v | м/с | Из раздела 11.5 |
| Плотность | ρ | г/см³ | ~1,053 для 50% гликоля |
| Коэффициент трения | λ | безразмерный | Из раздела 11.7 |
| Внутренний диаметр | d_inner | мм | D_ext - 2 × s |

**Вывод формулы:**
```
R = (v² × ρ[кг/м³] × λ) / (2 × d[м])    [Па/м] — формула Дарси-Вейсбаха

При ρ в г/см³ (ρ[г/см³] = ρ[кг/м³] / 1000):
ρ[кг/м³] = ρ[г/см³] × 1000

При d в мм:
d[м] = d[мм] / 1000

Подстановка:
R = (v² × (ρ × 1000) × λ) / (2 × (d / 1000))
R = (v² × ρ × λ × 1000 × 1000) / (2 × d)
R = 1000000 × v² × ρ × λ / (2 × d)

В Excel используется форма:
R = 10000 × (v² × ρ × λ) / (2 × d_inner) × 100    [Па/м]

Где множители 10000 × 100 = 1000000 обеспечивают правильную размерность.
```

**Пример расчёта:**
```
Дано: v = 0,59 м/с, ρ = 1,053 г/см³, λ = 0,042, d_inner = 13 мм

Проверка в единицах СИ:
v² = 0,3481 м²/с²
ρ = 1053 кг/м³
d = 0,013 м

R = v² × ρ × λ / (2 × d)
R = 0,3481 × 1053 × 0,042 / (2 × 0,013)
R = 15,39 / 0,026
R = 592 Па/м

По формуле Excel:
R = 10000 × (0,59² × 1,053 × 0,042) / (2 × 13) × 100
R = 10000 × 0,01539 / 26 × 100
R = 10000 × 0,000592 × 100
R = 592 Па/м ✓
```

**Ограничение:** R ≤ 300 Па/м (рекомендуется)

Если R > 300 Па/м:
- Уменьшить длину контура, или
- Выбрать трубу большего диаметра (17 → 20 → 25 мм)
```

### 11.9 Потери давления в трубе:
```
DpRohr = L_total × R    [Па]
```

Где L_total — общая длина трубы (контур + подводка), м

### 11.10 Потери давления в распределителе и вентиле коллектора

**Важно:** Формулы различаются для бытовых (HKV-D) и промышленных (IV) коллекторов!

#### Для HKV-D (бытовой коллектор):

**Потери в распределителе:**
```
DpVerteiler = (V_dot / 1000 / 1,2)² × 100000 × ρ    [Па]
```
Где Kv = 1,2 м³/ч для HKV-D

**Потери в вентиле:**
```
DpVent = 15000 × (ρ / 2000) × v²    [Па]
```

#### Для IV 1¼" (промышленный коллектор):

**Потери в распределителе:**
```
DpVerteiler = 15000 × (ρ / 2000) × v²    [Па]
```

**Потери в вентиле:**
```
DpVent = (V_dot / 1000 / Kv)² × 100000 × ρ    [Па]
```
Где Kv = 1,45 м³/ч для IV 1¼"

#### Для IV 1½" (промышленный коллектор):

**Потери в распределителе:**
```
DpVerteiler = 15000 × (ρ / 2000) × v²    [Па]
```

**Потери в вентиле:**
```
DpVent = (V_dot / 1000 / Kv)² × 100000 × ρ    [Па]
```
Где Kv = 1,5 м³/ч для IV 1½"

**Единицы измерения:**
| Параметр | Обозначение | Единица | Примечание |
|----------|-------------|---------|------------|
| Расход | V_dot | л/ч | Объёмный расход контура |
| Скорость | v | м/с | Из раздела 11.5 |
| Плотность | ρ | г/см³ | ~1,053 для 50% гликоля |
| Kv | — | м³/ч | Коэффициент пропускной способности |

**Примечание:** Плотность ρ в формулах должна быть в г/см³. GlycolProperties.Density хранит плотность в кг/м³, требуется конвертация: ρ[г/см³] = ρ[кг/м³] / 1000

### 11.11 Суммарные потери давления контура:
```
DpGesamt = DpRohr + DpVerteiler + DpVent    [Па]
```

Где:
- DpRohr — потери в трубе контура и подводки, Па
- DpVerteiler — потери в распределителе коллектора, Па
- DpVent — потери в балансировочном вентиле, Па

### 11.12 Максимальные потери в коллекторе:
```
Dp_max = MAX(DpGesamt всех контуров коллектора)    [Па]
Dp_max_mbar = Dp_max / 100    [мбар]
```

Ограничение: Dp_max ≤ 320 мбар (по нормам РЕХАУ)

### 11.13 Выбор теплоносителя (гликоль):
- Концентрация пропиленгликоля/этиленгликоля выбирается пользователем
- Программа выдаёт ошибку, если температура замерзания (по таблицам ASHRAE) выше t_cold_days_098 (температура наиболее холодных суток с обеспеченностью 0.98)

## 12. РАСЧЁТ ПРИ ТЕМПЕРАТУРЕ ЗАПУСКА СИСТЕМЫ

### 12.1 Назначение:
Расчёт гидравлики при низкой температуре теплоносителя для подбора насоса.
При низких температурах вязкость гликоля значительно возрастает.

### 12.2 Выбор температуры запуска:
| Температура холодной пятидневки | Температура запуска |
|--------------------------------|---------------------|
| -27°C и выше | -10°C |
| от -27°C до -37°C | -15°C |
| -37°C и ниже | -20°C |
| Ручной ввод | задаётся пользователем |

### 12.3 Свойства теплоносителя при температуре запуска:
При температуре запуска используются другие значения:
- ν_cold — вязкость при низкой температуре
- ρ_cold — плотность при низкой температуре

### 12.4 Алгоритм расчёта для КАЖДОГО контура:

1. **Длина:** L_total = L_HK + L_Zul
2. **Расход:** V_dot (из теплового расчёта, не меняется)
3. **Скорость:** v = V_dot / (3600 × π × d_inner² / 4)
4. **Re при низкой T:** Re_cold = v × d_inner / ν_cold
5. **λ при низкой T:** по формулам раздела 11.7
6. **R при низкой T:** R_cold = (v² × ρ_cold × λ) / (2 × d_inner)
7. **DpRohr:** L_total × R_cold
8. **DpVerteiler, DpVent:** по формулам раздела 11.10 с ρ_cold
9. **DpGesamt:** DpRohr + DpVerteiler + DpVent

### 12.5 Максимальные потери в коллекторе:
```
Dp_max = MAX(DpGesamt всех контуров коллектора)    [Па]
Dp_max_mbar = Dp_max / 100    [мбар]
```

### 12.6 Пример влияния температуры:

| Параметр | При T_рабочей (41°C) | При T_запуска (-15°C) |
|----------|---------------------|----------------------|
| ν (вязкость) | 2,16 мм²/с | 18,17 мм²/с |
| ρ (плотность) | 1053 кг/м³ | 1085 кг/м³ |
| Re | ~4000 | ~475 |
| λ | 0,04 | 0,135 |
| R (Па/м) | ~190 | ~460 |
| Δp (мбар) | ~233 | ~308 |

## 14. СПРАВОЧНЫЕ ДАННЫЕ

### Теплопроводность материалов (λ, Вт/м·К):
- Бетон: 1,2 – 1,8
- Бетон на арматурной сетке: 1,6
- Асфальт: 0,7 – 1,0 (не применять при t_нар ≤ -15°C)
- Цементно-песчаная стяжка: 1,2 – 1,4
- Плитка керамическая: 1,0 – 1,5
- Плитка из камня: 2,5 – 3,5
- Песок: 0,4 – 0,6
- ЭППС (пенополистирол): 0,03 – 0,04
- Грунт: 1,0 – 2,0

**Примечание:** В текущей версии реализуется только расчёт с бетонной плитой.

### Свойства теплоносителя (гликоль):

**Источник данных:** `data/glycol_data.json` (ASHRAE Handbook - Fundamentals)

База содержит свойства этиленгликоля и пропиленгликоля для концентраций 10-90% и температур от -34°C до 104°C:
- Плотность ρ (кг/м³)
- Кинематическая вязкость ν (мм²/с)
- Удельная теплоёмкость c_p (кДж/кг·К)
- Теплопроводность λ (Вт/м·К)

**Интерполяция:** Значения интерполируются по температуре и концентрации.

**Дефолт:** 50% пропиленгликоль (типичный для систем снеготаяния).
