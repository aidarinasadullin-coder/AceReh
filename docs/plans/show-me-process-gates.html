3Где мы на шкале зрелости AI-SDLC

План закрывает уровень 3 инфраструктурно и готовит данные уровня 5 — не двигая ни одного human-гейта.

Уровень 1
Личный инструмент
агент пишет код, тесты, разбирается в кодовой базе
сейчас · 2+
Уровень 2
Командная среда
AGENTS.md, ADR, уроки, фазовый цикл, show-me — уже сильный
цель плана · 3
Уровень 3
AI внутри SDLC
CI-гейты, реестр правил, чеки — процесс проверяется машиной
Уровень 4
Агентные процессы
PR-циклы, автономное расследование — фундамент теперь есть
Уровень 5
Самоулучшение
чеки = данные «находок на фазу»; эвалы — следующим решением
Owner-гейты сохраняются полностью — CI и реестр стоят рядом с правилом «нет коммита без owner-ревью», а не вместо него: CI отвечает «соответствует ли код заявленному», владелец — «принимать ли результат». Продукт, .smc, state ownership, R1–R6, замороженное досье — без изменений.

Аппрув плана → сигнал «делай»
G2 · после фазы A
Branch protection «только зелёный в master» — настройка GitHub
G3 · по ходу
Приёмка каждой фазы на обычном handover
