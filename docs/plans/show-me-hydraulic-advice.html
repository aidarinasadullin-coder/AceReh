2.1 Гидравлические советы с лечением

Пункт 2.1 очереди 2 роадмапа post-1.8 · Идея №7 · паттерн ThermalAdviceService (1.6.0) на гидравлический срез · условие владельца: «без грязи»
План: docs/plans/2026-09-21-hydraulic-advice-plan.md · правила — в сервисе гидравлического среза (зеркало ThermalAdviceService) · без записей VM→VM и новых писателей канона · state ownership без изменений
СОВЕТЫ — СЛОЙ РЕКОМЕНДАЦИЙ: ничего не гейтят, канонического состояния не создают. Кнопка «Применить» — только смена типоразмера, и идёт она через СУЩЕСТВУЮЩИЙ канонический метод IThermalStateCoordinator.ApplyInputEdit — тот же, которым тепловая форма меняет трубу.

Дубль MinVelocity (0.1 ValidationConstants vs 0.5 HydraulicsConstants) — две разные семантики: 0.1 — физическая валидация ввода (гейт отчёта), 0.5 — инженерный лимит РЕХАУ (советы). Решение H6 — на ревью владельца.

Блок «Советы» — новое (H3): между сводкой KPI-чипов и таблицей; один совет на правило со списком номеров контуров (H4); скрыт, когда нарушений нет; гаснет при правке ввода гидравлики (результаты инвалидируются, ADR-012 — H7); после «Применить» сохраняется с числами последнего гидравлического расчёта до пересчёта (H8). Кнопка «Применить» видна только там, где есть соседний типоразмер (H9) и предложенный типоразмер ещё не канонический (защита от второго клика); подпись — короткое имя трубы «RAUTHERM S 25x2,3» (канон PipeType.Name); у «длины > 120 м» лечения одним действием нет — только текст. Показ — только после расчёта: строка без результатов обеих температур в факты не входит.

Решения-дефолты плана (владелец может переопределить)

H1

Альт.: только навигация на тепловой шаг

Альт.: не синхронизировать — старая труба в форме

Место блока
Под сводкой KPI-чипов, над таблицей
Альт.: подсказки в ячейках dense-таблицы
H5
Потери: режим
Проверяются раб. и хол.; в тексте — какой
Альт.: только раб. — холодный прогон молча пройдёт
H6
MinVelocity 0.1 vs 0.5
Советы — 0.5 (РЕХАУ); 0.1 — валидация ввода
Альт.: уравнять — сломает гейт отчёта
H8
После «Применить»
Без автокаскада: пересчитать оба шага руками
Альт.: автопересчёт — скрытая цепочка расчётов
