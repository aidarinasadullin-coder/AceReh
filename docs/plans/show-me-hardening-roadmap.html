Волны 5–6 — отклик и хвосты

5a clock injection5b async-каскад — отдельное решение владельца6 хвосты
5a: 10 сайтов Task.Delay(3000) в ResultsViewModel → инъекция IDelayScheduler + отмена предыдущей очистки статуса. Эффект: 12 «трёхсекундных» тестов → мгновенные (−~36 c из 39 c прогона), класс гонок StatusMessage исчезает. 5b: синхронный каскад гидравлики на UI-потоке (CircuitsViewModel после тепла) → Task.Run + маршалинг — риск выше, отдельный мини-план, только при подтверждённой проблеме отзывчивости. 6: один хелпер ResetAppSettings (4 копии перестают удалять настоящий %APPDATA%-settings.json), переписать таутологичный тест TextBoxBehavior, слить Integration/ → IntegrationTests/, Directory.Build.props + CPM, publish-профиль вместо параметров в dev-csproj.

Вне объёма (решено)

D5: неподписанный сетап остаётся — сертификата нет; этап подписи появится в CI/CD при внешних релизах. Телеметрия — запрещена (D2). Релизный пайплайн (release.yml: publish → ISCC → артефакт → тег v*) — отдельный мини-план после волны 1, в этот роадмап не входит.
Правило волн: каждая заканчивается зелёными dotnet build + полным dotnet test + ArchitectureRulesTests; handover-строка «state ownership без изменений» (волна 4 — с ADR-016); wire-контракт .smc не меняется; диффы волн не смешиваются.
