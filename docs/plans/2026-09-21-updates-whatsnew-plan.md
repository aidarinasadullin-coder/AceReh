## 0. Суть

1. **«Файл → Проверить обновления»** — сверка версии сборки с каналом
   раздачи (Google Drive): доступна новая версия → диалог с номером,
   списком изменений и кнопкой «Открыть папку выдачи»; версия та же →
   «У вас последняя версия»; сеть недоступна → вежливое сообщение.
   **Загрузку приложение не выполняет** (условие роадмапа) — только
   уведомление и открытие папки.
2. **Диалог «Что нового»** — при первом запуске новой версии: локальное
   (без сети) сравнение версии сборки с `WhatsNewShownVersion` из
   AppSettings; показывается один раз на версию.

**State ownership без изменений.** Владельцы состояния не меняются,
`.smc` wire не меняется, канон-писатели не расширяются; новые данные —
один ключ в AppSettings (оболочка, вне `ProjectSession`). Единственное
внешнее действие приложения — HTTP GET манифеста по команде пользователя
и запуск браузера по ссылке папки.

### 0.1. Решения-дефолты (рекомендации агента; владелец может переопределить при ревью)

| # | Вопрос | Решение (дефолт) | Альтернатива (выбор за владельцем) |
|---|---|---|---|
| U1 | Механизм сверки | **Манифест `latest.json`** в папке выдачи Drive; приложение читает его по фиксированной прямой ссылке (константа в коде). Публикация манифеста — автоматически в release.yml после заливки сетапа | rclone-перечень: у пользователей rclone нет — нереализуемо в дистрибутиве; GitHub API: репозиторий приватный, токен нельзя вшивать |

| U4 | «Открыть папку выдачи» | Кнопка в диалоге обновления; URL — поле `folderUrl` манифеста, открытие браузером (`Process.Start`, UseShellExecute) | Прямая ссылка на Setup.exe — ведёт на большой файл, GDrive добавляет вирусскан-предупреждение |
| U5 | Сравнение версий | `Version` (X.Y.Z из csproj); манифест со старой/равной версией = «последняя версия» (даунгрейд не предлагаем) | Строковое сравнение — ломается на 1.10.0 vs 1.9.0 |
| U6 | Позиция пункта меню | «Проверить обновления» между «Инструкция» и «О программе» (служебная группа) | Рядом с «Недавние проекты» — смешивает работу с проектами и сервис |

| U8 | Первый пуск канала | Владелец один раз: запускает `scripts/publish-latest-manifest.ps1` (льёт манифест локальным rclone, печатает прямую ссылку) → вписывает ссылку в константу `UpdateChannelOptions.ManifestUrl` → коммит. | U9 | Гейт релиза при сбое публикации манифеста | **Warning-only** (дефолт): сетап и тег — главное содержание релиза; манифест не published → «Проверить обновления» честно скажет «не удалось проверить». Выбор владельца — строгий fail при ревью | Fail-гейт: манифест обязателен для успешного релиза |

## 1. Манифест и канал обновлений

Формат `latest.json` (реальная сущность канала):

```json
{
  "version": "1.10.0",
  "publishedAt": "2026-09-21",
  "whatsNew": [
    "Недавние проекты: «Файл → Недавние проекты» и перетаскивание .smc на окно",
    "«Файл → Проверить обновления» и диалог «Что нового»"
  ],
  "folderUrl": "https://drive.google.com/drive/folders/…"
}
```

| Сущность | Решение |
|---|---|
| Ссылка на манифест | Константа `UpdateChannelOptions.ManifestUrl` (`src/Services/Updates/UpdateChannelOptions.cs`, новый файл) — прямая ссылка вида `https://drive.google.com/uc?export=download&id=<FILE_ID>`; пустая по умолчанию (U8), файл не в `.smc`-контракте |
| Чтение | `HttpClient` (один статический экземпляр), таймаут 8 с; ответ — UTF-8 JSON; любой сетевой/форматный сбой → результат «канал недоступен», приложение не падает |
| `publishedAt` | Информационное поле (дата выпуска), в логике не участвует |
| Доступ к файлу | Манифест лежит в папке выдачи «ACE 08.09.2026», доступ «по ссылке» (сетап раздаётся так же) — отдельной настройки не требует |

## 3. AppSettings — новый ключ (конвенция плана 1.2)

`public string? WhatsNewShownVersion { get; set; }` — версия, для которой
«Что нового» уже показано. Отсутствие ключа = null = «ещё не показывалось».
Имя зафиксировано этим планом (конвенция §1 плана 1.2: свои свойства, без
переименований, без миграций); автосохранение 3.1 добавит свой префикс
`Autosave*`.

## 8. Совместимость и риски

- **`.smc`: не меняется.** `settings.json`: новый опциональный ключ
  (`WhatsNewShownVersion`), старые версии его игнорируют.
- Прямая ссылка GDrive (`uc?export=download`) — неофициальный механизм:
  для мелких файлов обычно отдаёт файл напрямую, но при интерстишл/confirm
  странице приложение получит HTML → `TryParse` = false → честная
  деградация «канал недоступен» (находка ревью №9: формулировка
  «скачивается без подтверждений» снята, гарантия — graceful failure).
  При изменении Google формата ссылки — чинится заменой константы (не
  контракт .smc).
- Манифест не публикуется (CI без секрета/сбой) → «Проверить обновления»
  честно скажет «не удалось проверить» — деградация без ломки (U9:
  warning-only, дефолт).
- Пустой `ManifestUrl` в дистрибутиве → «канал не настроен»; шаг владельца
  U8 закрыть ДО релиза 1.10.0 (заливка манифеста + вписывание ссылки);
  CI-напоминание при пустой константе — §5.
- R-инварианты: R1–R6 не задеты; ADR не требуется.
- Ручной smoke (на handover): «Проверить обновления» против реального
  манифеста; диалог при старте (сменить `WhatsNewShownVersion` в
  settings.json вручную); недоступная сеть (offline) → вежливое сообщение.
