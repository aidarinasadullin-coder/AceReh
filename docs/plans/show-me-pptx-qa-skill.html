Что проверяет verify_pptx.py

Два режима: --inventory — один раз снять манифест шейпов шаблона (slide_idx, shape_name, w_cm, h_cm, font_pt, orig_len) → template-inventory.json; --verify — проверки ниже, находки таблицей, код возврата ≠ 0.

1Переоткрытие

Presentation() поднимает файл, обход всех шейпов с рекурсией в GROUP — битый XML падает здесь, а не в PowerPoint.

2Rels

Каждый r:embed/r:link слайдов резолвится в часть с непустым blob — главный риск zipfile-хирургии.

3Счёт слайдов

Фактическое число слайдов == длина ORDER (12).

4Placeholder-мусор

Grep slide-XML: TODO, xxx, lorem, [insert, Click to add.

5Бюджет текста

Длина текста шейпа ≤ orig_len × 1.1 из манифеста — канон оверфлоу, не зависящий от шрифтозамены в превью.

Решения — выбор владельца на G1

№1 · Движок рендер-гейта

Aрекомендация
LibreOffice headless (soffice → pdf → pdftoppm): детерминированно, автоматизируемо. Установка — owner-действие winget install TheDocumentFoundation.LibreOffice (гейт G2-pre).
B — отклонить
PowerPoint COM: вернее рендерит, но хрупко в headless-автоматизации и привязан к офисной установке.

№2 · Где живёт канон скилла

Aрекомендация
Канон в репозитории: harness-assets/skill/ → установка install-skill.cmd в ~/.agents/skills/rehau-deck/. История правок в git, дрейф закрыт сверкой.
B — отклонить
Канон сразу в пользовательской папке: вне git, без истории, расхождение с репо не отследить.

№3 · Regex-хирургия build_final.py

Aрекомендация
Сохранить хирургию, добавить verify-гейт: работающий код не переписываем, риск закрывают проверки 1–2.
B — отклонить
Переписать клонирование in-process (deepcopy + relate_to): чище, но вне мотивации плана.

Фазы и критерии

Фаза A — verify-гейт

verify_pptx.py · template-inventory.json · README-QA.md (чек-лист камней pptxgenjs)
  • --verify зелёный на harness-deck-v2.pptx (12 слайдов);
  • испорченная копия (медиа-часть удалена, r:embed жив) ловится с внятным отчётом;
  • на чистой base12.pptx — 0 находок.

Фаза B — рендер-гейт (после G2-pre)

make_preview.py → preview/slide-01..12.png
  • превью всех 12 слайдов одной командой;
  • README-QA фиксирует шрифтозамену LibreOffice (прецедент compare-font.png): вердикты по превью ориентировочные;
  • владелец подтвердил читаемость превью.

Фаза C — скилл rehau-deck

build_final.py +argparse · skill/SKILL.md · skill/reference.md · install-skill.cmd
  • запуск без аргументов = текущее поведение (дефолты прежние);
  • мини-дека «титул / шаг / финал» проходит build → verify → preview;
  • универсальный document-skills:pptx не тронут.
