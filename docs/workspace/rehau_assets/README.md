# REHAU — фирменные элементы (извлечено из гайдлайна PDF)

Источник: `../rehau_guideline.pdf` (РЕХАУ_GUIDELINE_new_color_2, Adobe Illustrator, 2023).
Все SVG — чистый вектор на прозрачном фоне, извлечены без растрирования и потерь.
Координаты внутри SVG соответствуют исходной геометрии из PDF (viewBox сохранён).

## Логотип

| Файл | Что это | Стр. гайдлайна |
|---|---|---|
| `logo_main_color.svg` / `.png` | Основная версия: цветной знак + чёрное начертание «РЕХАУ» | 5 |
| `logo_icon_color.svg` / `.png` | Только графический знак («пиксельное сердце») | 5 |
| `logo_wordmark_black.svg` | Только шрифтовое начертание «РЕХАУ» | 5 |
| `logo_white.svg` / `.png` | Белый монохром (для тёмных/цветных фонов) | 6 |
| `logo_black.svg` / `.png` | Чёрный монохром (для светлых фонов) | 6 |

PNG — фолбэки 300 dpi с прозрачным фоном (для мест, где SVG недоступен).

Охранное поле: модуль `x` = ширина одного квадратика знака; логотип не размещать
на цветном фоне и фото в основной (цветной) версии, не перекрашивать,
не комбинировать варианты между собой (стр. 5–7).

## Цвета

`palette.json` — машиночитаемая палитра (HEX/CMYK/RAL/PANTONE).
`brand.css` — CSS-переменные `--rehau-*` для прямого подключения в проект.

- Активный Красный `#E50040` (CMYK 0/100/65/0, RAL 3028, PANTONE 199 PC)
- Умный Зелёный `#4FC7B5` (CMYK 60/0/30/0, RAL 6033, PANTONE 3258 C)
- Чёрный `#000000` (RAL 8022, PANTONE Black 6), Белый `#FFFFFF` (RAL 9003)
- Оттенки чёрного 20/40/60/80: `#D9D9D9`, `#B0B0B0`, `#818181`, `#4E4E4E`
