## 5. ПОВЕДЕНИЕ И ВЗАИМОДЕЙСТВИЕ

### 5.1 Навигация между шагами

- **Вперёд:** Валидация текущего шага → сохранение → переход
- **Назад:** Сохранение состояния → переход
- **Произвольный шаг:** Клик в боковой панели (с предупреждением о несохранённых данных)

### 5.2 Автосохранение

- **Интервал:** 5 минут
- **Место:** SQLite в %AppData%\ACE\autosave.db
- **При закрытии:** Предложение сохранить/отменить/не сохранять
- **При открытии:** Проверка autosave → предложение восстановить

### 5.3 Валидация при переходе

**Шаг 1 → 2:**
- ✓ Выбран город
- ✓ Интенсивность снегопада > 0

**Шаг 2 → 3:**
- ✓ Минимум 1 слой над трубой
- ✓ Минимум 1 слой под трубой
- ✓ Стяжка ≥ 40 мм

**Шаг 3 → 4:**
- ✓ Минимум 1 контур
- ✓ Все поля заполнены
- ✓ Δp ≤ 320 мбар (предупреждение, но не блокировка)

### 5.4 Горячие клавиши

- `Ctrl+S` — Сохранить проект
- `Ctrl+N` — Новый проект
- `Ctrl+O` — Открыть проект
- `F5` — Пересчёт
- `←/→` — Назад/Вперёд по шагам
- `F1` — Помощь

## 8. БАЗА ДАННЫХ ПРОЕКТОВ

### 8.1 Структура SQLite

```sql
-- Проекты
CREATE TABLE Projects (
    Id INTEGER PRIMARY KEY,
    Name TEXT NOT NULL,
    Object TEXT,
    FilePath TEXT,
    CreatedAt DATETIME,
    ModifiedAt DATETIME,
    JsonData TEXT -- сериализованный ProjectModel
);

-- Недавние проекты
CREATE TABLE RecentProjects (
    ProjectId INTEGER,
    OpenedAt DATETIME,
    FOREIGN KEY(ProjectId) REFERENCES Projects(Id)
);
```

### 8.2 Расположение

- **По умолчанию:** `%AppData%\ACE\projects.db`
- **Пользовательская:** выбирается в настройках
- **Автосохранение:** `%AppData%\ACE\autosave.db`
