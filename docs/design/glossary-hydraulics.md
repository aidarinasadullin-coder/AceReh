# Глоссарий гидравлики: немецкие термины → русские (Фаза 3)

> Место: `docs/design/` — рядом с бренд-доком и картой иконок; словарь
> описывает терминологию UI. Создан в Фазе 3 редизайна (план §Ф3,
> решение ревью Ф3 — ADR-007 п.10), переиспользуется Фазой 8 (отчёты):
> заголовки отчётов должны совпадать с заголовками таблицы.

Правила:

1. В интерфейсе — только русские формулировки; немецкие обозначения
   (`DpRohr` и т.п.) остаются в коде модели/DTO и wire-формате `.smc`
   (переименование не входит в объём Ф3 и не планируется).
2. Заголовки колонок таблицы контуров — по таблице «Колонки таблицы»
   ниже; формат «Величина, единица» (запятая перед единицей), единицы —
   русские (л/ч, м/с, Па/м, мм²/с).
3. Числа — русская локаль (десятичная запятая, пробел-тысячи), решение
   владельца 2026-09-04 (журнал п.9).

| — | ⚠ | Статус | Чип/точка: teal — ок, amber — `PressureLossWarning` (уд. потери рабочего режима > 300 Па/м; текст в tooltip) |
| L_hk (CircuitLength) | Длина (м) | Длина, м | Греющий контур без подводки |
| L_zul (SupplyLength) | Подводка (м) | Подводка, м | Подводящий участок |
| — (CircuitArea) | Площадь (м²) | Площадь, м² | S = L_hk·VA_hk/100 |
| VA_hk (PipeSpacing_cm) | Шаг (см) | Шаг, см | Шаг укладки трубы |
| — (Power) | Мощность (Вт) | Мощность, Вт | Полезная мощность контура |
| — (FlowRate) | Расход (л/ч) | Расход, л/ч | Объёмный расход теплоносителя |
| — (FlowRate_Ls) | Расход (л/с) | Расход, л/с | = л/ч / 3600 |
| — (Velocity) | Скорость (м/с) | Скорость, м/с | Только «Полностью» |
| ReynoldsNumber | Re | Re | Только «Полностью» |
| FrictionFactor | λ | λ | Коэффициент гидравлического трения, только «Полностью» |
| FlowRegime | Режим | Режим | ламинарный / переходный / турбулентный |
| PressureLossPerMeter | Уд.потери (Па/м) | R, Па/м | Удельные линейные потери; красный, если отображаемое значение > 300 Па/м (в обоих режимах; при холодном пуске превышение — штатное, см. примечание в блоке «Результаты») |
| DpRohr | DpRohr (Па) | Δp трубы, Па | Потери в трубе контура; красный при > 32000 Па (320 мбар) |
| DpVerteiler | DpVerteiler (Па) | Δp коллект., Па | Потери в коллекторе (распределителе) |
| DpVent | DpVent (Па) | Δp клап., Па | Потери в клапане контура |
| DpGesamt | DpGesamt (Па) | Δp всего, Па | DpRohr + DpVerteiler + DpVent; красный при > 32000 Па (320 мбар — паспортный предел HKV) |
| Throttling (zu_drosseln) | zu_drosseln (Па) | Дросс., Па | Требуемое дросселирование (излишек против референсного контура) |
| ValveTurns | Обороты | Обороты | Обороты клапана, дробь («2 ½»); видимы в обоих режимах |

Порядок колонок «Полностью» (20 колонок + ✕): №, Статус, Длина, Подводка,
Площадь, Шаг, Мощность, Расход л/ч, Расход л/с, Скорость, Re, λ, Режим,
R, Δp трубы, Δp коллект., Δp клап., Δp всего, Дросс., Обороты, ✕.
«Компактно» (8 + ✕): №, Статус, Длина, Подводка, Площадь, Шаг, Мощность,
Обороты. План §Ф3.4 называет «19 колонок» — счёт данных колонок без «№»;
в реализации «⚠» стал полноценной колонкой «Статус», поэтому 20.
«Обороты» видимы всегда (решение владельца, журнал п.3).
Красная подсветка ячеек — единый принцип «отображаемое значение > порога»:
R > 300 Па/м, Δp-колонки > 32000 Па (320 мбар); точка/чип «Статус» — по
`PressureLossWarning` (рабочий режим).
