# Концепт-рендеры целевого UI (Фаза R)

HTML-мокапы целевого дизайна из `redesign-plan.md` + токены из
`brandbook-2026-application.md`. Рендеры 1440×900, шрифт Inter
(app-ассеты + Regular/SemiBold woff2), все цвета и градиенты — бренд-токены.

| PNG | Что показывает | Фаза плана |
|---|---|---|
| `01-shell-climate.png` | Каркас: светлая шапка (рассчитать/отчёт), степпер, merged форм-карточка климата, правая панель «Сводка», статус-бар с плашкой | Ф1 + Ф5 |
| `02-results-dashboard.png` | Дашборд: Hero-KPI на градиенте `Red.Intensive` + «квадраты», бренд-рамка, 6 KPI-чипов 2:1, коллекторы/оборудование/конструкция | Ф1 + Ф6 |
| `03-hydraulics.png` | Гидравлика, **компактный режим**: сегмент режимов, коллектор-карточка с табами и чипами, таблица «Ввод» + колонка «Обороты» (всегда видима) | Ф3 |
| `03b-hydraulics-expanded.png` | Гидравлика, **полный режим**: та же страница целиком, таблица из 19 колонок (11 px, табличные цифры, закреплённая «№», обороты в дробях) | Ф3 |
| `04-thermal.png` | Тепловой: подписи режима как в приложении (температура поверхности в описании + отдельное read-only поле), форм-карточки, Hero-KPI + чипы результатов | Ф5 |
| `05-construction.png` | Конструкция: параметры+шаблон, пир слоёв с inline-схемой | Ф4 |
| `06-splash.png` | Сплэш при старте (показ 1–1,5 с): градиент `Red.Intensive`, белый логотип по центру — композиция финального слайда брендбука | Ф7 |
| `06b-about.png` | «О программе» — лёгкий диалог: белая карточка, тонкая красная полоса-акцент, версия, данные СП, слоган | Ф7 |

Исходники: `*.html` + `tokens.css` (единый словарь стилей мокапов).
Пересборка: поднять `python -m http.server` в корне репо, открыть
`/docs/design/renders/NN-*.html`, скриншот 1440×900.
