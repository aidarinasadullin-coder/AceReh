## 0. Стратегия

Две линии в одном потоке: **архитектура UI** (каркас «шапка-действия /
степпер / рабочая область / сводка / статус-бар» + компонентная система) и
**бренд 2026** (палитра, 4 фирменных градиента, Inter-веса, плашки/рамки/
квадраты). Свой каркас без UI-фреймворков; из готового — только
VirtualizingWrapPanel и FlaUI (обе MIT), иконки — генерация из Fluent SVG.

Порядок: **R → 0 → 1 → 1Б → 2 → (3 → 3Б · 4 · 4Б · 5 · 6 · 8) → 7**.
Фазы 3–8 независимы; 3Б — сразу после приёмки Ф3; 4Б и 8 запускаются
по явной команде; 7 — после модулей.
Размеры: S ≈ вечер, M ≈ 2–3 вечера, L ≈ спринт.
