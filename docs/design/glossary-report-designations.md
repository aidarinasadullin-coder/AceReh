# Словарь обозначений пояснительной записки (ПЗ)

> Место: `docs/design/` — рядом с глоссарием гидравлики Ф3. Создан по плану
> мини-фазы полировки ПЗ `docs/plans/2026-09-07-pz-polish-plan.md` (P0/P5,
> решения владельца В12/В16/В17 от 2026-09-07); применяется билдерами
> `src/Services/Reports/Calculation/Builders/**` и приложением «Обозначения»
> детального отчёта v2 (`docs/report-spec-v2.md`, §6 п.10). Статус: принят
> владельцем в объёме словаря-минимума В16–В17; пополнение — только по
> правилу конфликтов 4.

## Пирамида источников (В16)

Приоритет источников обозначений для ПЗ:

1. **Тепло/формулы** — эталон `docs/инструкция/README v.2.3 kimi.md`
   (итоговые таблицы обозначений: «Температуры и климат», «Теплотехника»,
   «Гидравлика и теплоноситель»).
2. **Входные величины** — `docs/Formulas_Snegotayanie.md`.
3. **Заголовки гидравлических таблиц и русские словарные эквиваленты** —
   Ф3: `docs/design/glossary-hydraulics.md`.
4. **Константы** — код (`Core/Constants/ThermalConstants.cs`,
   `Hydraulics.FlowRegimeCalculator`).

## Правила конфликтов (план P0, дословно)

1. Код-имя vs эталон → всегда эталон.
2. Ф3 vs эталон (гидравлика) → заголовки таблиц Ф3; формулы — русские
   эквиваленты Ф3, немецкое происхождение в приложении.
3. Внутренняя непоследовательность эталона (`q_FB` в формуле JHmü vs
   `PowerUp` в его таблице обозначений) → берём из таблицы обозначений
   эталона.
4. Величины нет ни в одном источнике → новое обозначение только через
   утверждение владельца (молча не изобретать).

## Структура записи (5 колонок, В16)

| Колонка | Содержание |
| --- | --- |
| Обозначение | Символ, выводимый в ПЗ (тело, формулы, таблицы, приложение) |
| Русское определение | Инженерный смысл по-русски |
| Единица | Единица измерения, как выводится в ПЗ |
| Источник | эталон kimi / Формулы (`docs/Formulas_Snegotayanie.md`) / Ф3 (`docs/design/glossary-hydraulics.md`) / код / «новое» |
| Немецкое происхождение | Заполняется только для гидравлики (по Ф3/эталону); «—» — не документировано |

Кодовые имена домена (`PowerDown`, `DpRohr`, `DpVerteiler`, `DpVent`,
`DpGesamt`, `zu_dr`, `Throttling`, `TotalPowerDensity`, `MassFlowRate`,
`VolumeFlowRate` и т.п.) в ПЗ не выводятся — в таблицах ниже они указаны
как «замена» для трассировки. Обозначения эталона (`JHmü`, `RFb`,
`PowerUp`, `q_D`, `ṁ`) легитимны.
