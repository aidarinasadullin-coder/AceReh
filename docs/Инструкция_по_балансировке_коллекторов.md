# Инструкция по балансировке коллекторов РЕХАУ

## 1. Общие сведения

Данная инструкция описывает процесс балансировки коллекторов на основе VBA-макросов из файла `gidravlica.xls`.

### Назначение
Балансировка коллекторов необходима для обеспечения правильного распределения расхода теплоносителя (воды) между различными контурами системы отопления или снеготаяния.

---

## 2. Используемые компоненты

### 2.1 Типы вентилей (клапанов)

В системе используются следующие типы клапанов:

| Тип клапана | Применение | Формула расчета |
|-------------|------------|-----------------|
| **IV 1 1/2"** | Встроенный вентиль 1 1/2 дюйма | `5.122 × Kv - 0.2106` |
| **IV 1 1/4"** | Встроенный вентиль 1 1/4 дюйма | `5.1818 × Kv - 0.23` |
| **HKV-D** | Балансировочный клапан HKV-D (кубическая характеристика) | `4.2111 × Kv³ - 6.7436 × Kv² + 4.6613 × Kv - 0.712` |

---

## 3. Расчет количества оборотов

### 3.1 Параметры

- **Kv** - коэффициент расхода (объемный расход воды в м³/ч при перепаде давления 1 бар)
- **Тип клапана** - выбирается из списка: IV 1 1/2", IV 1 1/4", HKV-D
- **Результат** - количество оборотов клапана для достижения требуемого расхода

### 3.2 Алгоритм расчета

```
Функция umdreh1(Kv, Тип_клапана):
    
    Если Тип_клапана = "IV 1 1/2" Тогда:
        Вернуть: 5.122 × Kv - 0.2106
        
    ИначеЕсли Тип_клапана = "IV 1 1/4" Тогда:
        Вернуть: 5.1818 × Kv - 0.23
        
    ИначеЕсли Тип_клапана = "HKV-D" Тогда:
        Вернуть: 4.2111 × Kv³ - 6.7436 × Kv² + 4.6613 × Kv - 0.712
        
    Иначе:
        Вернуть: "Ошибка" (неверный тип клапана)
```

### 3.3 Примеры расчетов

**Пример 1: Клапан IV 1 1/2" при Kv = 2.5**
```
Объем оборотов = 5.122 × 2.5 - 0.2106
               = 12.805 - 0.2106
               = 12.59 оборотов
```

**Пример 2: Клапан IV 1 1/4" при Kv = 3.0**
```
Объем оборотов = 5.1818 × 3.0 - 0.23
               = 15.5454 - 0.23
               = 15.32 оборотов
```

**Пример 3: Клапан HKV-D при Kv = 1.8**
```
Объем оборотов = 4.2111 × (1.8)³ - 6.7436 × (1.8)² + 4.6613 × (1.8) - 0.712
               = 4.2111 × 5.832 - 6.7436 × 3.24 + 8.3903 - 0.712
               = 24.56 - 21.85 + 8.39 - 0.71
               = 10.39 оборотов
```

## 4. Работа с Excel-макросом

### 4.1 Макрос `umdreh()`

**Назначение**: Сброс параметров и подготовка к новому расчету

**Выполняемые действия**:
1. Очищает ячейку R6 (сброс предыдущего значения)
2. Переходит к ячейке D37
3. Прокручивает лист вверх на 12 строк
4. Устанавливает курсор на ячейку Q5

**Применение**: Используется для сброса расчетов перед вводом новых данных.

### 4.2 Функция `umdreh1(kv, vert)`

**Назначение**: Расчет количества оборотов для балансировочного клапана

**Параметры**:
- `kv` (Double) - значение Kv коэффициента
- `vert` (String) - тип клапана: "IV 1 1/2", "IV 1 1/4" или "HKV-D"

**Возвращаемое значение**: 
- Число (Double) - количество оборотов
- Или строка "Ошибка" ("Fehler") при неверном типе клапана

## 5. Пошаговая инструкция по балансировке

### Шаг 1: Подготовка
1. Откройте файл `gidravlica.xls`
2. Убедитесь, что макросы включены
3. Запустите макрос `umdreh` для сброса предыдущих расчетов

### Шаг 2: Определение параметров
1. Определите требуемый расход теплоносителя для каждого контура
2. Рассчитайте Kv значение для каждого контура
3. Уточните тип установленного клапана

### Шаг 3: Расчет оборотов
1. Для каждого контура вызовите функцию `umdreh1(Kv, Тип_клапана)`
2. Запишите полученное количество оборотов

### Шаг 4: Настройка клапанов
1. Откройте балансировочный клапан
2. Установите ручку/шестерню клапана в положение "0" (полностью закрыто)
3. Поверните на рассчитанное количество оборотов против часовой стрелки
4. Зафиксируйте положение

### Шаг 5: Проверка
1. Измерьте фактический расход в каждом контуре
2. Сравните с расчетным
3. При необходимости скорректируйте положение клапана

## 6. Рекомендации

### 6.1 Общие правила

1. **Точность измерений**: Kv должен быть рассчитан с точностью до 0.01
2. **Проверка типа клапана**: Всегда уточняйте маркировку клапана перед расчетом
3. **Кратность оборотов**: Результат округляйте до 0.1 оборота
4. **Проверка**: После балансировки обязательно проверьте расходы всех контуров

### 6.2 Особенности клапана HKV-D

- Имеет **кубическую характеристику** (нелинейную)
- Требует более точного расчета Kv
- При малых Kv (< 0.5) чувствителен к погрешностям
- Рекомендуется использовать при Kv от 0.8 до 4.0

### 6.3 Частые ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Отрицательное количество оборотов | Слишком малое значение Kv | Проверьте расчет расхода |
| Значение "Ошибка" | Неверный тип клапана | Проверьте написание: "IV 1 1/2", "IV 1 1/4" или "HKV-D" |
| Большое количество оборотов (>20) | Слишком большое Kv | Проверьте единицы измерения расхода |
