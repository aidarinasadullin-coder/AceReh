# Changelog

## [1.1.2] - 2026-09-08

### Добавлено
- **Установщик Inno Setup** — `SnowMeltingCalculator-v1.1.2-Setup.exe` (self-contained win-x64, .NET 8 в комплекте); замена MSI/WiX из 1.0.0
- **Ассоциация файлов .smc** — открытие проекта двойным кликом из проводника
- **Полная инструкция в поставке** — `docs\Инструкция полная\` (README.html + media), открывается из меню «Файл → Инструкция»
- **PDF-записка расчёта (ПЗ)** — полный отчёт с рендером формул расчёта

### Изменено
- **PDF-стек:** QuestPDF → PDFsharp-MigraDoc 6.2.4; формулы — CSharpMath.SkiaSharp (ADR-Ф8/009)
- **Дизайн:** собственная дизайн-система REHAU вместо MaterialDesignInXamlToolkit
- **Архитектура:** завершена миграция (фазы 1–11) — `ProjectSession` корень агрегата состояния с явными слайсами (климат, конструкция, теплотехника, гидравлика), ViewModels — адаптеры; инварианты R1–R6 закреплены тестами `ArchitectureRulesTests`

### Исправлено
- Открытие PDF-отчётов в Adobe Acrobat («Недостаточно данных для изображения») — кодирование Flate-потоков BestSpeed (санкционированный обход мейнтейнера PDFsharp, empire/PDFsharp#258)

### Тестирование
- ~2200 unit-тестов (NUnit); прогон Release 2026-09-07: 2193 passed / 0 failed / 1 skipped (предсуществующий условный)

## [1.0.0] - 2026-04-06

### Добавлено
- **Климатический модуль** — данные по 550 городам РФ (СП 131.13330.2025)
- **Модуль конструкции** — расчёт многослойной конструкции ("пирог")
- **Тепловой расчёт** — определение теплопотерь и мощности системы
- **Гидравлический расчёт** — расчёт контуров, коллекторов, балансировка
- **База данных климатов** — JSON с данными по городам РФ
- **База данных гликолей** — свойства этилен- и пропиленгликоля (ASHRAE)
- **База данных материалов** — теплопроводность строительных материалов
- **База данных REHAU** — трубы RAUTHERM S, коллекторы HKV и IV
- **MSI-установщик** — профессиональный установщик Windows с проверкой .NET 8
- **Документация** — полная документация по формулам и архитектуре

### Технологии
- C# .NET 8
- WPF с Material Design
- MVVM (CommunityToolkit.Mvvm)
- SQLite для проектов
- QuestPDF для отчётов
- WiX v4 для установщика

### Тестирование
- 875 unit-тестов (NUnit)
- Покрытие основных модулей
