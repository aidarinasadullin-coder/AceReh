## Вопросы к пользователю

### 1. Отображение пустых контуров ("kein Kreis")

**Контекст:**
В немецком образце (Berechnung.png) пустые контуры отображаются как "kein Kreis" (нет контура).

**Вопрос:**
Нужно ли реализовать это поведение?

**Варианты:**
- **Вариант A:** Отображать прочерк (—) для всех вычисляемых полей пустого контура
- **Вариант B:** Отображать "нет контура" в столбце "Длина"
- **Вариант C:** Не отображать пустые контуры в таблице

**Рекомендация:** Вариант A — отображать прочерк для всех вычисляемых полей, это стандартная практика для табличных данных.

### 2. Цветовое выделение превышения давления

**Контекст:**
При превышении давления > 320 мбар (ограничение РЕХАУ) нужно визуально выделить это предупреждение.

**Вопрос:**
Какой способ выделения предпочтительнее?

**Варианты:**
- **Вариант A:** Красный цвет текста для значения потерь
- **Вариант B:** Красный фон ячейки с белым текстом
- **Вариант C:** Иконка предупреждения (⚠) рядом со значением
- **Вариант D:** Комбинация: красный текст + иконка предупреждения

**Рекомендация:** Вариант D — красный текст + иконка предупреждения, это наиболее заметно для пользователя.

### 3. Расположение информационных блоков

**Контекст:**
В немецком образце блоки расположены слева направо:
- EINGABEN (входные данные) — слева
- Verlege- und Leistungsdaten (данные укладки) — посередине
- ERGEBNISSE (результаты) — справа

**Вопрос:**
Какое расположение блоков предпочтительнее?

**Варианты:**
- **Вариант A:** Сверху вниз (как предложено в ТЗ)
  - Преимущества: больше ширины для каждого блока, лучше читаемость
  - Недостатки: больше вертикального пространства
- **Вариант B:** Слева направо (как в образце)
  - Преимущества: компактность, соответствие образцу
  - Недостатки: меньше ширины для каждого блока

**Рекомендация:** Вариант A — сверху вниз, так как это улучшает читаемость на широких экранах и соответствует существующему стилю интерфейса.

---

### 4. Режим отображения результатов (рабочая/расчётная температура)

**Контекст:**
В текущей реализации есть переключатель режима (рабочая/расчётная температура), который влияет на отображаемые значения в таблице контуров.

**Вопрос:**
Нужно ли отображать результаты для обоих режимов одновременно?

**Варианты:**
- **Вариант A:** Отображать только текущий режим (как сейчас)
  - Преимущества: простота, не перегружен интерфейс
  - Недостатки: нужно переключаться для сравнения
- **Вариант B:** Отображать оба режима в блоке результатов
  - Потери (рабочая T): 233.6 мбар
  - Потери (расчётная T): 308.2 мбар
  - Преимущества: сразу видны оба значения
  - Недостатки: больше информации на экране

**Рекомендация:** Вариант B — отображать оба значения в блоке результатов, так как это важно для подбора насоса (холодный пуск).

### 5. Отображение типа трубы

**Контекст:**
В немецком образце тип трубы отображается как "RAUTHERM S" без указания размеров.

**Вопрос:**
Как отображать тип трубы?

**Варианты:**
- **Вариант A:** Только наименование ("RAUTHERM S")
- **Вариант B:** Наименование с размерами ("RAUTHERM S 20×2.0")
- **Вариант C:** Полное описание ("Труба PE-Xa RAUTHERM S 20×2.0 мм")

**Рекомендация:** Вариант B — наименование с размерами, это информативнее и соответствует текущей реализации.

**Рекомендация:** Вариант B — русский формат, так как интерфейс на русском языке.
