### Решённые проблемы

1. **Нумерация контуров 1,1,1 вместо 10,11,12**
   - **Причина**: `CircuitNumber` — обычное свойство без `[ObservableProperty]`
   - **Решение**: Сделано ObservableProperty

2. **Коллекторы не отображаются в интерфейсе**
   - **Причина**: Нет TabControl для переключения между коллекторами
   - **Решение**: Добавлен TabControl с вкладками

3. **Отсутствует перенумерация коллекторов при удалении**
   - **Причина**: Нет метода `RenumberCollectors()`
   - **Решение**: Метод добавлен и вызывается в `RemoveCollector()`

4. **Дублирование кода**
   - **Причина**: `CircuitViewModel.cs` не использовался
   - **Решение**: Файл удалён
