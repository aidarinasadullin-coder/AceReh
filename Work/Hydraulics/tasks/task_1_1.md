## 2. Цель задачи

Сделать свойство `CircuitNumber` в классе `CircuitRow` ObservableProperty, чтобы UI получал уведомление об изменении номера контура при перенумерации.

---

## 3. Описание проблемы

### 3.1. Симптом
При добавлении контуров после 9-го номера отображаются как 1,1,1 вместо 10,11,12.

### 3.2. Корневая причина
**Файл**: `src/Models/Hydraulics/CircuitRow.cs`, строка 82

```csharp
/// <summary>
/// Номер контура
/// </summary>
public int CircuitNumber { get; set; }  // <-- ОБЫЧНОЕ свойство без уведомления!
```

Свойство `CircuitNumber` не является `ObservableProperty`, поэтому при изменении через метод `RenumberCircuits()` UI не получает уведомление об изменении.

### 3.3. Механизм бага
1. Пользователь добавляет контуры 1-9 → номера корректны
2. Пользователь удаляет контур №5
3. Метод `RenumberCircuits()` перенумеровывает: 1,2,3,4,6,7,8,9 → 1,2,3,4,5,6,7,8
4. **НО**: `CircuitNumber` не уведомляет UI, поэтому DataGrid показывает старые номера
5. При добавлении новых контуров отображаются некорректные номера

---

## 4. Изменения

### 4.1. Файл: `src/Models/Hydraulics/CircuitRow.cs`

#### Текущий код (строки 79-82):
```csharp
/// <summary>
/// Номер контура
/// </summary>
public int CircuitNumber { get; set; }
```

#### Требуемый код:
```csharp
/// <summary>
/// Номер контура
/// </summary>
[ObservableProperty]
private int _circuitNumber;
```

#### Обоснование:
- Атрибут `[ObservableProperty]` генерирует свойство `CircuitNumber` с уведомлением `INotifyPropertyChanged`
- UI будет автоматически обновляться при изменении номера
