## 1. Цель задачи

Исправить расчёт потерь давления в вентиле в методе `CalculateAtTemperature` — использовать плотность в **г/см³** вместо **кг/м³**.

---

## 2. Связь с юзер-кейсами

### UC-3: Расчёт потерь в вентиле

**Проблема**: Формула использует плотность в кг/м³, но требует г/см³. Результат в 1000 раз больше.

**Решение**: Конвертировать плотность: `density_g_cm3 = glycolProps.Density / 1000.0`

---

## 3. Описание изменений

### 3.1. Файл: `src/Services/Hydraulics/CircuitsCalculator.cs`

#### 3.1.1. Метод: `CalculateAtTemperature` (потери в вентиле)

**Строка**: 212

**Текущий код**:
```csharp
// Потери в вентиле: Δp_Vent = (V_dot / 1000 / Kv)² × 100000 × ρ
result.ValveLoss = Math.Pow(circuit.FlowRate / 1000.0 / kv, 2) * 100000 * glycolProps.Density;
```

**Требуемый код**:
```csharp
// Потери в вентиле: Δp_Vent = (V_dot / 1000 / Kv)² × 100000 × ρ
// Важно: ρ должно быть в г/см³, glycolProps.Density в кг/м³
double density_g_cm3 = glycolProps.Density / 1000.0;
result.ValveLoss = Math.Pow(circuit.FlowRate / 1000.0 / kv, 2) * 100000 * density_g_cm3;
```

#### 3.1.2. Оптимизация

**Примечание**: Переменную `density_g_cm3` можно объявить один раз в начале метода и использовать для обоих расчётов (удельные потери и потери в вентиле).

**Рекомендуемое место**: После строки получения `glycolProps` (около строки 170)

```csharp
// Конвертация плотности: кг/м³ → г/см³
double density_g_cm3 = glycolProps.Density / 1000.0;
```

## 4. Тест-кейсы

### 4.1. Тест: Корректные потери в вентиле

**Входные данные**:
- flowRate = 280 л/ч
- density = 1053 кг/м³ (= 1.053 г/см³)
- kv = 1.2 м³/ч

**Ожидаемый результат**: 5729 Па (±1)

**Формула**:
```
Δp_Vent = (280 / 1000 / 1.2)² × 100000 × 1.053
Δp_Vent = (0.233)² × 100000 × 1.053
Δp_Vent = 0.0544 × 100000 × 1.053
Δp_Vent = 5729 Па
```

### 4.2. Тест: Проверка отсутствия ошибки ×1000

**Входные данные**: те же

**Проверка**: Результат НЕ должен быть 5728272 Па (ошибка ×1000)

## 5. Критерии приёмки

- [ ] Потери в вентиле рассчитываются с плотностью в **г/см³**
- [ ] Результат соответствует формуле: `Δp_Vent = (V_dot / 1000 / Kv)² × 100000 × ρ[г/см³]`
- [ ] При V_dot = 280 л/ч, ρ = 1053 кг/м³, Kv = 1.2 м³/ч
  - Результат: **5729 Па** (не 5728272 Па)
- [ ] Переменная `density_g_cm3` используется для обоих расчётов (опционально)
- [ ] Unit-тесты проходят
