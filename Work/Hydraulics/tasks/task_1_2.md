## 2. Цель задачи

Добавить TabControl в `CircuitsView.xaml` для отображения списка коллекторов и переключения между ними.

---

## 3. Описание проблемы

### 3.1. Симптом
Кнопка "Добавить коллектор" нажимается, но новые коллекторы не появляются в интерфейсе.

### 3.2. Корневая причина
**Файл**: `src/Views/Hydraulics/CircuitsView.xaml`

В XAML **НЕТ** элемента для отображения списка коллекторов и переключения между ними:
- Нет TabControl
- Нет ListBox
- Нет ComboBox для выбора коллектора

Есть только:
- Строка 295: отображение номера **выбранного** коллектора
- Строка 312: привязка к контурам **выбранного** коллектора

### 3.3. Механизм бага
1. Пользователь нажимает "Добавить коллектор"
2. Метод `AddCollector()` создаёт коллектор и добавляет в `Collectors`
3. `SelectedCollectorIndex` устанавливается на новый коллектор
4. **НО**: В интерфейсе нет элемента для отображения списка коллекторов!
5. Пользователь видит только контуры текущего коллектора, но не может переключаться

---

## 4. Изменения

### 4.1. Файл: `src/Views/Hydraulics/CircuitsView.xaml`

#### Требуется добавить TabControl

**Место вставки**: После строки 113 (после заголовка "Таблица контуров")

**Структура XAML**:
```xml
<!-- TabControl для коллекторов -->
<TabControl Grid.Row="1"
             ItemsSource="{Binding Collectors}"
             SelectedIndex="{Binding SelectedCollectorIndex, Mode=TwoWay}">
    <TabControl.ItemTemplate>
        <DataTemplate>
            <TextBlock Text="{Binding CollectorNumber, StringFormat='Коллектор №{0}'}"/>
        </DataTemplate>
    </TabControl.ItemTemplate>
    <TabControl.ContentTemplate>
        <DataTemplate>
            <!-- Содержимое вкладки: параметры теплоносителя, DataGrid контуров, кнопки -->
            <ContentPresenter Content="{Binding}"/>
        </DataTemplate>
    </TabControl.ContentTemplate>
</TabControl>
```

#### Требуемая реструктуризация Grid

**Текущая структура**:
```
Grid.Row="0" - Заголовок
Grid.Row="1" - Параметры теплоносителя
Grid.Row="2" - Свойства теплоносителя
Grid.Row="3" - Информация о коллекторе
Grid.Row="4" - DataGrid контуров
Grid.Row="5" - Кнопки управления
```

**Новая структура**:
```
Grid.Row="0" - Заголовок
Grid.Row="1" - TabControl для коллекторов
    TabItem.Content:
        - Параметры теплоносителя
        - Свойства теплоносителя
        - Информация о коллекторе (удалить, т.к. номер в заголовке вкладки)
        - DataGrid контуров
        - Кнопки управления
```

#### Детали реализации

**Шаг 1**: Изменить структуру Grid
- Уменьшить количество строк Grid до 2
- Row 0: Заголовок
- Row 1: TabControl

**Шаг 2**: Переместить содержимое в TabControl.ContentTemplate
- Параметры теплоносителя (Border Grid.Row="1")
- Свойства теплоносителя (Border Grid.Row="2")
- DataGrid контуров (Grid.Row="4")
- Кнопки управления (StackPanel Grid.Row="5")

**Шаг 3**: Удалить информацию о коллекторе (Grid.Row="3")
- Номер коллектора теперь отображается в заголовке вкладки
- Оставить только тип вентиля и количество контуров (если нужно)

**Шаг 4**: Обновить привязки
- `ItemsSource="{Binding Collectors}"` — коллекция коллекторов
- `SelectedIndex="{Binding SelectedCollectorIndex, Mode=TwoWay}"` — выбранный коллектор
- `Text="{Binding CollectorNumber, StringFormat='Коллектор №{0}'}"` — заголовок вкладки

## 5. Тест-кейсы

### TC-1.2.1: Добавление коллектора
**Предусловия**:
- Открыт экран "Гидравлический расчёт"
- 1 коллектор (по умолчанию)

**Шаги**:
1. Нажать кнопку "+ Добавить коллектор"

**Ожидаемый результат**:
- Появляется новая вкладка "Коллектор №2"
- Вкладка активна (выбрана)
- DataGrid отображает контуры коллектора №2

### TC-1.2.2: Переключение между коллекторами
**Предусловия**:
- Открыт экран "Гидравлический расчёт"
- 2 коллектора

**Шаги**:
1. Нажать на вкладку "Коллектор №1"
2. Проверить контуры
3. Нажать на вкладку "Коллектор №2"
4. Проверить контуры

**Ожидаемый результат**:
- При переключении отображаются контуры выбранного коллектора
- `SelectedCollectorIndex` обновляется

### TC-1.2.3: Удаление коллектора
**Предусловия**:
- Открыт экран "Гидравлический расчёт"
- 3 коллектора

**Шаги**:
1. Выбрать вкладку "Коллектор №2"
2. Нажать кнопку "- Удалить коллектор"
3. Подтвердить удаление

**Ожидаемый результат**:
- Вкладка "Коллектор №2" удалена
- Остались вкладки "Коллектор №1" и "Коллектор №2" (бывший №3)
- Активна вкладка "Коллектор №1"

### TC-1.2.4: Максимум коллекторов
**Предусловия**:
- Открыт экран "Гидравлический расчёт"
- 4 коллектора

**Шаги**:
1. Проверить состояние кнопки "+ Добавить коллектор"

**Ожидаемый результат**:
- Кнопка заблокирована (IsEnabled=False)
- Невозможно добавить 5-й коллектор

## 6. Критерии приёмки

- [ ] TabControl отображает список коллекторов
- [ ] Каждая вкладка имеет заголовок "Коллектор №{N}"
- [ ] При переключении вкладки обновляется `SelectedCollectorIndex`
- [ ] При переключении отображаются контуры выбранного коллектора
- [ ] При добавлении коллектора появляется новая вкладка
- [ ] При удалении коллектора вкладка удаляется
- [ ] Кнопка "+ Добавить коллектор" заблокирована при 4 коллекторах
- [ ] Существующий функционал не нарушен
