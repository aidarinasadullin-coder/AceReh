# Отчёт о тестировании задачи 1.2

## Задача
Добавить TabControl для коллекторов в `CircuitsView.xaml`

## Выполненные изменения

### 1. Изменён файл: `src/Views/Hydraulics/CircuitsView.xaml`

#### Структура изменений:

**До:**
```
Grid.Row="0" - Заголовок
Grid.Row="1" - Параметры теплоносителя
Grid.Row="2" - Свойства теплоносителя
Grid.Row="3" - Информация о коллекторе
Grid.Row="4" - DataGrid контуров
Grid.Row="5" - Кнопки управления
```

**После:**
```
Grid.Row="0" - Заголовок + кнопки управления коллекторами
Grid.Row="1" - (пустая строка для отступа)
Grid.Row="2" - TabControl для коллекторов
    TabItem.Content:
        - Параметры теплоносителя
        - Свойства теплоносителя
        - Информация о коллекторе (количество контуров, тип вентиля)
        - DataGrid контуров
        - Кнопки "+ Добавить контур" и "Рассчитать"
```

#### Ключевые изменения:

1. **Добавлен TabControl** с привязками:
   - `ItemsSource="{Binding Collectors}"` — коллекция коллекторов
   - `SelectedIndex="{Binding SelectedCollectorIndex, Mode=TwoWay}"` — выбранный коллектор

2. **ItemTemplate** — заголовок вкладки:
   ```xml
   <TextBlock Text="{Binding CollectorNumber, StringFormat='Коллектор №{0}'}"/>
   ```

3. **ContentTemplate** — содержимое вкладки:
   - Параметры теплоносителя (тип гликоли, концентрация, режим расчёта)
   - Свойства теплоносителя (рабочая и расчётная температура)
   - Информация о коллекторе (количество контуров, тип вентиля)
   - DataGrid контуров
   - Кнопки "+ Добавить контур" и "Рассчитать"

4. **Кнопки управления коллекторами** вынесены в заголовок:
   - "+ Добавить коллектор" — привязка к `AddCollectorCommand`
   - "- Удалить коллектор" — привязка к `RemoveCollectorCommand`

5. **Привязки внутри ContentTemplate** используют `RelativeSource` для доступа к DataContext:
   - `{Binding DataContext.GlycolType, RelativeSource={RelativeSource AncestorType=UserControl}}`
   - `{Binding DataContext.AddCircuitCommand, RelativeSource={RelativeSource AncestorType=UserControl}}`

## Технические детали

### MVVM привязки

1. **TabControl.ItemsSource** → `Collectors` (ObservableCollection<CollectorData>)
2. **TabControl.SelectedIndex** → `SelectedCollectorIndex` (TwoWay)
3. **TabItem.Header** → `CollectorNumber` (StringFormat='Коллектор №{0}')
4. **ContentTemplate DataContext** → CollectorData (текущий коллектор)

### Особенности реализации

1. **RelativeSource привязки** — внутри ContentTemplate DataContext указывает на CollectorData, поэтому для доступа к свойствам CircuitsViewModel используется `RelativeSource={RelativeSource AncestorType=UserControl}`

2. **Удалена информация о номере коллектора** — номер теперь отображается в заголовке вкладки

3. **Кнопки управления коллекторами** — вынесены в заголовок для удобства доступа
