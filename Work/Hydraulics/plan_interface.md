## 1. Обзор

### 1.1. Цель
Модификация интерфейса вкладки "Контур" (CircuitsView) для соответствия немецкому образцу расчёта (Berechnung.png). Добавление информационных блоков с входными данными, результатами расчёта и расширение таблицы контуров.

### 1.2. Связь с ТЗ
- **Файл ТЗ:** `Work/Hydraulics/technical_specification_interface.md`
- **Юзер-кейсы:** UC-1 (Входные данные), UC-2 (Данные укладки), UC-3 (Результаты коллектора), UC-4 (Переключение режима), UC-5 (Таблица с λ)

### 1.3. Принятые решения пользователя
1. **Расположение блоков:** В один ряд (слева направо)
2. **Режим отображения:** Активный режим (переключается кнопкой)
3. **Цветовое выделение:** При >320 мбар
4. **Пустые контуры:** Отображать с "—"
5. **Тип трубы:** Из ThermalViewModel
