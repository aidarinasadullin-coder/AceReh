## 3. АЛГОРИТМ РАСЧЁТА

### 3.1 Общий алгоритм балансировки

**Источник:** `CircuitsCalculator.cs` (строки 341-380)

```
1. Найти контур с максимальными потерями (референсный)
2. Для каждого контура:
   a. Рассчитать дросселирование: zu_drosseln = Δp_max - Δp_total
   b. Если zu_drosseln > 0:
      - Рассчитать Kv для дросселирования
      - Рассчитать обороты клапана
   c. Иначе:
      - Обороты = 0 (референсный контур)
```

### 3.2 Расчёт Kv для дросселирования

**Источник:** `CircuitsCalculator.cs` (строки 475-490)

```
Kv = V_dot / 1000 / √(Δp / 100000 / ρ[г/см³])
```

Где:
- `V_dot` — расход, л/ч
- `Δp` — дросселирование, Па
- `ρ` — плотность, г/см³

### 3.3 Пример расчёта

```
Дано:
- V_dot = 280 л/ч
- Δp = 5000 Па
- ρ = 1.053 г/см³

Расчёт:
1. flowRate_m3h = 280 / 1000 = 0.28 м³/ч
2. throttling_bar = 5000 / 100000 = 0.05 бар
3. Kv = 0.28 / √(0.05 / 1.053) = 0.28 / √0.0475 = 0.28 / 0.218 = 1.28 м³/ч

Для HKV-D:
Обороты = 4.2111 × 1.28³ - 6.7436 × 1.28² + 4.6613 × 1.28 - 0.712
       = 4.2111 × 2.097 - 6.7436 × 1.638 + 5.966 - 0.712
       = 8.83 - 11.05 + 5.966 - 0.712
       = 3.03 оборота
```

### 4.2 Что означает "без потерь на клапане"

**Источник:** `CircuitsCalculator.cs` (строки 362-376)

```csharp
// Референсный контур
circuit.IsReferenceCircuit = Math.Abs(circuit.OperatingResult.TotalLoss - maxPressureLoss) < 0.01;

// Расчёт оборотов клапана
if (circuit.Throttling > 0)
{
    // Kv для дросселирования
    double kv = CalculateKvForThrottling(...);
    circuit.ValveTurns = ValveTurnsCalculator.CalculateTurns(kv, valveType);
}
else
{
    circuit.ValveTurns = 0;  // Референсный контур
}
```

**Объяснение:**
- **Референсный контур** — контур с максимальными потерями давления
- Для референсного контура `ValveTurns = 0` — клапан полностью открыт
- Для остальных контуров рассчитывается дросселирование

### 4.3 Проверка максимального оборота

**ПРОБЛЕМА:** В коде **НЕТ проверки** на превышение максимального оборота (8).

**Рекомендация:** Добавить валидацию:
```csharp
if (circuit.ValveTurns > 8)
{
    // Предупреждение: невозможно сбалансировать контур
```

**Текущий формат:** Десятичное число с 1 знаком после запятой (например, "3.0")

### 6.2 Рекомендуемое отображение

**Проблема:** В технической документации РЕХАУ обороты часто указываются в виде дробей:
- "2 1/4" (два и одна четверть)
- "3 1/2" (три с половиной)
- "4 3/4" (четыре и три четверти)

**Рекомендация:** Создать конвертер для отображения в виде дробей:

```csharp
public class ValveTurnsToFractionConverter : IValueConverter
{
    public object Convert(object value, ...)
    {
        if (value is double turns)
        {
            // Округляем до 0.25
            double rounded = Math.Round(turns * 4) / 4;
            
            int whole = (int)rounded;
            double fraction = rounded - whole;
            
            return fraction switch
            {
                0.0 => whole.ToString(),
                0.25 => $"{whole} 1/4",
                0.5 => $"{whole} 1/2",
                0.75 => $"{whole} 3/4",
                _ => rounded.ToString("F1")
            };
        }
        return "—";
    }
}
```

## 7. НАЙДЕННЫЕ ПРОБЛЕМЫ

### 7.1 КРИТИЧЕСКИЕ ПРОБЛЕМЫ

#### ❌ Проблема 1: Отсутствие формул в документации

**Файл:** `docs/Formulas_Snegotayanie.md`  
**Описание:** В документации НЕТ формул расчёта оборотов клапана.  
**Источник формул:** Неизвестно.  
**Рекомендация:** Добавить раздел "14. РАСЧЁТ ОБОРОТОВ БАЛАНСИРОВОЧНОГО КЛАПАНА" в документацию.

#### ❌ Проблема 2: Превышение максимального оборота

**Описание:** Формулы для IV 1¼" и IV 1½" могут давать обороты > 8.  
**Пример:** При Kv = 2.0 для IV 1¼" обороты = 10.1 > 8.  
**Рекомендация:** Добавить валидацию и предупреждение пользователю.

### 7.2 СРЕДНИЕ ПРОБЛЕМЫ

#### ⚠ Проблема 3: Нет ограничения на минимальный оборот

**Описание:** Формула может давать отрицательные обороты при малых Kv.  
**Пример:** Для HKV-D при Kv < 0.8 формула даёт отрицательные значения.  
**Рекомендация:** Добавить проверку `Math.Max(0, turns)`.

#### ⚠ Проблема 4: Нет округления до 0.25 оборота

**Описание:** Клапаны РЕХАУ настраиваются с шагом 0.25 оборота.  
**Текущее поведение:** Округление до 0.1 оборота.  
**Рекомендация:** Изменить на `Math.Round(turns * 4) / 4`.

### 7.3 МИНОРНЫЕ ПРОБЛЕМЫ

#### ℹ Проблема 5: Отображение в виде десятичного числа

**Описание:** Пользователям привычнее видеть дроби (например, "2 1/4").  
**Рекомендация:** Создать конвертер для отображения в виде дробей.

#### ℹ Проблема 6: Нет визуальной индикации референсного контура

**Описание:** Референсный контур (ValveTurns = 0) не выделяется в UI.  
**Рекомендация:** Добавить цветовую индикацию или значок.

## 9. ПРЕДЛОЖЕНИЯ ПО УЛУЧШЕНИЮ КОДА

### 9.1 Добавить валидацию оборотов

```csharp
public static double CalculateTurns(double kv, ValveType valveType)
{
    double turns = valveType switch
    {
        ValveType.IV_1_5 => CalculateTurnsIV_1_5(kv),
        ValveType.IV_1_25 => CalculateTurnsIV_1_25(kv),
        ValveType.HKV_D => CalculateTurnsHKV_D(kv),
        _ => throw new ArgumentException($"Неподдерживаемый тип клапана: {valveType}", nameof(valveType))
    };

    // Округление до 0.25 оборота
    turns = Math.Round(turns * 4) / 4;
    
    // Ограничение диапазона
    turns = Math.Max(0, Math.Min(8, turns));
    
    return turns;
}
```

### 9.2 Добавить метод проверки валидности оборотов

```csharp
public static bool IsValidTurns(double turns, ValveType valveType)
{
    return turns >= 0 && turns <= 8;
}

public static string GetTurnsWarning(double turns, ValveType valveType)
{
    if (turns < 0)
        return "Отрицательные обороты недопустимы. Проверьте расчёт.";
    
    if (turns > 8)
        return $"Обороты ({turns:F1}) превышают максимум (8). Невозможно сбалансировать контур.";
    
    return null;
}
```

### 9.3 Добавить конвертер для отображения дробей

```csharp
public class ValveTurnsToFractionConverter : IValueConverter
{
    public object Convert(object value, Type targetType, object parameter, CultureInfo culture)
    {
        if (value is double turns)
        {
            // Округляем до 0.25
            double rounded = Math.Round(turns * 4) / 4;
            
            int whole = (int)rounded;
            double fraction = rounded - whole;
            
            string fractionStr = fraction switch
            {
                0.0 => "",
                0.25 => " 1/4",
                0.5 => " 1/2",
                0.75 => " 3/4",
                _ => $" {fraction:F2}"
            };
            
            if (whole == 0 && fraction > 0)
                return fractionStr.Trim();
            
            return $"{whole}{fractionStr}".Trim();
        }
        return "—";
    }
    
    public object ConvertBack(object value, Type targetType, object parameter, CultureInfo culture)
    {
        throw new NotImplementedException();
    }
}
```
