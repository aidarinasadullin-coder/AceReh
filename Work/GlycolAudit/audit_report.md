## 4. КОРНЕВАЯ ПРОБЛЕМА

### Описание проблемы

В `DesignGlycolProperties` записывается температура **наружного воздуха** (-15°C), а не температура теплоносителя!

При -15°C вязкость гликоля действительно **выше**, чем при +40°C:
- При -15°C (интерполяция): ~23 мм²/с
- При +40°C (интерполяция): ~0.9 мм²/с

### Физический смысл

Для расчёта "холодного пуска" (Design Temperature) должна использоваться:
- **Температура теплоносителя при пуске** (например, +5°C или +10°C)
- А НЕ температура наружного воздуха (-15°C)

### Текущая логика (НЕВЕРНАЯ)
```
DesignGlycolProperties.Temperature = AirTemperature (-15°C)
```

### Правильная логика
```
DesignGlycolProperties.Temperature = температура теплоносителя при пуске
```

## 5. Рекомендации

### Вариант A: Использовать температуру обратки для расчётного режима

Если система запускается при температуре наружного воздуха -15°C, то температура теплоносителя на входе может быть, например, +10°C (температура воды в системе перед запуском).

```csharp
// Для расчётного режима использовать температуру обратки или заданную температуру пуска
var designTemp = input.ReturnTemperature;  // или заданная температура пуска
```

### Вариант B: Добавить отдельное поле для температуры пуска

Добавить в `HydraulicInputData` поле `StartupTemperature` и использовать его для расчётного режима.

### Вариант C: Использовать температуру холодной пятидневки как температуру теплоносителя

Если по проекту теплоноситель действительно может быть при температуре -15°C (например, при использовании антифриза), то текущая логика верна, и вязкость должна быть выше.

## 8. Вопрос для уточнения

**Какая температура должна использоваться для расчётного режима (Design Temperature)?**

1. Температура наружного воздуха (текущая логика) — но тогда вязкость при -15°C будет выше, чем при +40°C
2. Температура теплоносителя при пуске (например, +10°C)
3. Температура обратки (например, +30°C)

---

## 9. Пример расчёта

### При текущей логике:
- Рабочая температура: +32.5°C → вязкость ~1.5 мм²/с
- Расчётная температура: -15°C → вязкость ~23 мм²/с

**Вязкость при -15°C ВЫШЕ, чем при +32.5°C** — это физически корректно!

### Если пользователь видит обратное:
Возможно, проблема в том, что пользователь ожидает, что "расчётная температура" — это температура теплоносителя, а не температура наружного воздуха.
