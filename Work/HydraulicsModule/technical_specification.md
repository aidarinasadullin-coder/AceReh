## 1. Общее описание

### 1.1. Краткое описание задачи

Модуль "Гидравлический расчёт" предназначен для расчёта гидравлических параметров контуров системы снеготаяния: скорости потока, числа Рейнольдса, коэффициента трения, потерь давления в трубах и вентилях. Модуль обеспечивает подбор коллекторов РЕХАУ и расчёт дросселирования контуров.

### 1.2. Цель разработки

Создать модуль для:
1. Расчёта гидравлических параметров одного контура (скорость, Re, λ, потери)
2. Поддержки всех режимов течения (ламинарный, переходный, турбулентный)
3. Расчёта потерь давления в трубах RAUTHERM и вентилях HKV/IV
4. Подбора коллекторов РЕХАУ по количеству контуров
5. Интеграции с ThermalModule через интерфейс `IThermalCalculationResult`

### 1.3. Связь с существующей системой

**Существующие компоненты:**
- `src/Models/Thermal/ThermalParameters.cs` — параметры теплового расчёта
- `src/Models/Thermal/ThermalCalculationResult.cs` — результат теплового расчёта
- `src/Models/Thermal/PipeType.cs` — типы труб RAUTHERM
- `src/Services/Thermal/ThermalCalculator.cs` — калькулятор теплового расчёта
- `data/glycol_data.json` — свойства гликолей (плотность, вязкость, теплоёмкость)
- `data/rehau_products.json` — продукция РЕХАУ (трубы, коллекторы)

**Интеграционные точки:**
- Получение `VolumeFlowRate` (расход) из `ThermalCalculationResult`
- Получение `SupplyTemperature`, `ReturnTemperature` из `ThermalCalculationResult`
- Получение `Pipe` из `ThermalParameters`
- Получение свойств теплоносителя из `glycol_data.json` по температуре и концентрации

## 2. Список юзер-кейсов

### UC-01: Расчёт гидравлических параметров контура

#### 2.1. Название
Расчёт гидравлических параметров одного контура

#### 2.2. Актёры
- Пользователь (инженер-проектировщик)
- Система (Калькулятор РЕХАУ)
- ThermalModule (источник данных)

#### 2.3. Предусловия
1. Тепловой расчёт выполнен (ThermalCalculationResult.IsValid = true)
2. Параметры теплоносителя заданы (доля гликоля, температура)
3. Труба выбрана (PipeType)
4. Длина контура задана (L_HK)
5. Длина подводки задана (L_Zul)

#### 2.4. Основной сценарий
1. Пользователь открывает вкладку "Гидравлика"
2. Система автоматически получает данные из ThermalModule:
   - Расход теплоносителя (VolumeFlowRate, л/(ч·м²))
   - Температуру подачи (SupplyTemperature, °C)
   - Температуру обратки (ReturnTemperature, °C)
   - Тип трубы (Pipe)
3. Пользователь вводит параметры контура:
   - Длина контура (L_HK), м
   - Длина подводки (L_Zul), м
   - Шаг укладки (VAHK), см
   - Шаг подводки (VAZul), см
4. Пользователь вводит параметры теплоносителя:
   - Доля гликоля (Glycolanteil), %
   - Тип гликоля (этиленгликоль/пропиленгликоль)
5. Система автоматически загружает свойства теплоносителя из `glycol_data.json`:
   - Плотность (ρ), кг/м³
   - Теплоёмкость (c_p), кДж/(кг·К)
   - Кинематическая вязкость (ν), мм²/с
6. Система выполняет расчёт:
   - Скорость потока (w), м/с
   - Число Рейнольдса (Re)
   - Режим течения (ламинарный/переходный/турбулентный)
   - Коэффициент трения (λ)
   - Удельные потери давления (R), Па/м
   - Потери давления в трубе (Δp_труба), Па
7. Система отображает результаты расчёта

#### 2.5. Альтернативные сценарии
- **А1: Тепловой расчёт не выполнен** — система отображает предупреждение "Сначала выполните тепловой расчёт"
- **А2: Некорректные входные данные** — система отображает ошибки валидации
- **А3: Выход за пределы базы данных** — система интерполирует значения свойств теплоносителя

#### 2.6. Постусловия
- Гидравлические параметры рассчитаны
- Результаты отображены пользователю
- Данные готовы для расчёта коллектора

#### 2.7. Критерии приёмки
- ✅ Скорость потока рассчитывается по формуле w = v × 1000 / (3600 × π × di² / 4)
- ✅ Число Рейнольдса рассчитывается по формуле Re = 1000 × w × di / ν
- ✅ Коэффициент трения λ определяется по режиму течения
- ✅ Удельные потери давления рассчитываются по формуле R = 1000 × (w² × ρ × λ) / (2 × di)
- ✅ Время расчёта < 10 мс

### UC-02: Определение режима течения

#### 2.1. Название
Автоматическое определение режима течения

#### 2.2. Актёры
- Система (Калькулятор РЕХАУ)

#### 2.3. Предусловия
1. Число Рейнольдса рассчитано (UC-01)

#### 2.4. Основной сценарий
1. Система проверяет значение Re:
   - Если Re < 2300 → ламинарный режим
   - Если 2300 ≤ Re ≤ 4000 → переходный режим
   - Если Re > 4000 → турбулентный режим
2. Система рассчитывает коэффициент трения λ:
   - **Ламинарный режим:** λ = 64 / Re (формула Пуазейля)
   - **Переходный режим:** λ = λ_lam + (Re - 2300) / 1700 × (λ_turb - λ_lam)
     - где λ_lam = 64 / 2300 ≈ 0.0278
     - λ_turb = ColebrookWhite(Re=4000)
   - **Турбулентный режим:** λ = ColebrookWhite(Re, di, k)
3. Система отображает режим течения и коэффициент трения

#### 2.5. Альтернативные сценарии
- **A1: Переходный режим** — система отображает предупреждение "Переходный режим течения. Рекомендуется изменить диаметр трубы или расход."

#### 2.6. Постусловия
- Режим течения определён
- Коэффициент трения рассчитан

#### 2.7. Критерии приёмки
- ✅ Ламинарный режим: Re < 2300, λ = 64 / Re
- ✅ Переходный режим: 2300 ≤ Re ≤ 4000, интерполяция
- ✅ Турбулентный режим: Re > 4000, формула Колбрука-Уайта
- ✅ Погрешность расчёта λ < 0.1%

### UC-03: Расчёт потерь давления в трубе

#### 2.1. Название
Расчёт потерь давления в трубе контура

#### 2.2. Актёры
- Пользователь (инженер-проектировщик)
- Система (Калькулятор РЕХАУ)

#### 2.3. Предусловия
1. Гидравлические параметры рассчитаны (UC-01)
2. Длина контура задана (L_HK)
3. Длина подводки задана (L_Zul)

#### 2.4. Основной сценарий
1. Система рассчитывает общую длину трубы:
   - L_общ = L_HK + L_Zul
2. Система рассчитывает потери давления в трубе:
   - Δp_труба = L_общ × R
3. Система отображает:
   - Потери в контуре (L_HK × R), Па
   - Потери в подводке (L_Zul × R), Па
   - Общие потери (Δp_труба), Па

#### 2.5. Альтернативные сценарии
- **A1: Разные диаметры** — если подводка имеет другой диаметр, расчёт выполняется раздельно

#### 2.6. Постусловия
- Потери давления в трубе рассчитаны

#### 2.7. Критерии приёмки
- ✅ Формула: Δp_труба = L × R
- ✅ Единицы измерения: Па (Паскаль)
- ✅ Отображение в кПа для удобства (1 кПа = 1000 Па)

### UC-04: Расчёт потерь давления в вентилях

#### 2.1. Название
Расчёт потерь давления в вентилях коллектора

#### 2.2. Актёры
- Пользователь (инженер-проектировщик)
- Система (Калькулятор РЕХАУ)

#### 2.3. Предусловия
1. Расход теплоносителя известен (v, л/ч)
2. Тип коллектора выбран (HKV-D или IV)

#### 2.4. Основной сценарий
1. Пользователь выбирает тип коллектора:
   - HKV-D (бытовой, 2-12 контуров)
   - IV 1¼" (промышленный)
   - IV 1½" (промышленный)
2. Система рассчитывает потери давления в вентилях:
   - **HKV-D:** Δp_вентиль = (v / 1000 / 1.2)² × 100000 × ρ
   - **IV 1¼":** Δp_вентиль = (v / 1000 / 1.45)² × 100000 × ρ
   - **IV 1½":** Δp_вентиль = (v / 1000 / 1.5)² × 100000 × ρ
3. Система отображает потери давления в вентиле

#### 2.5. Альтернативные сценарии
- **A1: Несколько контуров** — расчёт выполняется для каждого контура отдельно

#### 2.6. Постусловия
- Потери давления в вентилях рассчитаны

#### 2.7. Критерии приёмки
- ✅ Формула HKV-D: Δp = (v / 1000 / 1.2)² × 100000 × ρ
- ✅ Формула IV 1¼": Δp = (v / 1000 / 1.45)² × 100000 × ρ
- ✅ Формула IV 1½": Δp = (v / 1000 / 1.5)² × 100000 × ρ
- ✅ Единицы измерения: Па

### UC-08: Интеграция с ThermalModule

#### 2.1. Название
Получение данных из модуля теплового расчёта

#### 2.2. Актёры
- HydraulicsViewModel (получатель)

- IThermalCalculationResult (интерфейс)

#### 2.3. Предусловия
1. Тепловой расчёт выполнен
2. ThermalCalculationResult.IsValid = true

#### 2.4. Основной сценарий
1. HydraulicsViewModel подписывается на событие `ResultChanged`
2. ThermalViewModel выполняет расчёт и вызывает `RaiseResultChanged`
3. HydraulicsViewModel получает ThermalCalculationResult:
   - VolumeFlowRate (расход, л/(ч·м²))
   - SupplyTemperature (температура подачи, °C)
   - ReturnTemperature (температура обратки, °C)
   - PowerTotal (мощность, Вт/м²)
4. HydraulicsViewModel пересчитывает:
   - Расход на контур: v = VolumeFlowRate × Площадь_контура
   - Средняя температура: T_ср = (SupplyTemperature + ReturnTemperature) / 2
5. HydraulicsViewModel обновляет отображение

#### 2.5. Альтернативные сценарии
- **A1: Тепловой расчёт невалиден** — система отображает ошибку
- **A2: Площадь контура не задана** — система запрашивает ввод

#### 2.6. Постусловия
- Данные из ThermalModule получены
- Гидравлический расчёт готов к выполнению

#### 2.7. Критерии приёмки
- ✅ Автоматическое получение VolumeFlowRate
- ✅ Автоматическое получение температур
- ✅ Подписка на событие ResultChanged
- ✅ Обновление при изменении теплового расчёта

### 3.1. Класс HydraulicParameters (Параметры гидравлического расчёта)

```csharp
namespace SnowMeltingCalculator.Models.Hydraulics
{
    /// <summary>
    /// Параметры для гидравлического расчёта
    /// </summary>
    public class HydraulicParameters
    {
        // === Параметры контура ===
        
        /// <summary>
        /// Длина контура, м
        /// </summary>
        public double CircuitLength { get; set; }
        
        /// <summary>
        /// Длина подводки, м
        /// </summary>
        public double SupplyLength { get; set; }
        
        /// <summary>
        /// Шаг укладки, см
        /// </summary>
        public double PipeSpacing { get; set; }
        
        /// <summary>
        /// Шаг подводки, см
        /// </summary>
        public double SupplySpacing { get; set; }
        
        // === Параметры теплоносителя ===
        
        /// <summary>
        /// Доля гликоля, % (объёмные)
        /// </summary>
        public double GlycolConcentration { get; set; } = 50.0;
        
        /// <summary>
        /// Тип гликоля
        /// </summary>
        public GlycolType GlycolType { get; set; } = GlycolType.Ethylene;
        
        /// <summary>
        /// Температура подачи, °C
        /// </summary>
        public double SupplyTemperature { get; set; }
        
        /// <summary>
        /// Температура обратки, °C
        /// </summary>
        public double ReturnTemperature { get; set; }
        
        /// <summary>
        /// Плотность теплоносителя, кг/м³
        /// </summary>
        public double Density { get; set; }
        
        /// <summary>
        /// Кинематическая вязкость, мм²/с
        /// </summary>
        public double KinematicViscosity { get; set; }
        
        /// <summary>
        /// Теплоёмкость, кДж/(кг·К)
        /// </summary>
        public double SpecificHeat { get; set; }
        
        // === Параметры трубы ===
        
        /// <summary>
        /// Тип трубы
        /// </summary>
        public PipeType Pipe { get; set; } = PipeType.StandardPipes[1];
        
        /// <summary>
        /// Шероховатость трубы, мм
        /// </summary>
        public double Roughness { get; set; } = 0.007;
        
        // === Параметры из теплового расчёта ===
        
        /// <summary>
        /// Расход теплоносителя, л/(ч·м²)
        /// </summary>
        public double VolumeFlowRate { get; set; }
        
        /// <summary>
        /// Мощность контура, Вт/м²
        /// </summary>
        public double PowerPerArea { get; set; }
        
        /// <summary>
        /// Площадь контура, м²
        /// </summary>
        public double CircuitArea { get; set; }
    }
    
    /// <summary>
    /// Тип гликоля
    /// </summary>
    public enum GlycolType
    {
        Ethylene,
        Propylene
    }
}
```

### 3.2. Класс HydraulicResult (Результат гидравлического расчёта)

```csharp
namespace SnowMeltingCalculator.Models.Hydraulics
{
    /// <summary>
    /// Результат гидравлического расчёта
    /// </summary>
    public class HydraulicResult
    {
        // === Скорость и режим течения ===
        
        /// <summary>
        /// Скорость потока, м/с
        /// </summary>

        /// Число Рейнольдса
        /// </summary>

        public double FrictionFactor { get; set; }
        
        // === Потери давления ===
```

```csharp
namespace SnowMeltingCalculator.Services.Hydraulics
{
    public class HydraulicValidator
    {
        public ValidationResult Validate(HydraulicParameters parameters)
        {
            var errors = new List<string>();
            var warnings = new List<string>();
            
            // Проверка длины контура
            if (parameters.CircuitLength < 10 || parameters.CircuitLength > 500)
            {
                errors.Add($"Длина контура должна быть от 10 до 500 м (текущая: {parameters.CircuitLength:F1} м)");
            }
            
            // Проверка длины подводки
            if (parameters.SupplyLength < 1 || parameters.SupplyLength > 100)
            {
                errors.Add($"Длина подводки должна быть от 1 до 100 м (текущая: {parameters.SupplyLength:F1} м)");
            }
            
            // Проверка доли гликоля
            if (parameters.GlycolConcentration < 10 || parameters.GlycolConcentration > 90)
            {
                errors.Add($"Доля гликоля должна быть от 10 до 90% (текущая: {parameters.GlycolConcentration:F0}%)");
            }
            
            // Проверка температур
            if (parameters.SupplyTemperature < 20 || parameters.SupplyTemperature > 90)
            {
                errors.Add($"Температура подачи должна быть от 20 до 90°C (текущая: {parameters.SupplyTemperature:F1}°C)");
            }
            
            if (parameters.ReturnTemperature < 15 || parameters.ReturnTemperature > 80)
            {
                errors.Add($"Температура обратки должна быть от 15 до 80°C (текущая: {parameters.ReturnTemperature:F1}°C)");
            }
            
            // Проверка трубы
            if (parameters.Pipe == null)
            {
                errors.Add("Тип трубы не задан");
            }
            
            // Проверка плотности
            if (parameters.Density <= 0)
            {
                errors.Add("Плотность теплоносителя должна быть положительной");
            }
            
            // Проверка вязкости
            if (parameters.KinematicViscosity <= 0)
            {
                errors.Add("Кинематическая вязкость должна быть положительной");
            }
            
            return new ValidationResult
            {
                IsValid = errors.Count == 0,
                Errors = errors,
                Warnings = warnings
            };
        }
        
        public ValidationResult ValidateResult(HydraulicResult result)
        {
            var warnings = new List<string>();
            
            // Проверка скорости потока
            if (result.Velocity < 0.2)
            {
                warnings.Add($"Скорость потока низкая ({result.Velocity:F3} м/с). Возможны проблемы с теплоотдачей.");
            }
            else if (result.Velocity > 1.5)
            {
                warnings.Add($"Скорость потока высокая ({result.Velocity:F3} м/с). Рекомендуется увеличить диаметр трубы.");
            }
            
            // Проверка режима течения
            if (result.FlowRegime == FlowRegime.Transitional)
            {
                warnings.Add("Переходный режим течения (2300 ≤ Re ≤ 4000). Рекомендуется изменить параметры для обеспечения стабильного течения.");
            }
            
            return new ValidationResult
            {
                IsValid = true,
                Errors = Array.Empty<string>(),
                Warnings = warnings
            };
        }
```

### 9.1. Таблица единиц измерения

| Параметр | Единица СИ | Единица в формулах | Преобразование |
|----------|------------|-------------------|----------------|
| Скорость (w) | м/с | м/с | — |
| Диаметр (di) | м | мм | × 1000 |
| Вязкость (ν) | м²/с | мм²/с | × 10⁶ |
| Плотность (ρ) | кг/м³ | кг/м³ | — |
| Расход (v) | м³/с | л/ч | × 3.6 × 10⁶ |

| Потери (R) | Па/м | Па/м | — |

### 9.2. Преобразования единиц

**Расход:**
- 1 л/ч = 1 / 3600 м³/с = 2.778 × 10⁻⁷ м³/с
- v [м³/с] = v [л/ч] / 3600000

**Диаметр:**
- di [м] = di [мм] / 1000

**Вязкость:**
- ν [м²/с] = ν [мм²/с] × 10⁻⁶

## 10. Приложение: Формулы расчёта

### 10.1. Скорость потока

```
w = (v / 3600) / (π × di² / 4 / 1000000)    [м/с]

где:
- v — расход, л/ч
- di — внутренний диаметр, мм
- π — число Пи (3.141593)
```

**Альтернативная форма:**
```
w = v × 1000 / (3600 × π × di² / 4)    [м/с]
```

**Пример расчёта:**
```
Дано:
- v = 100 л/ч
- di = 16 мм

Расчёт:
w = (100 / 3600) / (π × 16² / 4 / 1000000)
w = 0.02778 / (π × 256 / 4 / 1000000)
w = 0.02778 / 0.00020106
w = 0.138 м/с
```

---

### 10.2. Число Рейнольдса

```
Re = 1000 × w × di / ν    [безразмерный]

где:
- w — скорость, м/с
- di — внутренний диаметр, мм
- ν — кинематическая вязкость, мм²/с
```

**Физический смысл:**
Число Рейнольдса определяет режим течения:
- Re < 2300 — ламинарный режим
- 2300 ≤ Re ≤ 4000 — переходный режим
- Re > 4000 — турбулентный режим

**Пример расчёта:**
```
Дано:
- w = 0.5 м/с
- di = 16 мм
- ν = 2.16 мм²/с

Расчёт:
Re = 1000 × 0.5 × 16 / 2.16
Re = 8000 / 2.16
Re = 3704

Режим течения: переходный (2300 ≤ 3704 ≤ 4000)
```

**Проверка через единицы СИ:**
```
Re = w × di / ν
Re = 0.5 × 0.016 / (2.16 × 10⁻⁶)
Re = 0.008 / 0.00000216
Re = 3704 ✓
```

---

### 10.3. Коэффициент трения λ

**Ламинарный режим (Re < 2300):**
```
λ = 64 / Re    (формула Пуазейля)
```

**Пример (ламинарный режим):**
```
Дано: Re = 2000

Расчёт:
λ = 64 / 2000 = 0.032
```

**Переходный режим (2300 ≤ Re ≤ 4000):**
```
λ = λ_lam + (Re - 2300) / 1700 × (λ_turb - λ_lam)

где:
- λ_lam = 64 / 2300 ≈ 0.0278
- λ_turb = ColebrookWhite(Re=4000, di, k)
```

**Пример (переходный режим):**
```
Дано:
- Re = 3000
- di = 16 мм
- k = 0.007 мм

Расчёт:
λ_lam = 64 / 2300 = 0.0278
λ_turb = ColebrookWhite(4000, 16, 0.007) ≈ 0.041
λ = 0.0278 + (3000 - 2300) / 1700 × (0.041 - 0.0278)
λ = 0.0278 + 0.412 × 0.0132
λ = 0.0332
```

**Турбулентный режим (Re > 4000):**
```
λ = (1 / (-2 × LOG(k/(3.71×di) + 2.51/(Re×√λ))))²    (формула Колбрука-Уайта)

где:
- k — шероховатость, мм (0.007 для PE-Xa)
- di — внутренний диаметр, мм
- Re — число Рейнольдса
```

**Итерационное решение Колбрука-Уайта:**
```csharp
double lambda = 0.02; // Начальное приближение
for (int i = 0; i < 20; i++)
{
    double newLambda = Math.Pow(
        1.0 / (-2.0 * Math.Log10(k / (3.71 * di) + 2.51 / (Re * Math.Sqrt(lambda)))),
        2);
    if (Math.Abs(newLambda - lambda) < 0.000001) break;
    lambda = newLambda;
}
```

**Пример (турбулентный режим):**
```
Дано:
- Re = 10000
- di = 16 мм
- k = 0.007 мм

Итерации:
λ₀ = 0.02
λ₁ = 0.0312
λ₂ = 0.0305
λ₃ = 0.0306
λ₄ = 0.0306

Результат: λ ≈ 0.0306
```

### 10.4. Удельные потери давления

```
R = 1000 × (w² × ρ × λ) / (2 × di)    [Па/м]

где:
- w — скорость, м/с
- ρ — плотность, кг/м³
- λ — коэффициент трения (безразмерный)
- di — внутренний диаметр, мм
```

**Пример расчёта:**
```
Дано:
- w = 0.5 м/с
- ρ = 1053 кг/м³
- λ = 0.04
- di = 16 мм

Расчёт:
R = 1000 × (0.5² × 1053 × 0.04) / (2 × 16)
R = 1000 × (0.25 × 1053 × 0.04) / 32
R = 1000 × 10.53 / 32
R = 329 Па/м
```

**Проверка через единицы СИ:**
```
R = λ × ρ × w² / (2 × di)
R = 0.04 × 1053 × 0.25 / (2 × 0.016)
R = 10.53 / 0.032
R = 329 Па/м ✓
```

### 10.5. Потери давления в трубе

```
Δp_труба = L × R    [Па]

где:
- L — длина трубы, м
- R — удельные потери давления, Па/м
```

**Пример расчёта:**
```
Дано:
- L = 100 м
- R = 329 Па/м

Расчёт:
Δp_труба = 100 × 329 = 32900 Па = 32.9 кПа
```

---

### 10.6. Потери давления в вентилях

**Общая формула:**
```
Δp_вентиль = (v / 1000 / Kv)² × 100000 × ρ    [Па]

где:
- v — расход, л/ч
- Kv — коэффициент вентиля (безразмерный)
- ρ — плотность, кг/м³
- 1000 — преобразование л/ч → м³/ч
- 100000 — преобразование бар → Па (1 бар = 100000 Па)
```

**Коэффициенты Kv:**
- HKV-D: Kv = 1.2
- IV 1¼": Kv = 1.45
- IV 1½": Kv = 1.5

**HKV-D:**
```
Δp_вентиль = (v / 1000 / 1.2)² × 100000 × ρ    [Па]
```

**IV 1¼":**
```
Δp_вентиль = (v / 1000 / 1.45)² × 100000 × ρ    [Па]
```

**IV 1½":**
```
Δp_вентиль = (v / 1000 / 1.5)² × 100000 × ρ    [Па]
```

**Пример расчёта (HKV-D):**
```
Дано:
- v = 100 л/ч
- ρ = 1053 кг/м³
- Kv = 1.2

Расчёт:
Δp_вентиль = (100 / 1000 / 1.2)² × 100000 × 1053
Δp_вентиль = (0.0833)² × 100000 × 1053
Δp_вентиль = 0.00694 × 100000 × 1053
Δp_вентиль = 730000 Па = 7.3 бар
```

**Проверка:**
```
v = 100 л/ч = 0.1 м³/ч = 2.78 × 10⁻⁵ м³/с
Q = v / Kv = 100 / 1.2 = 83.3 л/ч (эквивалентный расход)
Δp = (Q / 1000)² × 100000 × ρ
Δp = (83.3 / 1000)² × 100000 × 1053
Δp = 0.00694 × 100000 × 1053
Δp = 730000 Па ✓
```

### 10.7. Дросселирование для балансировки

```
zu_drosseln = Δp_max - Δp_контур - Δp_вентиль    [Па]

где:
- Δp_max — максимальные потери среди всех контуров
- Δp_контур — потери давления в контуре
- Δp_вентиль — потери давления в вентиле
```

**Пример расчёта:**
```
Дано:
- Δp_max = 50000 Па (контур с максимальными потерями)
- Δp_контур = 30000 Па
- Δp_вентиль = 5000 Па

Расчёт:
zu_drosseln = 50000 - 30000 - 5000 = 15000 Па = 15 кПа
```
