# Статус разработки: Модуль "Гидравлика"

## Задача
Разработка модуля гидравлического расчёта для Калькулятора снеготаяния РЕХАУ.

## Описание модуля
Модуль предназначен для расчёта гидравлических параметров системы снеготаяния:
- Скорость потока теплоносителя
- Число Рейнольдса (Re)
- Коэффициент гидравлического трения (λ) для разных режимов течения
- Потери давления в трубах и вентилях
- Подбор диаметров труб и коллекторов
