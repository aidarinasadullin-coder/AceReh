## 2. Найденные формулы

### 2.1. Формула расхода теплоносителя

**Расположение:** `src/Services/Hydraulics/CircuitsCalculator.cs`, метод `CalculateFlowRate` (строки 112-132)

**Код:**
```csharp
public double CalculateFlowRate(double power, double deltaT, double density, double specificHeat)
{
    // V_dot = Q_HK × 3.6 / (ρ × c_p × ΔT)
    // Результат в м³/ч, переводим в л/ч
    double flowRate_m3h = power * 3.6 / (density * specificHeat * deltaT);
    double flowRate_lh = flowRate_m3h * 1000;
    return flowRate_lh;
}
```

**Формула из документации** (`docs/Formulas_Snegotayanie.md`, раздел 11.4):
```
V_dot = Q_HK × 3,6 / (ρ × c_p × ΔT)    [л/ч]
```

### 2.2. Входные параметры

| Параметр | Обозначение | Единица | Источник |
|----------|-------------|---------|----------|
| Мощность контура | Q_HK | Вт | `CircuitRow.Power` |
| Температурный перепад | ΔT | К | `HydraulicInputData.DeltaT` |
| Плотность | ρ | кг/м³ | `GlycolProperties.Density` |
| Удельная теплоёмкость | c_p | кДж/(кг·К) | `GlycolProperties.SpecificHeat` |

### 2.3. Вычисление температурного перепада

**Расположение:** `src/Models/Hydraulics/HydraulicInputData.cs` (строки 143-149)

**Код:**
```csharp
/// <summary>
/// Температурный перепад (ΔT), К
/// </summary>
/// <remarks>
/// Формула: ΔT = T_supply - T_return
/// </remarks>
public double DeltaT => SupplyTemperature - ReturnTemperature;
```

## 3. Проверка корректности формулы

### 3.1. Теоретический вывод

**Исходная формула (массовый расход):**
```
ṁ = Q / (c_p × ΔT)    [кг/с]
```

Где:
- Q — мощность, Вт = Дж/с
- c_p — удельная теплоёмкость, Дж/(кг·К)
- ΔT — температурный перепад, К

**Перевод единиц:**
- c_p в коде передаётся в кДж/(кг·К) = 1000 Дж/(кг·К)
- Поэтому: ṁ = Q / (c_p × 1000 × ΔT) [кг/с]

**Объёмный расход:**
```
V_dot = ṁ / ρ    [м³/с]
```

Где ρ — плотность, кг/м³

**Перевод в л/ч:**
```
V_dot [л/ч] = V_dot [м³/с] × 3600 [с/ч] × 1000 [л/м³]
            = Q × 3600 / (c_p × 1000 × ΔT × ρ) × 1000
            = Q × 3.6 / (c_p × ΔT × ρ) × 1000
```

### 3.2. Сравнение с кодом

**Формула в коде:**
```
V_dot = power × 3.6 / (density × specificHeat × deltaT) × 1000
```

**Результат:** ✅ Формула корректна!

### 3.3. Проверка примера из документации

**Дано:**
- Q_HK = 5246 Вт
- ρ = 1053 кг/м³
- c_p = 3.21 кДж/(кг·К)
- ΔT = 10 К

**Расчёт:**
```
V_dot = 5246 × 3.6 / (1053 × 3.21 × 10) × 1000
      = 18885.6 / 33801.3 × 1000
      = 0.5587 × 1000
      = 558.7 л/ч
```

**В документации указано:** 560 л/ч (округление)

**Результат:** ✅ Пример совпадает!

## 5. Зависимости расчёта

### 5.1. Зависимость расхода от мощности

```
V_dot ∝ Q_HK
```

При увеличении мощности в 2 раза, расход увеличивается в 2 раза.

### 5.2. Зависимость расхода от температурного перепада

```
V_dot ∝ 1 / ΔT
```

При увеличении ΔT в 2 раза, расход уменьшается в 2 раза.

### 5.3. Зависимость расхода от свойств теплоносителя

```
V_dot ∝ 1 / (ρ × c_p)
```

При увеличении плотности или теплоёмкости, расход уменьшается.

**Пример для 50% этиленгликоля при 40°C:**
- ρ = 1053 кг/м³
- c_p = 3.21 кДж/(кг·К)
- Произведение: ρ × c_p = 3380

**Пример для воды при 40°C:**
- ρ = 992 кг/м³
- c_p = 4.18 кДж/(кг·К)
- Произведение: ρ × c_p = 4147

**Отношение:** 4147 / 3380 = 1.23

**Вывод:** Расход воды на 23% меньше, чем расход гликоля при той же мощности и ΔT.

### 8.2. Вопрос о расчёте при двух температурах

**Статус:** Требует уточнения

**Описание:** Расчёт выполняется при двух температурах:
- Рабочая температура: `T_operating = (T_supply + T_return) / 2`
- Расчётная температура: `T_design = t_cold`

**Вопрос:** Должен ли расход рассчитываться при обеих температурах или только при рабочей?

**Текущее поведение:** Расход рассчитывается один раз при рабочей температуре.
