## 2. Проблемы

### 2.1. Критическая проблема: Ввод ΔT не влияет на расчёт

**Описание:**  
Пользователь вводит `DeltaT` в поле ввода, но это значение:
1. НЕ используется для расчёта температур (T_supply вводится, T_return рассчитывается)
2. НЕ влияет на результат расчёта
3. Создаёт ложное впечатление, что пользователь контролирует ΔT

**Формула расчёта (из ThermalCalculator.cs):**
```
T_mean = JHmü + t_H           // Средняя температура (рассчитывается)
T_supply = ввод пользователя  // Температура подачи (вводится)
T_return = 2 × T_mean - T_supply  // Температура обратки (рассчитывается)
ΔT = T_supply - T_return      // Температурный перепад (рассчитывается!)
```

### 2.2. Проблема валидации

**Описание:**  
Валидация `parameters.DeltaT` в ThermalCalculator.cs (строки 598-601) проверяет значение, которое не используется в расчёте:
```csharp
if (parameters.DeltaT <= 0 || parameters.DeltaT > 30)
{
    errorList.Add("Температурный перепад должен быть в диапазоне от 1 до 30 К");
}
```

### 2.3. Проблема UX: Нет подсказки для пользователя

**Описание:**  
Пользователь не знает, какую температуру подачи выбрать. Согласно документации:
- Рекомендуемый ΔT: 10-15 К
- Оптимальное значение: 15 К

Но нет подсказки вида: "Рекомендуемая температура подачи: X°C (для ΔT ≈ 15 К)"

### 2.4. Проблема расчёта расхода

**Описание:**  
В строке 470 используется `result.DeltaT` (рассчитанный), что корректно:
```csharp
result.MassFlowRate = result.PowerTotal / (cp / 3.6) / result.DeltaT;
```

Но `parameters.DeltaT` (введённый пользователем) нигде не используется!

```xml
           Style="{StaticResource MaterialDesignBody1TextBlock}"

```

#### 3.1.4. Добавить подсказку для температуры подачи

**Формула для рекомендуемой температуры подачи:**
```
T_supply_recommended = T_mean + ΔT_optimal / 2
                     = T_mean + 7.5
```
где ΔT_optimal = 15 К (оптимальное значение)

**Реализация в ThermalViewModel:**
```csharp

/// </summary>

/// Подсказка для пользователя
/// </summary>

    ? $"Рекомендуемая температура подачи: {RecommendedSupplyTemperature:F1}°C (для ΔT ≈ 15 К)"
    : "Выполните расчёт для получения рекомендации";
```

**Реализация в ThermalView.xaml:**
```xml
<!-- Подсказка для температуры подачи -->

           Visibility="{Binding Result, Converter={StaticResource NullToVisibilityConverter}}">

                            VerticalAlignment="Center"

              VerticalAlignment="Center"

              FontSize="12"/>
```

## 4. Формула для подсказки температуры подачи

### 4.1. Математическое обоснование

Из формул раздела 8 документации:
```
T_mean = JHmü + t_H           // Средняя температура (рассчитывается)
T_supply = ввод пользователя  // Температура подачи
T_return = 2 × T_mean - T_supply  // Температура обратки
ΔT = T_supply - T_return      // Температурный перепад
```

Раскроем ΔT:
```
ΔT = T_supply - T_return
ΔT = T_supply - (2 × T_mean - T_supply)
ΔT = 2 × T_supply - 2 × T_mean
T_supply = T_mean + ΔT / 2
```

### 4.2. Рекомендуемое значение

Согласно разделу 1.5 документации:
- **Рекомендуемый ΔT:** 10-15 К
- **Оптимальное значение:** 15 К

**Формула подсказки:**
```
T_supply_recommended = T_mean + 15 / 2 = T_mean + 7.5
```

### 4.3. Пример расчёта

| Параметр | Значение |
|----------|----------|
| T_mean (рассчитано) | 35.0°C |
| ΔT_optimal | 15 К |
| **T_supply_recommended** | **35.0 + 7.5 = 42.5°C** |
| T_return (рассчитано) | 35.0 - 7.5 = 27.5°C |
| ΔT (рассчитано) | 42.5 - 27.5 = 15 К ✓ |
