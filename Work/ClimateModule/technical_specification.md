## 1. Общее описание

### 1.1. Название модуля
Модуль климатических данных (Climate Data Module)

### 1.2. Цель и назначение
Модуль предназначен для выбора и настройки климатических параметров, необходимых для проведения теплового расчёта систем снеготаяния открытых площадок. Модуль обеспечивает:
- Выбор города из справочника 550 городов РФ
- Автоматическое заполнение климатических данных из СП 131.13330.2025
- Ручной ввод и корректировку параметров
- Определение расчётной температуры на основе региона
- Предоставление данных для теплового расчёта

### 1.3. Связь с существующей системой
Модуль является первым шагом в цепочке расчёта и передаёт данные в:
- **Модуль конструкции** — для определения тепловых характеристик покрытия
- **Тепловой расчёт** — расчёт требуемой мощности системы
- **Гидравлический расчёт** — учёт параметров теплоносителя

### 1.4. Нормативная база
- **СП 131.13330.2025** «Строительная климатология и геофизика»
- **EN 1264-2** — системы тёплых полов (применимые положения)

## 3. Выходные данные (для других модулей)

### 3.1. Климатические параметры расчёта

| Параметр | Тип | Диапазон | Описание |
|----------|-----|----------|----------|
| `SelectedCity` | string | — | Выбранный город |
| `SelectedRegion` | string | — | Регион города |
| `AirTemperature` | double | -50 до +10°C | Расчётная температура наружного воздуха |
| `WindSpeed` | double | 0.1 до 30 м/с | Скорость ветра |
| `Humidity` | double | 20 до 100% | Относительная влажность воздуха |
| `SnowfallIntensity` | double | 0.1 до 5 см/ч | Интенсивность снегопада (ручной ввод) |
| `ClimateZone` | enum | Zone_M10, Zone_M15, Zone_M20, Zone_M20_Plus | Зона по температуре холодной пятидневки |

### 3.2. Перечисление климатических зон

```csharp
public enum ClimateZone
{
    Zone_M10,    // t_5days_092 ≥ -27°C (колонка -10°C)
    Zone_M15,    // -37°C < t_5days_092 < -27°C (колонка -15°C)
    Zone_M20,    // t_5days_092 ≤ -37°C (колонка -20°C)
    Zone_M20_Plus // Повышенные требования (вручную, колонка -20°C)
}
```

### 3.3. Интерфейс передачи данных

```csharp
public interface IClimateData
{
    // Идентификация
    string SelectedCity { get; }
    string SelectedRegion { get; }
    
    // Температурные параметры
    double AirTemperature { get; }           // Расчётная t наружного воздуха
    double ColdFiveDayTemperature { get; }   // t_5days_092 из СП
    
    // Ветер и влажность
    double WindSpeed { get; }
    double Humidity { get; }
    
    // Снегопад (ручной ввод)
    double SnowfallIntensity { get; }
    
    // Зона
    ClimateZone Zone { get; }
    
    // Событие изменения данных
    event EventHandler<ClimateDataChangedEventArgs> DataChanged;
}
```

## 4. Функциональные требования

### 4.1. Use Case UC-1: Выбор города из справочника

#### 4.1.1. Актёры
- **Пользователь** — инженер-проектировщик
- **Система** — Калькулятор снеготаяния РЕХАУ

#### 4.1.2. Предусловия
- Пользователь находится на экране «Климатические данные»
- Файл `climate_db.json` доступен и не повреждён

#### 4.1.3. Основной сценарий

| Шаг | Действие пользователя | Действие системы | Результат |
|-----|----------------------|------------------|-----------|
| 1 | Нажимает на поле «Выбор города» | Открывает выпадающий список с поиском | Отображается поле ввода и список городов (первые 50) |
| 2 | Начинает вводить название города (мин. 2 символа) | Выполняет поиск по полю `city` с учётом регистра | Отображает отфильтрованный список (макс. 20 результатов) |
| 3 | Выбирает город из списка | Загружает данные города из JSON | Выбранный город отображается в поле |
| 4 | — | Автоматически заполняет поля: | Все поля заполнены данными из СП |
|  |  | • `AirTemperature` = `t_5days_092` |  |
|  |  | • `WindSpeed` = `wind_max_jan` |  |
|  |  | • `Humidity` = `humidity_15h_cold` |  |
|  |  | • Отображает `region` |  |
| 5 | — | Определяет `ClimateZone` на основе `t_5days_092`: | Отображается зона (-10, -15, -20) |
|  |  | • ≥ -27°C → Zone_M10 |  |
|  |  | • от -27°C до -37°C → Zone_M15 |  |
|  |  | • ≤ -37°C → Zone_M20 |  |
| 6 | — | Вызывает событие `DataChanged` | Другие модули получают обновление |

#### 4.1.4. Альтернативный сценарий А1: Город не найден

| Шаг | Условие | Действие системы |
|-----|---------|------------------|
| А1.1 | Поиск не дал результатов | Отображает сообщение: «Город не найден. Введите параметры вручную» |
| А1.2 | — | Предлагает ручной ввод всех параметров |
| А1.3 | — | Поля остаются пустыми/с дефолтными значениями |

#### 4.1.5. Альтернативный сценарий А2: Пользователь редактирует автозаполненные данные

| Шаг | Действие пользователя | Действие системы |
|-----|----------------------|------------------|
| А2.1 | Изменяет значение в любом поле | Помечает поле как «изменено пользователем» (иконка/цвет) |
| А2.2 | — | Сохраняет пользовательское значение |
| А2.3 | Выбирает другой город | Показывает диалог: «Сохранить изменения? Да/Нет/Отмена» |

#### 4.1.6. Постусловия
- Все климатические параметры определены
- Данные валидны и готовы для передачи в тепловой расчёт

#### 4.1.7. Критерии приёмки
- ✅ Поиск работает по вводу от 2 символов
- ✅ Список отображает до 20 результатов
- ✅ Поиск выполняется за < 100 мс (550 записей)
- ✅ Автозаполнение срабатывает при выборе города
- ✅ Определение зоны корректно для всех диапазонов температур

#### 4.3.3. Критерии приёмки
- ✅ Чекбокс доступен всегда
- ✅ При активации показывается предупреждение
- ✅ В UI визуально выделяется, что выбраны повышенные требования

## 5. Валидация данных

### 5.1. Правила валидации

| Поле | Минимум | Максимум | Точность | Сообщение об ошибке |
|------|---------|----------|----------|---------------------|
| `AirTemperature` | -50°C | +10°C | 0.1°C | «Температура должна быть от -50°C до +10°C» |
| `WindSpeed` | 0.1 м/с | 30 м/с | 0.1 м/с | «Скорость ветра от 0.1 до 30 м/с» |
| `Humidity` | 20% | 100% | 1% | «Влажность от 20% до 100%» |
| `SnowfallIntensity` | 0.1 см/ч | 5 см/ч | 0.1 см/ч | «Интенсивность от 0.1 до 5 см/ч» |

### 5.2. Поведение при ошибке
1. Поле с ошибкой подсвечивается красной рамкой
2. Отображается иконка ошибки с ToolTip
3. Кнопка «Далее»/«Рассчитать» блокируется
4. При наведении показывается сообщение об ошибке

### 5.3. Предупреждения (не блокирующие)

| Условие | Предупреждение |
|---------|---------------|
| t_5days_092 > -10°C | «Внимание: в вашем регионе редко образуется снежный покров. Система снеготаяния может быть нецелесообразна» |
| SnowfallIntensity > 1.0 см/ч | «Высокая интенсивность снегопада. Убедитесь в корректности значения» |
| WindSpeed > 15 м/с | «Высокая скорость ветра. Рекомендуется усиленная теплоизоляция» |

## 7. Интерфейсы модуля

### 7.1. Публичный API (для ViewModel)

```csharp
public interface IClimateModule
{
    // Свойства для привязки к UI
    ObservableCollection<CityInfo> FilteredCities { get; }
    CityInfo SelectedCity { get; set; }
    
    // Климатические параметры
    double AirTemperature { get; set; }
    double WindSpeed { get; set; }
    double Humidity { get; set; }
    double SnowfallIntensity { get; set; }
    ClimateZone SelectedZone { get; set; }
    bool IsHighRequirements { get; set; }
    
    // Состояние
    bool IsValid { get; }
    string ValidationMessage { get; }
    bool HasUserModifications { get; }
    
    // Методы
    Task LoadClimateDataAsync();
    void SearchCities(string query);
    void ResetToDefaults();
    void ResetToCityData();
    IClimateData GetClimateData();
    
    // События
    event EventHandler<ClimateDataChangedEventArgs> DataChanged;
    event EventHandler<ValidationEventArgs> ValidationChanged;
}

public class CityInfo
{
    public string Name { get; set; }
    public string Region { get; set; }
    public double T5Days092 { get; set; }
    public double WindMaxJan { get; set; }
    public double Humidity15hCold { get; set; }
}

public class ClimateDataChangedEventArgs : EventArgs
{
    public string ChangedProperty { get; set; }
    public object OldValue { get; set; }
    public object NewValue { get; set; }
    public bool IsValid { get; set; }
}
```

### 7.2. События изменения данных

| Событие | Описание | Когда вызывается |
|---------|----------|----------------|
| `DataChanged` | Любое изменение климатических данных | При изменении любого параметра |
| `CityChanged` | Изменён выбранный город | При выборе/смене города |
| `ZoneChanged` | Изменена климатическая зона | При автоматическом/ручном изменении |

### 9.3. Тестовые сценарии

#### TC-1: Выбор города Москва
1. Ввести «Москва» → найти город
2. Проверить автозаполнение:
   - AirTemperature = -28 (примерное значение)
   - Zone = Zone_M15 (т.к. -27 > t > -37)

#### TC-2: Выбор города Сочи
1. Ввести «Сочи» → найти город
2. Проверить автозаполнение:
   - AirTemperature > -10
   - Zone = Zone_M10
   - Показано предупреждение о снежном покрове

#### TC-3: Ручной ввод
1. Очистить выбор города
2. Ввести вручную:
   - AirTemperature = -20
   - WindSpeed = 10
   - Humidity = 80
   - SnowfallIntensity = 0.5
3. Убедиться, что расчёт работает

#### TC-4: Повышенные требования
1. Выбрать город с Zone_M10
2. Установить чекбокс «Повышенные требования»
3. Убедиться, что в расчёте используется колонка -20°C

    Zone = Zone_M10
