## 1. Общее описание

### 1.1. Название модуля
Модуль теплового расчёта (Thermal Calculation Module)

### 1.2. Цель и назначение
Модуль предназначен для расчёта требуемой мощности системы снеготаяния на основе климатических данных, конструкции покрытия и параметров теплоносителя. Расчёт выполняется по методике Chapman-Katunich с поправками EN 1264-2.

### 1.3. Связь с другими модулями
- **Вход:** Модуль климатических данных (IClimateData)
- **Вход:** Модуль конструкции (IConstructionData) — слои покрытия
- **Выход:** Модуль гидравлического расчёта — мощность, расход
- **Выход:** Модуль отчётов — результаты расчёта

### 1.4. Нормативная база
- **СП 131.13330.2025** — климатология
- **EN 1264-2** — системы тёплых полов
- **Паспорта РЕХАУ** — трубы RAUTHERM S

## 3. Выходные данные

### 3.1. Результаты теплового расчёта

| Коэффициент теплоотдачи | α | Вт/м²·К | На поверхности |

| Температура подачи | T_supply | °C | Вводится пользователем |
| Температура обратки | T_return | °C | Рассчитывается |
| Массовый расход | ṁ | кг/(ч·м²) | Массовый расход теплоносителя |
| Объёмный расход | V_dot | л/(ч·м²) | Объёмный расход теплоносителя |

### 3.2. Интерфейс передачи данных

```csharp
public interface IThermalCalculationResult
{
    // Коэффициенты
    double Alpha { get; }              // Вт/м²·К
    
    // Мощности
    double PowerUp { get; }            // Вт/м² (q_FB)
    double PowerDown { get; }          // Вт/м² (q_D)
    double PowerTotal { get; }         // Вт/м² (q_total)
    
    // Температуры
    double ExcessTemperature { get; }  // °C (JHmü)
    double MeanTemperature { get; }    // °C (T_mean)
    double SupplyTemperature { get; }  // °C (T_supply)
    double ReturnTemperature { get; }  // °C (T_return)
    double DeltaT { get; }             // К
    
    // Расходы
    double MassFlowRate { get; }       // кг/(ч·м²)
    double VolumeFlowRate { get; }     // л/(ч·м²)
    
    // Валидация
    bool IsValid { get; }
    string[] ValidationErrors { get; }
    
    // Событие изменения
    event EventHandler<ThermalResultChangedEventArgs>? ResultChanged;
}
```

## 4. Функциональные требования

### 4.1. Use Case UC-1: Расчёт коэффициента теплоотдачи

#### Формула
```
α = 2,26 × (t_П - t_H)^0,33 + 2,6 × v_H    [Вт/м²·К]
```

#### Шаги
| Шаг | Действие | Результат |
|-----|----------|-----------|
| 1 | Получить t_H из IClimateData | Температура наружного воздуха |
| 2 | Получить v_H из IClimateData | Скорость ветра |
| 3 | Получить t_П из выбранного режима | +3, +5 или +7°C |
| 4 | Рассчитать α | Коэффициент теплоотдачи |

#### Критерии приёмки
- ✅ Формула соответствует разделу 2 Formulas_Snegotayanie.md
- ✅ Результат > 0
- ✅ Учитывается скорость ветра

---

### 4.2. Use Case UC-2: Расчёт мощности вверх

#### Формулы
```
Q_таяние = (h / 3600) × 900 × [2100 × (0 - t_H) + 330000 + 4200 × (t_П - 0)]
Q_изл = 0,055 × 5,77 × [(273 + t_П) / 100]^4
Q_конв = α × (t_П - t_H)
q_FB = Q_таяние + Q_изл + Q_конв
```

#### Шаги
| Шаг | Действие | Результат |
|-----|----------|-----------|
| 1 | Получить h из IClimateData | Интенсивность снегопада |
| 2 | Рассчитать Q_таяние | Теплота плавления снега |
| 3 | Рассчитать Q_изл | Лучистый поток |
| 4 | Рассчитать Q_конв | Конвективный поток |
| 5 | Суммировать q_FB | Требуемая мощность |

#### Критерии приёмки
- ✅ Все три составляющие рассчитаны
- ✅ Результат > 0
- ✅ Единицы измерения корректны (Вт/м²)

---

### 4.3. Use Case UC-3: Расчёт теплового сопротивления

#### Формулы
```
R1_total = Σ(d_i / λ_i / 1000)    [м²·К/Вт]
R2_total = Σ(d_i / λ_i / 1000)    [м²·К/Вт]
RFb = R1_total + 1 / α             [м²·К/Вт]
RD = R2_total + 1 / α_низ          [м²·К/Вт]
```

Где α_низ ≈ 999999999 (адиабата)

#### Шаги
| Шаг | Действие | Результат |
|-----|----------|-----------|
| 1 | Получить слои над трубой из IConstructionData | R1 |
| 2 | Получить слои под трубой из IConstructionData | R2 |
| 3 | Рассчитать RFb | Сопротивление вверх |
| 4 | Рассчитать RD | Сопротивление вниз |

#### Критерии приёмки
- ✅ Учёт λА или λБ в зависимости от УГВ
- ✅ RFb > 0, RD > 0

---

### 4.4. Use Case UC-4: Расчёт по теории стержня

#### Формулы
```
m = 0,6 × √[(1/RFb + 1/RD) / (λE × dE)]
x = m × lR / 2
tanh(x) = 1 - 2 / (e^(2×x) + 1)
ηR = tanh(x) / x
```

#### Шаги
| Шаг | Действие | Результат |
|-----|----------|-----------|
| 1 | Получить λE из IConstructionData | Теплопроводность стяжки |
| 2 | Получить dE из параметров трубы | Наружный диаметр |
| 3 | Получить lR (шаг укладки) | Шаг трубы |
| 4 | Рассчитать m | Параметр |
| 5 | Рассчитать ηR | КПД ребра |

#### Критерии приёмки
- ✅ 0 < ηR ≤ 1
- ✅ Формула tanh корректна

---

### 4.5. Use Case UC-5: Расчёт избыточной температуры

#### Формула
```
JHmü = [A + (B - C/(q_FB × RFb × RD)) × D × E] × q_FB × RFb
```

Где:
- A = 1 / ηR
- B = (1/RFb + 1/RD)
- C = |t_H - t_G|
- D = lR / (π × λR)
- E = s / (d - s)

#### Критерии приёмки
- ✅ JHmü > 0
- ✅ T_mean = JHmü + t_H

---

### 4.6. Use Case UC-6: Расчёт температур подачи и обратки

#### Формулы
```
T_mean = JHmü + t_H
T_supply = ввод пользователя
T_return = T_mean - (T_supply - T_mean)
ΔT = T_supply - T_return
```

#### Валидация
- ✅ T_supply > T_mean
- ✅ ΔT в диапазоне 10–15 К
- ✅ T_supply ≤ 65°C (PE-Xa)
- ✅ T_supply ≤ 50°C (бетон)

---

### 4.7. Use Case UC-7: Расчёт расхода теплоносителя

#### Формулы
```
q_total = q_FB + q_D
ṁ = q_total / (c_p / 3,6) / ΔT    [кг/(ч·м²)]
V_dot = ṁ / ρ × 1000              [л/(ч·м²)]
```

#### Критерии приёмки
- ✅ Расход > 0
- ✅ Учитывается тип теплоносителя (вода/гликоль)

## 5. Валидация данных

### 5.1. Правила валидации

| Параметр | Условие | Сообщение об ошибке |
|----------|---------|---------------------|
| T_supply | > T_mean | "Температура подачи должна быть выше средней" |
| T_supply | ≤ 65°C | "Максимальная температура подачи 65°C (PE-Xa)" |
| T_supply | ≤ 50°C (бетон) | "Для бетона макс. температура подачи 50°C" |
| ΔT | 10–15 К | "Температурный перепад должен быть 10–15 К" |
| t_H | < t_П | "Температура наружного воздуха должна быть ниже целевой" |
| h | 0.1–5 см/ч | "Интенсивность снегопада от 0.1 до 5 см/ч" |

### 5.2. Предупреждения

| Условие | Предупреждение |
|---------|---------------|
| q_FB > 300 Вт/м² | "Высокая удельная мощность. Проверьте конструкцию." |
| T_supply > 55°C | "Высокая температура подачи. Убедитесь в совместимости с покрытием." |

## 7. Интерфейсы модуля

### 7.1. Публичный API

```csharp
public interface IThermalCalculator
{
    // Входные данные
    IClimateData ClimateData { get; set; }
    IConstructionData ConstructionData { get; set; }
    
    // Параметры расчёта
    OperatingMode Mode { get; set; }
    double SupplyTemperature { get; set; }
    double DeltaT { get; set; }
    double GroundTemperature { get; set; }
    PipeType Pipe { get; set; }
    double PipeSpacing { get; set; }  // мм
    
    // Методы
    IThermalCalculationResult Calculate();
    bool Validate();
    string[] GetValidationErrors();
    
    // События
    event EventHandler<ThermalResultChangedEventArgs>? CalculationCompleted;
}

public enum OperatingMode
{
    AntiIcing = 3,     // Антиобледенение (+3°C)
    Melting = 5,       // Таяние (+5°C)
    Intensive = 7      // Интенсивное (+7°C)
}

public class PipeType
{
    public string Name { get; set; }        // "RAUTHERM S 17x2,0"
    public double OuterDiameter { get; set; } // мм
    public double WallThickness { get; set; } // мм
    public double ThermalConductivity { get; set; } // Вт/м·К
}
```
