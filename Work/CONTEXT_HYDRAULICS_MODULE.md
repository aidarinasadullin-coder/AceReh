## 3. ВЫЯВЛЕННЫЕ НЕСООТВЕТСТВИЯ В ФОРМУЛАХ

### 3.1 Формула числа Рейнольдса

**В план работ.txt:**
```
Re = 10 * v * (D_ext - 2 * s) / ν
Единицы: v м/с, D и s в мм, ν в мм²/с
```

**В Formulas_Snegotayanie.md раздел 11.6:**
```
Re = v × d_inner / ν
Единицы: d_inner в м, ν в м²/с
```

**ПРОБЛЕМА:** Множитель 10 вместо 1000. При переводе единиц:
- Если d в мм, ν в мм²/с: нужен множитель 1000

**Пример:** v=0.59 м/с, d=13 мм, ν=2.16 мм²/с
- С множителем 10: Re = 35.5 ← НЕВЕРНО
- Правильно: Re = 1000 × 0.59 × 13 / 2.16 = 3550

### 3.2 Формула удельных потерь R

**В план работ.txt:**
```
R = 10000 * (v² * ρ * λ) / (2 * (D_ext - 2*s)) * 100    [Па/м]
Единицы: v м/с, ρ г/см³ (≈1.053), D мм
```

**В Formulas_Snegotayanie.md раздел 11.8:**
```
R = (v² × ρ × λ) / (2 × d_inner) × 100    [Па/м]
```

**ПРОБЛЕМА:** Отсутствуют множители 10000 и несоответствие единиц ρ.

**Пример:** v=0.59 м/с, ρ=1.053 г/см³, λ=0.042, d=13 мм
- По план работ: R = 592 Па/м ← ВЕРНО
- По Formulas: R = 59200 Па/м ← НЕВЕРНО (в100 раз больше!)

### 3.3 Единицы плотности

**В план работ.txt:** ρ в г/см³ (значение ~1.053 для 50% гликоля)
**В Formulas_Snegotayanie.md:** ρ в кг/м³ (значение ~1053)

## 4. ПРАВИЛЬНЫЕ ФОРМУЛЫ (ИЗ план работ.txt)

### Число Рейнольдса:
```
Re = 1000 * v * d_inner / ν

где:
- v — скорость, м/с
- d_inner — внутренний диаметр, мм (= D_ext - 2*s)
- ν — кинематическая вязкость, мм²/с
- Результат: безразмерный

Примечание: Множитель 1000 получается из:
  Re = v[м/с] * d[м] / ν[м²/с]
  Re = v * (d/1000) / (ν * 10^-6)
  Re = v * d * 1000 / ν
```

### Удельные потери давления:
```
R = 10000 * (v² * ρ * λ) / (2 * d_inner) * 100    [Па/м]

где:
- v — скорость, м/с
- ρ — плотность, г/см³ (или кг/л, численно равно)
- λ — коэффициент трения, безразмерный
- d_inner — внутренний диаметр, мм
- Результат: Па/м

Примечание: Множители 10000 * 100 = 1000000 получаются из:
  R = (v² * ρ[кг/м³] * λ) / (2 * d[м])   [Па/м]
  R = (v² * (ρ * 1000) * λ) / (2 * (d/1000))
  R = 1000000 * v² * ρ * λ / (2 * d)
  
  Если ρ в г/см³ (= ρ[кг/м³] / 1000):
  R = 1000 * v² * ρ[г/см³] * 1000 * λ / (2 * d[мм])
  
  Формула в Excel: 10000 * v² * ρ * λ / (2 * d) * 100
```
