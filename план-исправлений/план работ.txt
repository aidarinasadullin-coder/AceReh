7. у нас есть площади обогрева - каждого контура, нужно посчитать тепло на эту площадь:
ФОРМУЛА РАСЧЕТА ОБЩЕЙ МОЩНОСТИ (P_total):

P_total = [ ( L_hk / (100 / VA_hk) ) + ( L_zul / (100 / VA_zul) ) * ( q_zul / 100 ) ] * ( q_up + q_down )

ГДЕ:

L_hk     - Длина греющего контура (м). 
VA_hk    - Шаг укладки основного контура (см). Параметр Verlegeabstand Heizkreis.
           Выражение (L_hk / (100 / VA_hk)) вычисляет эффективную площадь основного обогрева.

L_zul    - Длина подводящих труб / магистралей (м). В таблице ячейка D19.
VA_zul   - Шаг укладки подводок (см). Параметр Verlegeabstand Zuleitung.
q_zul    - Коэффициент эффективности подводок (%). В вашем случае 10%. 
           Показывает, какую долю тепла отдает изолированная подводка относительно открытой трубы.

q_up     - Удельная мощность вверх (Вт/м?). Параметр Leistung nach Oben (qo).
           Это полезная мощность для таяния снега и льда.
q_down   - Удельная мощность вниз (Вт/м?). Параметр Leistung nach Unten (qu).
           Это теплопотери в грунт или бетонное основание под трубами.
