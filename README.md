# КАЛЬКУЛЯТОР СНЕГОТАЯНИЯ РЕХАУ

Система расчёта и проектирования систем снеготаяния открытых площадок.

## Структура проекта

```
ace/
├── docs/                           # Документация
│   ├── ACE.txt                     # Техническое задание
│   ├── Formulas_Snegotayanie.md    # Формулы расчёта
│   └── Hydraulics_Analysis.md      # Анализ гидравлики (Excel)
│
├── data/                           # Базы данных (JSON)
│   ├── climate_db.json             # Климатология 550 городов РФ
│   ├── glycol_data.json            # Свойства гликолей (ASHRAE)
│   ├── materials_db.json           # Материалы конструкции
│   └── rehau_products.json         # Продукция РЕХАУ
│
├── src/                            # Исходный код
│   ├── Core/                       # Бизнес-логика, расчёты
│   ├── UI/                         # WPF интерфейс
│   └── Data/                       # Работа с БД
│
└── resources/                      # Ресурсы
    ├── РЕХАУ_logo.svg              # Логотип
    └── renders/                    # 3D-рендеры
```

## Базы данных

### climate_db.json
Климатические данные по 550 городам РФ (СП 131.13330.2025):
- Температура холодной пятидневки (t_5days_092, t_5days_098)
- Скорость ветра
- Влажность

### glycol_data.json
Свойства гликолей (ASHRAE):
- Этиленгликоль: 10-90% концентрация
- Пропиленгликоль: 10-90% концентрация
- Плотность, вязкость, теплоёмкость, теплопроводность

### materials_db.json
Материалы конструкции:
- λА — сухие условия (УГВ ≥ 1м)
- λБ — влажные условия (УГВ < 1м)

### rehau_products.json
Продукция РЕХАУ:
- Трубы RAUTHERM S (17, 20, 25 мм)
- Коллекторы HKV (2-12 контуров) с артикулами
- Промышленные коллекторы IV 1¼", IV 1½"

## Технологии

- **Язык:** C# (.NET 8)
- **UI:** WPF (MaterialDesignInXamlToolkit)
- **Архитектура:** MVVM (CommunityToolkit.Mvvm)
- **DI:** Microsoft.Extensions.DependencyInjection
- **БД:** SQLite (проекты), JSON (справочники)
- **Отчёты:** QuestPDF, ClosedXML
