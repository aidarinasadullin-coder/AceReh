### Функционал:

1. **Поиск города** — введите минимум 2 символа, появится выпадающий список с городами
2. **Автозаполнение** — при выборе города автоматически заполняются:
   - Температура
   - Скорость ветра
   - Влажность
3. **Определение зоны** — автоматически по температуре
4. **Валидация** — проверка диапазонов значений

## Команды для работы с проектом

```bash
# Сборка проекта
dotnet build SnowMeltingCalculator.sln

# Запуск приложения
cd src && dotnet run

# Запуск тестов
dotnet test tests/SnowMeltingCalculator.Tests

# Публикация_release версии
dotnet publish src/SnowMeltingCalculator.csproj -c Release
```
